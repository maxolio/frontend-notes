## 🧠 Банк концепций и терминов (Словарь)
- **V8** — высокопроизводительный движок JavaScript от Google (используется в Chrome и Node.js), компилирующий JS в машинный код.
- **Statement (Инструкция)** — команда для браузера/интерпретатора выполнить определенное действие (например, `console.log('Hi');`).
- **ASI (Automatic Semicolon Insertion)** — механизм автоматической расстановки точек с запятой в JS парсером.
- **defer** — атрибут тега `<script>`, который загружает файл асинхронно, но выполняет его строго после построения HTML DOM и сохраняет порядок подключения файлов.
- **TDZ (Temporal Dead Zone)** — временная мертвая зона от начала блока до строки объявления `let` / `const`, обращение к переменной в которой вызывает `ReferenceError`.
- **Explaining Variable** — паттерн рефакторинга (поясняющая переменная), вынесение сложного условия в переменную с говорящим именем перед `if`.
- **Callback (Колбэк)** — функция, передаваемая аргументом в другую функцию (без вызова `()`), чтобы та вызвала её позже.
- **NFE (Named Function Expression)** — функциональное выражение с внутренним именем (`const fn = function inner() {}`), видимым только внутри самой функции.
- **Closure (Замыкание)** — способность функции запоминать и сохранять доступ к переменным своего лексического окружения, в котором она была создана.
