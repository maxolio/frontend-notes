# Урок 01. Семантика и базовая структура HTML5

Суть урока: Семантические теги (`<header>`, `<main>`, `<nav>`, `<article>`, `<footer>`) описывают смысл блоков для браузера, скринридеров и поисковиков вместо безликих `<div>`.

## 1. Каркас семантической страницы

[+] Обязательный стартовый шаблон: здесь легко добавлять свои будущие конспекты по HTML прямо в папку `site/data/html/`.

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Документ</title>
</head>
<body>
  <header>Шапка и навигация</header>
  <main>
    <article>Основная статья</article>
  </main>
  <footer>Подвал</footer>
</body>
</html>
```

[!] Внутри формы `<button>` без атрибута `type` по умолчанию работает как `type="submit"` и перезагружает страницу. Для обычных кликов в JS всегда пиши `type="button"`.

## 3 главные ловушки урока (чек-лист для повторения)

1. Использовать `<section>` как обычную обёртку для стилей: если у блока нет логического заголовка, бери `<div>`.

2. Ставить несколько `<main>` на странице без `hidden`: основной контент страницы должен быть в одном `<main>`.

3. Делать кнопки из `<div>` или `<a>` без `href`: для действий внутри страницы используй `<button type="button">`.
