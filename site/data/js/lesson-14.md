# Урок 14. Строки и методы работы со строками

Суть урока: строки в JS неизменяемы (иммутабельны) — ни один метод не меняет исходную строку, а всегда возвращает новую строку (или число / boolean / массив).

## 1. Длина строки (length) и доступ к символам ([], at) (00:25 – 02:19)

```js
const word = 'Привет';
/* length — СВОЙСТВО (скобки () не ставим!). Пробелы тоже считаются за символы ('' -> 0). */
word.length;           // 6  |  '😀'.length -> 2 (эмодзи в UTF-16 занимает 2 единицы!)
[...'😀'].length;      // 1  (способ узнать реальное число символов со смайлами)
word[0];               // 'П' (индексы начинаются с 0)
word[-1];              // undefined (минус в [] НЕ работает!)
word[word.length - 1]; // 'т' (старый способ взять последний символ)
/* .at(индекс) — современный способ: понимает отрицательные индексы (считает с конца): */
word.at(-1);           // 'т' (последний символ)  |  word.at(-2) -> 'е'
/* Оба способа ТОЛЬКО для чтения: word[0] = 'Б' не сработает, а word.at(0) = 'Б' -> ошибка! */
```

## 2. Изменение регистра и обрезка пробелов (03:29 – 03:44)

```js
const raw = '   JavaScript   ';
raw.toLowerCase(); // '   javascript   ' (в нижний регистр)
raw.toUpperCase(); // '   JAVASCRIPT   ' (в верхний регистр)
/* trim убирает пробелы (и переносы \n) только ПО КРАЯМ, пробелы в середине остаются: */
raw.trim();        // 'JavaScript'
raw.trimStart();   // 'JavaScript   ' (только слева/в начале)
raw.trimEnd();     // '   JavaScript' (только справа/в конце)
```

## 3. Поиск в строке и 2-й аргумент (04:34 – 06:13)

```js
const text = 'Привет, фронтенд мир!';
/* ВСЕ методы поиска чувствительны к регистру ('Мир' !== 'мир')! */
text.indexOf('мир');        // 17 (индекс начала)  |  если не найдено -> -1
text.indexOf('мир') !== -1; // true (классическая проверка наличия через indexOf)
text.includes('мир');       // true (более удобная проверка есть/нет в современном JS)
text.startsWith('При');     // true (начинается ли строка с этого фрагмента)
text.endsWith('мир!');      // true (заканчивается ли строка этим фрагментом)
/* 2-й аргумент — стартовый индекс (indexOf/includes/startsWith) или длина (endsWith): */
text.includes('Привет', 1);    // false (ищем с 1-го индекса — буква 'П' на 0 позади)
text.startsWith('фронтенд', 8); // true (с индекса 8 начинается 'фронтенд')
text.endsWith('фронтенд', 16); // true  (обрезаем конец поиска до первых 16 символов)

/* Поиск ВСЕХ вхождений подстроки с помощью 2-го аргумента indexOf в цикле while: */
let pos = 0;
while (true) {
  const found = 'иа и иа'.indexOf('иа', pos);
  if (found === -1) break;
  console.log(found);  // Выведет: 0, затем 5
  pos = found + 1;     // Сдвигаем старт на следующий символ после найденного
}
```

## 4. Получение подстроки: slice и substring (08:08 – 11:19)

```js
const lang = 'JavaScript';
/* Оба вырезают от start до end (НЕ включая end). Без end — берут до конца строки. */
lang.slice(0, 4);     // 'Java'   |  lang.slice(4) -> 'Script'
lang.slice(-6);       // 'Script' (slice понимает минусы с конца — используй именно его!)
lang.slice(-6, -3);   // 'Scr'    (важно: -6 < -3; если start > end, slice вернёт '')
/* substring: минусы превращает в 0, а если start > end — сам меняет их местами: */
lang.substring(4, 0); // 'Java'   (поменял 4 и 0 местами; старый substr() устарел!)
```

## 5. Повтор, замена (с регулярками) и разбиение на массив (11:20 – 13:52)

```js
'ха'.repeat(3);                        // 'хахаха' (повторяет строку N раз)
/* replace меняет ТОЛЬКО ПЕРВОЕ совпадение; replaceAll — ВСЕ совпадения (регистр важен!): */
'дом и дом'.replace('дом', 'лес');     // 'лес и дом'
'дом и дом'.replaceAll('дом', 'лес');  // 'лес и лес'
/* Регулярные выражения /.../ в replace (g = все совпадения, i = без учёта регистра): */
'BackEnd и BACKEND'.replace(/backend/gi, 'FrontEnd'); // 'FrontEnd и FrontEnd'
'Код 123 и 45'.replace(/\d/g, '#');   // 'Код ### и ##' (\d находит любую цифру)
/* split(разделитель, limit) — режет строку в МАССИВ (limit ограничивает число частей): */
'яблоко, груша, киви'.split(', ', 2);  // ['яблоко', 'груша']
'код'.split('');                       // ['к', 'о', 'д'] (разбить посимвольно)
```

## 6. Иммутабельность, чейнинг и задача валидации ввода (15:01 – 17:12)

```js
/* Методы НЕ меняют исходную строку — результат нужно сохранять (или переприсвоить let): */
let msg = '  Привет  ';
msg.trim().toUpperCase(); // Без присвоения результат уйдёт 'в никуда' (msg не изменится!)
/* Чейнинг (цепочка методов, каждый следующий работает с результатом предыдущего): */
msg = msg
  .trim()
  .toUpperCase()
  .slice(0, 4);           // 'ПРИВ'

/* Задача из урока: валидация имени пользователя из prompt: */
const value = prompt('Введите имя:') ?? '';
const clearValue = value.trim();
if (clearValue.length === 0) {
  alert('Имя не может быть пустым'); // Ловит даже ввод из одних пробелов
} else if (clearValue.toLowerCase().includes('админ')) {
  alert('Ошибка: вы не можете занять это имя'); // Ловит 'АдМиН', 'ADMIN' и т.д.
}
```

## 7. Спецсимволы, перебор посимвольно и алфавитное сравнение

```js
/* 1. Спецсимволы (экранирование \): \n — перенос строки, \' и \" — кавычки. */
const lines = 'Строка 1\nСтрока 2';
/* 2. Перебор строки посимвольно через for..of (безопасно даже для строк с эмодзи!): */
for (const char of 'JS') { console.log(char); } // 'J', затем 'S'
/* 3. > и < сравнивают коды Unicode (где 'a' > 'Z' и 'ё' > 'я'!). Для алфавита: */
'ёлка'.localeCompare('яблоко'); // -1 ('ёлка' идёт раньше 'яблоко' по алфавиту!)
```

## 3 главные ловушки урока (чек-лист для повторения)

1. Строки иммутабельны — вызов str.trim() или str.toLowerCase() без присвоения результата в переменную пропадёт впустую.

2. indexOf возвращает 0 как нормальный индекс — проверка if (str.indexOf("П")) даст false, если слово в самом начале! Сравнивай !== -1 или бери includes().

3. Замена/поиск зависят от регистра и ломаются на "ё" — приводи к toLowerCase(), используй флаги /.../gi и localeCompare() для сортировки.
