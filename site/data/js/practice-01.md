<summary>🧩 Задача 1. Перепиши if на ?? и ??=</summary>

**Темы для повторения:** Урок 05 (`??` и `??=`, отличие от `||` и сравнение с `null` / `undefined`).  
**Сложность:** 🟢 Лёгкая

### Что нужно сделать
В коде ниже длинный блок `if / else` проверяет переменные на `null` и `undefined`. Замени его на **одну строчку** с помощью операторов `??` и `??=`.

> **Напоминание:**
> - `a ?? b` — возвращает `a`, если оно не `null` / `undefined`, иначе `b`.
> - `a ??= b` — записывает `b` в `a`, только если `a` сейчас `null` или `undefined`.

1. Удали весь блок `if / else`.
2. Одной строкой обнови `result`: если `result` сейчас пустой (`null` или `undefined`), запиши в него `num1`, а если и `num1` пустой — то `num2`.
3. Выведи итоговый `result` в консоль.

**Проверь себя на разных значениях:**
- `num1 = 10`, `num2 = 20`, `result = undefined` -> выведет `10`
- `num1 = null`, `num2 = 20`, `result = undefined` -> выведет `20`
- `num1 = 10`, `num2 = 20`, `result = 0` -> выведет `0` (`result` не перезапишется, так как `0` — не `null` и не `undefined`)

### Шаблон для копирования
```js
'use strict';

const num1 = 10;
const num2 = 20;
let result;

/* Перепиши этот блок в 1 строку через ??= и ??: */
if (result === null || result === undefined) {
  if (num1 !== null && num1 !== undefined) {
    result = num1;
  } else {
    result = num2;
  }
}

console.log(result);
```

<details>
<summary>Раскрыть решение</summary>

```js
'use strict';

const num1 = 10;
const num2 = 20;
let result;

/*
  1. result сейчас undefined, поэтому ??= запускает вычисление правой части.
  2. num1 ?? num2 возвращает 10 (не null и не undefined; до num2 не доходит).
  3. Важный нюанс: если бы result изначально был 0 или '', оператор ??=
     оставил бы их как есть (в отличие от ||=).
*/
result ??= num1 ?? num2;

console.log(result); /* 10 */
```

<summary>Раскрыть решение</summary>

/*
  Вариант 1 (с оператором !):
  Скобки вокруг (age >= 14 && age <= 90) обязательны!
  Без них ! сработает только на age (!age), а не на всё условие.

*/
if (age < 14 || age > 90) {

<summary>🧩 Задача 6. Мега-тренажёр: 45 коварных сравнений (==, ===, &gt;, &gt;=, Object.is)</summary>

**Темы для повторения:** Урок 04 (`==` vs `===`, приведение примитивов, сравнения строк, `null` и `undefined`).  
**Сложность:** 🟢 Лёгкая *(удобно проходить порциями по 10–15 пунктов)*

### 5 правил движка JS (ключ ко всем 45 примерам)
1. **`===` никогда не меняет типы:** разные типы сразу дают `false`. Нюансы: `NaN !== NaN`, `+0 === -0`, а объекты и массивы сравниваются **по ссылке в памяти**.
2. **В `==` при одинаковых типах приведения НЕТ** — работает как `===` (поэтому `'0' == ''` даёт `false`, и `[] == []` даёт `false`).
3. **В `==` у `null` и `undefined` спецправило:** они равны **только друг другу** и никому больше (`null == 0` и `null == false` — всегда `false`).
4. **В `==` все остальные разные типы сводятся к числу:** `boolean` сразу становится `1`/`0`, строка парсится как `Number(...)`, а массив/объект переводится в примитив (обычно через `.toString()`).
5. **В неравенствах `<`, `>`, `<=`, `>=`:** две строки сравниваются посимвольно по Unicode (`'20' > '100'`), а в остальных случаях всё идёт через `Number()` — **включая `null` (`0`) и `undefined` (`NaN`)**.

1. Пройдись по строкам `1–45` и рядом с каждым выражением сначала **устно (или в комментарии)** запиши свой прогноз (`true` или `false`) и **почему именно так** по 5 правилам выше.

<details>
<summary>Полный разбор всех 45 выражений по пунктам</summary>

#### Часть 1А. Нестрогое сравнение (`==`) — примитивы
1. `'0' == 0` -> **`true`** — строка приводится к числу: `Number('0')` даёт `0`, `0 == 0`.
2. `'' == 0` -> **`true`** — пустая строка при переводе в число даёт `0`, `0 == 0`.
3. `'   ' == 0` -> **`true`** — `Number()` сначала обрезает пробелы/табы/переносы, остаётся `''`, а это `0`.
4. `'010' == 10` -> **`true`** — ведущий ноль в десятичной строке отбрасывается: `Number('010')` даёт `10`.
5. `'10px' == 10` -> **`false`** — `Number('10px')` даёт `NaN`, а `NaN` ничему не равен.
6. `'0' == ''` -> **`false`** — **ловушка!** Оба операнда одного типа (`string`), приведения к числу НЕТ: сравниваются `'0'` и `''`.
7. `'0' == false` -> **`true`** — сначала `false` становится `0`, затем `'0'` становится `0` -> `0 == 0`.
8. `'' == false` -> **`true`** — `false` -> `0`, `''` -> `0` -> `0 == 0`.
9. `'   ' == false` -> **`true`** — `false` -> `0`, `'   '` -> `0` -> `0 == 0` (хотя в `if ('   ')` строка истинна!).
10. `'1' == true` -> **`true`** — `true` -> `1`, `'1'` -> `1` -> `1 == 1`.
11. `'2' == true` -> **`false`** — **ловушка!** `true` становится числом `1`, а `'2'` — числом `2`; `2 == 1` даёт `false`.
12. `'true' == true` -> **`false`** — `true` -> `1`, а `Number('true')` -> `NaN`; `NaN == 1` даёт `false`.
13. `'false' == false` -> **`false`** — `false` -> `0`, а `Number('false')` -> `NaN`; `NaN == 0` даёт `false`.
14. `null == undefined` -> **`true`** — особое правило языка: они равны друг другу (удобная проверка `x == null`).
15. `null == 0` -> **`false`** — в `==` `null` **не приводится** к числу `0` (равен только `null` и `undefined`).
16. `null == false` -> **`false`** — то же спецправило `null`.
17. `undefined == false` -> **`false`** — то же спецправило `undefined`.
18. `NaN == NaN` -> **`false`** — `NaN` не равен ничему, даже самому себе (а `NaN != NaN` даёт `true`).
19. `10n == 10` -> **`true`** — в `==` типы `bigint` и `number` сравниваются по математическому значению.
20. `'10' == 10n` -> **`true`** — строка `'10'` переводится в `BigInt` (`10n`), `10n == 10n`.

#### Часть 1Б. Нестрогое сравнение (`==`) — объекты и массивы (на вырост)
21. `[] == false` -> **`true`** — `false` -> `0`; массив `[]` через `.toString()` становится `''`, затем `0` -> `0 == 0`.
22. `[] == 0` -> **`true`** — `[]` -> `''` -> `0`; `0 == 0`.
23. `[] == ''` -> **`true`** — `[]` -> `''`; `'' == ''`.
24. `[1] == 1` -> **`true`** — `[1].toString()` даёт `'1'`, затем `Number('1')` -> `1`; `1 == 1`.
25. `[1, 2] == '1,2'` -> **`true`** — `[1, 2].toString()` склеивает элементы через запятую в `'1,2'`.
26. `[] == []` -> **`false`** — оба операнда одного типа (`object`), сравниваются **ссылки в памяти** (разные массивы).
27. `[] == ![]` -> **`true`** — **хит собеседований!** Шаг 1: `![]` даёт `false`. Шаг 2: `[] == false` сводится к `0 == 0`.
28. `({}) == false` -> **`false`** — `false` -> `0`; `({}).toString()` даёт `'[object Object]'`, а `Number(...)` -> `NaN`.

#### Часть 2. Строгое сравнение (`===`)
29. `'0' === 0` -> **`false`** — разные типы (`string` и `number`), приведения нет.
30. `'' === false` -> **`false`** — разные типы (`string` и `boolean`).
31. `'true' === true` -> **`false`** — разные типы (`string` и `boolean`).
32. `null === undefined` -> **`false`** — в строгом `===` это два разных типа данных.
33. `10n === 10` -> **`false`** — разные типы (`bigint` и `number`), в отличие от `10n == 10`.
34. `NaN === NaN` -> **`false`** — даже в строгом сравнении `NaN` не равен сам себе (проверяем через `Number.isNaN(x)`).
35. `+0 === -0` -> **`true`** — в `===` плюс-ноль и минус-ноль считаются равными.
36. `0.1 + 0.2 === 0.3` -> **`false`** — из-за двоичной точности IEEE 754 слева получается `0.30000000000000004`.
37. `Infinity === Infinity` -> **`true`** — в отличие от `NaN`, бесконечность равна сама себе.
38. `[] === []` -> **`false`** — разные ссылки в памяти (то же самое для `({}) === ({})`).

#### Часть 3. Бонус — неравенства (`<`, `>`, `>=`) и `Object.is`
39. `'20' > '100'` -> **`true`** — обе стороны строки: сравниваются посимвольно по кодам Unicode, `'2'` больше `'1'`.
40. `'20' > 100` -> **`false`** — разные типы: `'20'` приводится к числу `20`, а `20 > 100` ложно.
41. `'ёлка' > 'яблоко'` -> **`true`** — код буквы `'ё'` в Unicode стоит после `'я'` (для алфавита используют `.localeCompare()`).
42. `null > 0` -> **`false`** — в неравенствах `null` приводится к `0`: `0 > 0` даёт `false`.
43. `null >= 0` -> **`true`** — **главная ловушка `null`!** `null == 0` было `false`, но `>=` приводит `null` к `0`.
44. `undefined >= 0` -> **`false`** — `undefined` при переводе в число даёт `NaN`, а любое неравенство с `NaN` всегда `false`.
45. `Object.is(NaN, NaN)` -> **`true`**, а `Object.is(+0, -0)` -> **`false`** — сверхстрогое сравнение, исправляющее два исключения `===`.

### Вариант 1 (классический цикл `for`)
```js
'use strict';

function analyzeText(text, forbiddenChar = '!') {
  /* Оператор ?? заменяет только null и undefined на '', не трогая другие значения */
  const textResult = text ?? '';
  const textLength = textResult.length;

  /* Выносим приведение к нижнему регистру до цикла, чтобы не делать его на каждом шаге */
  const targetChar = forbiddenChar.toLowerCase();

  let spaces = 0;
  let forbiddenCount = 0;

  /* Цикл for проходит по индексам строки от 0 до последнего символа */
  for (let i = 0; i < textResult.length; i++) {
    const char = textResult[i];

    if (char === ' ') {
      spaces += 1;
    }

    /* Сравниваем текущий символ тоже в нижнем регистре, чтобы 'А' и 'а' совпадали */
    if (char.toLowerCase() === targetChar) {
      forbiddenCount += 1;
    }
  }

  /* Сокращённая запись свойств: spaces: spaces и forbiddenCount: forbiddenCount */
  return { length: textLength, spaces, forbiddenCount };
}

/* Пояснение:
   1. text ?? '' страхует от ошибки при чтении .length у null/undefined.
   2. Оба сравниваемых символа (char и forbiddenChar) приводятся к lowerCase,
      иначе заглавная буква в тексте не совпала бы с маленькой в forbiddenChar. */
```

### Вариант 2 (через цикл `for..of` и единый нижний регистр)

'use strict';

function analyzeText(text, forbiddenChar = '!') {
  /* Сразу приводим всю строку и искомый символ к нижнему регистру один раз */
  const normalized = (text ?? '').toLowerCase();
  const target = forbiddenChar.toLowerCase();

  let spaces = 0;
  let forbiddenCount = 0;

  /* for..of сразу даёт каждый символ строки без индекса i */
  for (const char of normalized) {
    if (char === ' ') {
      spaces += 1;
    } else if (char === target) {
      forbiddenCount += 1;
    }
  }

  return {
    length: normalized.length,
    spaces,
    forbiddenCount,
  };
}

/* Пояснение:
   1. Выражение (text ?? '').toLowerCase() сразу безопасно готовит строку.
   2. else if логично разделяет ветки: если символ — пробел (и target не пробел),
      второе условие проверять уже не нужно.
   3. Цикл for..of читается короче, когда индекс i внутри тела не используется. */

### Пошаговый разбор: почему внутри метода теряется `this` и как работает `.call()`

#### 1. Почему `function applyBonus()` внутри метода падает
1. **Шаг 1. Вызов `player1.addBonus(25)`**
   Перед точкой стоит `player1`, поэтому внутри `addBonus` значение `this === player1`.

3. **Шаг 3. Падение при `this.score += ...`**
   Движок пытается прочитать `undefined.score` и падает с `TypeError`.

#### 2. Почему стрелка `const applyBonus = () => ...` спасает
1. **Шаг 1. Создание стрелки внутри `addBonus`**
   У стрелочной функции нет собственного `this`, поэтому она смотрит на `this` внешней функции `addBonus` (а там `this === player1`).
2. **Шаг 2. Вызов `applyBonus()`**
   ```js
   applyBonus(); // внутри стрелки this всё равно равен player1
   ```

#### 3. Как работает `showInfo.call(player1, 'Игрок 1')`
1. **Шаг 1. Временная подмена `this`**
   `.call(player1, 'Игрок 1')` берёт функцию `showInfo`, на один вызов подставляет внутрь `this = player1` и передаёт `'Игрок 1'` в параметр `prefix`.
2. **Шаг 2. Выполнение тела `showInfo`**
   ```js
   console.log(`${'Игрок 1'}: ${player1.name} — ${player1.score} очков`);
   // Игрок 1: Алекс — 150 очков
   ```

#### 4. Все 4 способа привязать отдельную функцию к объекту

```js
'use strict';

const player1 = { name: 'Алекс', score: 150 };

function showInfo(prefix) {
  console.log(`${prefix}: ${this.name} — ${this.score} очков`);
}

/* 1. .call() — вызывает функцию СРАЗУ, аргументы через запятую */
showInfo.call(player1, 'Игрок 1');

/* 2. .apply() — вызывает функцию СРАЗУ, аргументы массивом */
showInfo.apply(player1, ['Игрок 1']);

/* 3. .bind() — НЕ вызывает сразу, а возвращает новую функцию с приклеенным this */
const showPlayer1 = showInfo.bind(player1);
showPlayer1('Игрок 1');

/* 4. Положить функцию в свойство объекта и вызвать через точку */
player1.show = showInfo;
player1.show('Игрок 1');
```

*Важно:* все 4 способа работают только с обычной `function showInfo`. Стрелочная функция игнорирует `.call`, `.apply`, `.bind` и вызов через точку.
