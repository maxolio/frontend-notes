# Урок 08. Функции: объявление, область видимости, параметры и return

Суть урока: Функция (Function Declaration) выполняется только в момент вызова name(), имеет локальную область видимости {}, принимает аргументы по порядку (дефолтные параметры ставят последними) и всегда возвращает результат (или undefined без return).

## 1. Объявление функции и область видимости (00:15–06:38)

[+] Любые фигурные скобки {} (функция, цикл или отдельный блок) создают локальную область видимости: изнутри видно внешние переменные, а снаружи внутренние — нет. Локальное имя перекрывает глобальное только внутри своего блока.

```js
const message = 'Глобальный привет';

function logMessage() { /* при объявлении код внутри НЕ выполняется */
  const message = 'Локальный привет'; /* затеняет глобальную только здесь */
  const innerOnly = 'Секрет';
  console.log(message); /* "Локальный привет" */
}

logMessage();         /* запуск кода функции */
/* Hoisting: Function Declaration всплывает и её можно вызывать даже ДО строки объявления! */
console.log(message); /* "Глобальный привет" */
/* console.log(innerOnly); -> ReferenceError: innerOnly is not defined */
```

## 2. Параметры, аргументы и значения по умолчанию (06:39–13:33)

[+] Параметры в (...) при объявлении ведут себя как локальные let-переменные, а при вызове в них по порядку попадают аргументы. Хороший стиль: не менять сам параметр внутри тела и ставить необязательные параметры по умолчанию в конец списка.

```js
function repeatMessage(text = 'Мяу', count = 1) { /* значения по умолчанию */
  for (let i = 0; i < count; i++) {
    console.log(text);
  }
}

repeatMessage('Привет', 3);       /* text = 'Привет', count = 3 */
repeatMessage('Привет');          /* count станет 1 (по умолчанию) */
repeatMessage(undefined, 2);      /* пропуск 1-го аргумента — сработает "Мяу" */
/* Дефолт сработает ТОЛЬКО при undefined (null, 0 и "" его НЕ включают)! */
/* Выражение по умолчанию (напр. text = getTitle()) вычисляется заново в момент вызова! */
```

## 3. Возврат значения (return) и ранний выход (13:34–19:04)

[+] Инструкция return вычисляет выражение, отдаёт его наружу и сразу завершает функцию (код ниже return не сработает). Если return нет или он пустой — вернётся undefined. Удобно для раннего выхода при проверках на старте функции.

```js
function getAgeType(age) {
  if (typeof age !== 'number') return 'Возраст указан некорректно';
  if (age < 1 || age > 125)    return 'Такого возраста не может быть';
  if (age < 18)                return 'Несовершеннолетний';
  return 'Взрослый'; /* сработает, только если все проверки выше не вышли */
}

function getSecretMessage(name) {
  if (!name) return; /* пустой return досрочно вернёт undefined */
  return `Секрет для ${name}`;
}

/* Ловушка ASI: после return перенос строки вернёт undefined! Если переносим итог, */
/* открывающую скобку ставят на той же строке: return ( ... ); */
```

## 3 главные ловушки урока (чек-лист для повторения)

1. Указать параметры по умолчанию в начале списка (придётся передавать undefined для пропуска) или забыть передать нужный аргумент (параметр станет undefined).

2. Забыть return (функция вернёт undefined) или написать инструкции после return (после возврата функция останавливается, и нижний код мёртв).

3. Пытаться прочитать переменную, объявленную внутри {}, снаружи функции, либо перезаписывать входной параметр напрямую вместо новой локальной переменной.
