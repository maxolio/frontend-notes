# Урок 08. Функции: объявление, область видимости, параметры и `return`

Суть урока:

- **Вызов и область:** функция (`Function Declaration`) запускается только при вызове `name()` и имеет свою локальную область видимости `{}`.
- **Параметры и возврат:** аргументы передаются по порядку (дефолтные ставят последними); функция всегда возвращает результат (или `undefined`, если нет `return`).

## 1. Объявление функции и область видимости (00:15–06:38)

[+] Любые фигурные скобки `{}` (функция, цикл или отдельный блок) создают локальную область видимости: изнутри видно внешние переменные, а снаружи внутренние — нет. Локальное имя перекрывает (затеняет) внешнее только внутри своего блока.

```js
const message = 'Глобальный привет';

/* Hoisting: Function Declaration можно вызывать ДО объявления */
logMessage();

function logMessage() {
  /* Новая const затеняет внешнюю message, не меняя её снаружи */
  /* (а запись без const/let изменила бы внешнюю let-переменную) */
  const message = 'Локальный привет';
  const innerOnly = 'Секрет';
  console.log(message); /* 'Локальный привет' */
}

console.log(message); /* 'Глобальный привет' */
/* console.log(innerOnly); -> ReferenceError: innerOnly is not defined */
```

## 2. Параметры, аргументы и значения по умолчанию (06:39–13:33)

[+] **Параметры** — имена в `(...)` при объявлении функции (ведут себя как локальные `let`), а **аргументы** — реальные значения при вызове. Недостающие параметры получают `undefined`, а лишние аргументы просто игнорируются. Хороший стиль: не перезаписывать входной параметр и ставить параметры по умолчанию в конец списка.

```js
/* Значения по умолчанию сработают, если аргумент не передан */
function repeatMessage(text = 'Мяу', count = 1) {
  for (let i = 0; i < count; i++) {
    console.log(text);
  }
}

repeatMessage('Привет', 3);      /* text = 'Привет', count = 3 */
repeatMessage('Привет');         /* count станет 1 (по умолчанию) */
repeatMessage(undefined, 2);     /* пропуск 1-го -> сработает 'Мяу' */
repeatMessage('Hi', 1, 'лишний');/* лишний 3-й аргумент игнорируется */

/* Дефолт включается ТОЛЬКО при undefined (null, 0 и '' — НЕТ!) */
/*
  Выражение по умолчанию (text = getTitle()) вычисляется заново
  в момент вызова, но ТОЛЬКО если аргумент равен undefined
*/
```

## 3. Возврат значения (`return`) и ранний выход (13:34–19:04)

[+] Инструкция `return` вычисляет выражение, отдаёт его наружу и мгновенно завершает функцию (код ниже `return` не сработает). Если `return` нет или он пустой — вернётся `undefined`. Это удобно для раннего выхода (guard) при проверках в начале функции.

```js
function getAgeType(age) {
  /* Проверяем и тип, и NaN (иначе NaN проскочил бы в 'Взрослый'!) */
  if (typeof age !== 'number' || Number.isNaN(age)) {
    return 'Возраст указан некорректно';
  }
  if (age < 1 || age > 125) return 'Такого возраста не может быть';
  if (age < 18) return 'Несовершеннолетний';

  return 'Взрослый'; /* дойдёт сюда, если проверки выше не вышли */
}

function getSecretMessage(name) {
  if (!name) return; /* пустой return досрочно вернёт undefined */
  return `Секрет для ${name}`;
}

/*
  Ловушка ASI: перенос сразу после return вернёт undefined!
  Чтобы перенести выражение, ставьте '(' на строке с return
*/
```

| Вариант в функции | Что вернёт вызов | Пояснение |
| :--- | :--- | :--- |
| `return expr;` | Результат `expr` | Выходит из функции немедленно |
| `return;` (пустой) | `undefined` | Досрочный выход без значения |
| Нет `return` | `undefined` | Функция доходит до `}` и отдаёт `undefined` |
| `return` + перенос строки | `undefined` | Из-за ASI движок ставит `;` после `return` |

## 3 главные ловушки урока (чек-лист для повторения)

1. Указать параметры по умолчанию в начале списка (придётся передавать `undefined` для пропуска) или ждать, что `null`, `0` или `''` включат значение по умолчанию (включает только `undefined`).
2. Забыть `return`, поставить перенос строки сразу после `return` (ловушка ASI -> `undefined`) или написать код ниже `return` (он никогда не выполнится).
3. Пытаться прочитать локальную переменную из `{}` снаружи функции (`ReferenceError`), либо перезаписывать входной параметр напрямую вместо новой локальной переменной.

## Вопросы для закрепления

**1. Что выведет функция `greet` при каждом из трёх вызовов и почему не везде сработает `'Гость'`?**

```js
function greet(name = 'Гость') {
  console.log(`Привет, ${name}!`);
}

greet();
greet(null);
greet('');
```

<details>
<summary>Показать ответ</summary>

1. `Привет, Гость!` — аргумент не передан, значит внутри `name === undefined`, и включается значение по умолчанию.
2. `Привет, null!` — параметр по умолчанию срабатывает **строго только при `undefined`**. Переданные `null`, `0`, `false` или `''` считаются полноценными значениями.
3. `Привет, !` — пустая строка `''` тоже отменяет значение по умолчанию.

</details>

**2. Что вернёт `getSum(2, 3)` и сработает ли строка `console.log` внутри функции?**

```js
function getSum(a, b) {
  return
  a + b;
  console.log('Готово');
}
```

<details>
<summary>Показать ответ</summary>

Функция вернёт **`undefined`**, а `console.log('Готово')` никогда не запустится. Из-за переноса строки сразу после `return` движок по правилам ASI автоматически ставит точку с запятой (`return;`) и мгновенно завершает функцию. Чтобы безопасно перенести результат на новую строку, открывающую скобку оставляют на строке с `return`: `return (a + b);`.

</details>

**3. Почему вызов `showTitle()` сработает до строки объявления функции и что окажется в последнем `console.log(title)`?**

```js
const title = 'Внешний';
showTitle();

function showTitle() {
  const title = 'Внутренний';
  console.log(title);
}

console.log(title);
```

<details>
<summary>Показать ответ</summary>

В консоли появится сначала **`'Внутренний'`**, затем **`'Внешний'`**.

1. `Function Declaration` (`function showTitle()`) всплывает в начало области видимости (`hoisting`), поэтому к ней можно обращаться даже выше её объявления в файле.
2. `const title` внутри `{ ... }` создаёт отдельную локальную переменную, которая лишь временно затеняет внешнюю `title` и не меняет её снаружи.

</details>

## Задачи

**Задача 1. Функция `min(a, b)` с ранним выходом**

Напиши функцию `min(a, b)`, возвращающую меньшее из двух чисел (если числа равны — любое из них):

1. В начале функции сделай ранний выход: если хотя бы один аргумент не типа `number` или равен `NaN` (`Number.isNaN`), сразу верни `null`.
2. Если аргументы валидны, верни меньшее число через тернарный оператор `? :`.

Проверка: `min(2, 5)` -> `2`, `min(3, -1)` -> `-1`, `min(4, 4)` -> `4`, `min('2', 5)` -> `null`.

```js
'use strict';

/* Твоё решение: */

console.log(min(2, 5));   /* 2 */
console.log(min(3, -1));  /* -1 */
console.log(min(4, 4));   /* 4 */
console.log(min('2', 5)); /* null */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

function min(a, b) {
  /*
    Ранний выход (guard): отсекаем нечисловые аргументы и NaN до расчётов,
    чтобы основная логика функции оставалась плоской и чистой
  */
  if (
    typeof a !== 'number' ||
    typeof b !== 'number' ||
    Number.isNaN(a) ||
    Number.isNaN(b)
  ) {
    return null;
  }

  /* Возвращаем меньшее из двух чисел через тернарный оператор */
  return a < b ? a : b;
}

console.log(min(2, 5));   /* 2 */
console.log(min(3, -1));  /* -1 */
console.log(min(4, 4));   /* 4 */
console.log(min('2', 5)); /* null */
```

</details>

**Задача 2. Функция `pow(x, n)` с параметром по умолчанию и циклом**

Напиши функцию `pow(x, n = 2)`, которая возводит `x` в натуральную степень `n` без оператора `**`:

1. Если `n < 1` или `n` дробное (`n % 1 !== 0`), сразу верни `null`.
2. Заведи локальный накопитель `let result = 1` и умножь его на `x` ровно `n` раз в цикле `for`.
3. Верни итоговое значение `result`.

Проверка: `pow(3)` -> `9`, `pow(2, 4)` -> `16`, `pow(5, 0)` -> `null`, `pow(2, 1.5)` -> `null`.

```js
'use strict';

/* Твоё решение: */

console.log(pow(3));      /* 9 */
console.log(pow(2, 4));   /* 16 */
console.log(pow(5, 0));   /* null */
console.log(pow(2, 1.5)); /* null */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

/* Необязательный параметр по умолчанию n = 2 ставим последним в списке */
function pow(x, n = 2) {
  /* Ранний выход для степени меньше 1 или дробного числа (n % 1 !== 0) */
  if (n < 1 || n % 1 !== 0) return null;

  /* Заводим накопитель, чтобы не перезаписывать входной параметр x */
  let result = 1;

  for (let i = 0; i < n; i++) {
    result *= x;
  }

  return result;
}

console.log(pow(3));      /* 9 (подставилось n = 2 по умолчанию) */
console.log(pow(2, 4));   /* 16 */
console.log(pow(5, 0));   /* null */
console.log(pow(2, 1.5)); /* null */
```

</details>

**Задача 3. Почини порядок параметров, потерянный `return` и перенос строки**

Сейчас обе функции ниже возвращают `undefined` или путают аргументы. Почини их:

1. В `createOrderText` перенеси обязательный параметр `price` на первое место, `currency = 'RUB'` — в конец, и верни `label` через `return`.
2. В `formatGreeting` исправь перенос строки после `return` (оберни возвращаемую строку в скобки `return (...)` или оставь на той же строке).

Проверка: в консоль должны вывестись `'1500 RUB'`, `'1500 $'` и `'Добро пожаловать, Алиса!'`.

```js
'use strict';

/* Твоё решение: */
function createOrderText(currency = 'RUB', price) {
  const label = `${price} ${currency}`;
}

function formatGreeting(userName) {
  if (!userName) return 'Привет, гость!';

  return
    `Добро пожаловать, ${userName}!`;
}

console.log(createOrderText(1500));      /* должно быть: 1500 RUB */
console.log(createOrderText(1500, '$')); /* должно быть: 1500 $ */
console.log(formatGreeting('Алиса'));    /* Добро пожаловать, Алиса! */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

/*
  Переносим обязательный параметр price на 1-е место, а дефолт
  currency = 'RUB' — в конец; добавляем return, иначе вернётся undefined
*/
function createOrderText(price, currency = 'RUB') {
  const label = `${price} ${currency}`;
  return label;
}

function formatGreeting(userName) {
  if (!userName) return 'Привет, гость!';

  /*
    Открывающая скобка ( стоит на той же строке, что и return —
    это запрещает ASI поставить ; сразу после return
  */
  return (
    `Добро пожаловать, ${userName}!`
  );
}

console.log(createOrderText(1500));      /* 1500 RUB */
console.log(createOrderText(1500, '$')); /* 1500 $ */
console.log(formatGreeting('Алиса'));    /* Добро пожаловать, Алиса! */
```

</details>
