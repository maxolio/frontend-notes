# Урок 08. Функции: объявление, область видимости, параметры и return

Суть урока: Функция (Function Declaration) выполняется только в момент вызова name(), имеет локальную область видимости {}, принимает аргументы по порядку (дефолтные параметры ставят последними) и всегда возвращает результат (или undefined без return).

## 1. Объявление функции и область видимости (00:15–06:38)

[+] Любые фигурные скобки {} (функция, цикл или отдельный блок) создают локальную область видимости: изнутри видно внешние переменные, а снаружи внутренние — нет. Локальное имя перекрывает глобальное только внутри своего блока.

```js
const message = 'Глобальный привет';

function logMessage() { /* при объявлении код внутри НЕ выполняется */
  const message = 'Локальный привет'; /* затеняет глобальную только здесь */
  const innerOnly = 'Секрет';
  console.log(message); /* "Локальный привет" */
}

logMessage();         /* запуск кода функции */
/* Hoisting: Function Declaration всплывает и её можно вызывать даже ДО строки объявления! */
console.log(message); /* "Глобальный привет" */
/* console.log(innerOnly); -> ReferenceError: innerOnly is not defined */
```

## 2. Параметры, аргументы и значения по умолчанию (06:39–13:33)

[+] Параметры в (...) при объявлении ведут себя как локальные let-переменные, а при вызове в них по порядку попадают аргументы. Хороший стиль: не менять сам параметр внутри тела и ставить необязательные параметры по умолчанию в конец списка.

```js
function repeatMessage(text = 'Мяу', count = 1) { /* значения по умолчанию */
  for (let i = 0; i < count; i++) {
    console.log(text);
  }
}

repeatMessage('Привет', 3);       /* text = 'Привет', count = 3 */
repeatMessage('Привет');          /* count станет 1 (по умолчанию) */
repeatMessage(undefined, 2);      /* пропуск 1-го аргумента — сработает "Мяу" */
/* Дефолт сработает ТОЛЬКО при undefined (null, 0 и "" его НЕ включают)! */
/* Выражение по умолчанию (напр. text = getTitle()) вычисляется заново в момент вызова! */
```

## 3. Возврат значения (return) и ранний выход (13:34–19:04)

[+] Инструкция return вычисляет выражение, отдаёт его наружу и сразу завершает функцию (код ниже return не сработает). Если return нет или он пустой — вернётся undefined. Удобно для раннего выхода при проверках на старте функции.

```js
function getAgeType(age) {
  if (typeof age !== 'number') return 'Возраст указан некорректно';
  if (age < 1 || age > 125)    return 'Такого возраста не может быть';
  if (age < 18)                return 'Несовершеннолетний';
  return 'Взрослый'; /* сработает, только если все проверки выше не вышли */
}

function getSecretMessage(name) {
  if (!name) return; /* пустой return досрочно вернёт undefined */
  return `Секрет для ${name}`;
}

/* Ловушка ASI: после return перенос строки вернёт undefined! Если переносим итог, */
/* открывающую скобку ставят на той же строке: return ( ... ); */
```

## 3 главные ловушки урока (чек-лист для повторения)

1. Указать параметры по умолчанию в начале списка (придётся передавать undefined для пропуска) или забыть передать нужный аргумент (параметр станет undefined).

2. Забыть return (функция вернёт undefined) или написать инструкции после return (после возврата функция останавливается, и нижний код мёртв).

3. Пытаться прочитать переменную, объявленную внутри {}, снаружи функции, либо перезаписывать входной параметр напрямую вместо новой локальной переменной.

## Вопросы для закрепления

**1. Что выведет функция `greet` при каждом из трёх вызовов и почему не везде сработает `'Гость'`?**

```js
function greet(name = 'Гость') {
  console.log(`Привет, ${name}!`);
}

greet();
greet(null);
greet('');
```

<details>
<summary>Показать ответ</summary>

1. `Привет, Гость!` — аргумент не передан, значит внутри `name === undefined`, и включается значение по умолчанию.
2. `Привет, null!` — параметр по умолчанию срабатывает **строго только при `undefined`**. Переданные `null`, `0`, `false` или `''` считаются полноценными значениями.
3. `Привет, !` — пустая строка `''` тоже отменяет значение по умолчанию.

</details>

**2. Что вернёт `getSum(2, 3)` и сработает ли строка `console.log` внутри функции?**

```js
function getSum(a, b) {
  return
  a + b;
  console.log('Готово');
}
```

<details>
<summary>Показать ответ</summary>

Функция вернёт **`undefined`**, а `console.log('Готово')` никогда не запустится. Из-за переноса строки сразу после `return` движок по правилам ASI автоматически ставит точку с запятой (`return;`) и мгновенно завершает функцию. Чтобы безопасно перенести результат на новую строку, открывающую скобку оставляют на строке с `return`: `return (a + b);`.

</details>

**3. Почему вызов `showTitle()` сработает до строки объявления функции и что окажется в последнем `console.log(title)`?**

```js
const title = 'Внешний';
showTitle();

function showTitle() {
  const title = 'Внутренний';
  console.log(title);
}

console.log(title);
```

<details>
<summary>Показать ответ</summary>

В консоли появится сначала **`'Внутренний'`**, затем **`'Внешний'`**.
1. `Function Declaration` (`function showTitle()`) всплывает в начало области видимости (hoisting), поэтому к ней можно обращаться даже выше её объявления в файле.
2. `const title` внутри `{ ... }` создаёт отдельную локальную переменную, которая лишь временно затеняет внешнюю `title` и не меняет её снаружи.

</details>

## Задачи

**Задача 1. Функция `min(a, b)` с ранним выходом**

Напиши функцию `min(a, b)`, которая возвращает меньшее из двух чисел (если числа равны — любое из них). На старте функции сделай ранний выход: если хотя бы один аргумент не типа `number` или равен `NaN` (`Number.isNaN`), сразу возвращай `null`, а иначе — меньшее число через тернарный оператор `? :`.

```js
'use strict';

/* Твоё решение: */

console.log(min(2, 5));   /* 2 */
console.log(min(3, -1));  /* -1 */
console.log(min(4, 4));   /* 4 */
console.log(min('2', 5)); /* null */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

function min(a, b) {
  /*
    Ранний выход (guard): отсекаем нечисловые аргументы и NaN до расчётов,
    чтобы основная логика функции оставалась плоской и чистой
  */
  if (
    typeof a !== 'number' ||
    typeof b !== 'number' ||
    Number.isNaN(a) ||
    Number.isNaN(b)
  ) {
    return null;
  }

  /* Возвращаем меньшее из двух чисел через тернарный оператор */
  return a < b ? a : b;
}

console.log(min(2, 5));   /* 2 */
console.log(min(3, -1));  /* -1 */
console.log(min(4, 4));   /* 4 */
console.log(min('2', 5)); /* null */
```

</details>

**Задача 2. Функция `pow(x, n)` с параметром по умолчанию и циклом**

Напиши функцию `pow(x, n = 2)`, которая возводит `x` в натуральную степень `n` через цикл `for` (без оператора `**`). Если `n < 1` или `n` дробное (`n % 1 !== 0`), верни `null`. За основу расчёта возьми локальную переменную `let result = 1`.

```js
'use strict';

/* Твоё решение: */

console.log(pow(3));      /* 9 */
console.log(pow(2, 4));   /* 16 */
console.log(pow(5, 0));   /* null */
console.log(pow(2, 1.5)); /* null */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

/* Необязательный параметр по умолчанию n = 2 ставим последним в списке */
function pow(x, n = 2) {
  /* Ранний выход для степени меньше 1 или дробного числа (n % 1 !== 0) */
  if (n < 1 || n % 1 !== 0) return null;

  /* Заводим локальный накопитель, чтобы не перезаписывать входной параметр x */
  let result = 1;

  for (let i = 0; i < n; i++) {
    result *= x;
  }

  return result;
}

console.log(pow(3));      /* 9 (подставилось n = 2 по умолчанию) */
console.log(pow(2, 4));   /* 16 */
console.log(pow(5, 0));   /* null */
console.log(pow(2, 1.5)); /* null */
```

</details>

**Задача 3. Почини порядок параметров, потерянный `return` и перенос строки**

Сейчас `createOrderText` ставит параметр по умолчанию в начало и ничего не возвращает, а `formatGreeting` возвращает `undefined` из-за переноса строки после `return`. Исправь обе функции так, чтобы все три вызова вывели нужные строки.

```js
'use strict';

/* Твоё решение: */
function createOrderText(currency = 'RUB', price) {
  const label = `${price} ${currency}`;
}

function formatGreeting(userName) {
  if (!userName) return 'Привет, гость!';

  return
    `Добро пожаловать, ${userName}!`;
}

console.log(createOrderText(1500));      /* должно быть: 1500 RUB */
console.log(createOrderText(1500, '$')); /* должно быть: 1500 $ */
console.log(formatGreeting('Алиса'));    /* должно быть: Добро пожаловать, Алиса! */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

/*
  Переносим обязательный параметр price на первое место, а параметр по умолчанию
  currency = 'RUB' — в конец; добавляем return, иначе функция отдаст undefined
*/
function createOrderText(price, currency = 'RUB') {
  const label = `${price} ${currency}`;
  return label;
}

function formatGreeting(userName) {
  if (!userName) return 'Привет, гость!';

  /*
    Открывающая скобка ( стоит на той же строке, что и return —
    это запрещает ASI поставить ; сразу после return
  */
  return (
    `Добро пожаловать, ${userName}!`
  );
}

console.log(createOrderText(1500));      /* 1500 RUB */
console.log(createOrderText(1500, '$')); /* 1500 $ */
console.log(formatGreeting('Алиса'));    /* Добро пожаловать, Алиса! */
```

</details>
