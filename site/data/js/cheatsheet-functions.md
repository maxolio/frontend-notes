# Шпаргалка. Как проектировать и читать функции (HtDF + CQS)

## Краткая шпаргалка

### 1. Как написать функцию (4 шага из условия)
- **Шаг 1. Что понимаем из условия (Роль + Контракт):**
  - **1.1. Роль (CQS) — функция отвечает на вопрос или делает дело?** *(если нужно и посчитать, и вывести — делай 2 функции)*
    - **Запрос** *(«Сколько? / Какой? / Да или нет?» — отдаёт `return`, ничего не меняет, без `console.log`)*:
      - **Вычислитель** (`calc`, `get`, `count`, `format`) -> число, текст, `null`.
      - **Проверка** (`is`, `has`, `can`, `check`) -> строго `true` или `false`.
      - **Фабрика** (`create`, `make`) -> новая функция или объект.
    - **Команда** *(«Покажи! / Измени! / Запусти!» — делает действие, возвращает `undefined`)*:
      - **Вывод** (`show`, `hide`, `log`) -> консоль, `alert`, экран.
      - **Изменение** (`set`, `add`, `update`, `delete`, `clear`) -> меняет или чистит данные.
      - **Оркестратор** (`run`, `process`, `ask`) -> запускает процесс и колбэки.
  - **1.2. Контракт — краткая запись `/* Роль: имя(вход) -> выход */`:**
    - **Обозначения:** до стрелки `(...)` — типы входа; `?` — необязательный с дефолтом `=`; `|` — «ИЛИ».
    - `/* Запрос: calcSum(number, number) -> number */` — обычный расчёт.
    - `/* Запрос: calcPrice(number, number?) -> number | null */` — с дефолтом `?` и ошибкой `null`.
    - `/* Запрос: isAdult(number) -> boolean */` — проверка (`true` / `false`).
    - `/* Запрос: createTag(string) -> function */` — фабрика (возвращает функцию).
    - `/* Команда: showResult(string) -> undefined */` — вывод без `return`.
    - `/* Команда: runTask(number, function, function?) -> undefined */` — оркестратор с колбэками.
- **Шаг 2. Примеры (пишем до логики, чтобы проверить контракт):**
  - **2.1. Рабочие вызовы (2 шт.):**
    - Обычный вызов: `calcPrice(1000) -> 900` *(работает с дефолтом)*.
    - С явными аргументами: `calcPrice(1000, 0.2) -> 800`.
  - **2.2. Плохие и граничные вызовы (1–2 шт.):**
    - Неверный тип / `NaN`: `calcPrice('1000') -> null` или `calcPrice(NaN) -> null`.
    - Граница диапазона (`0`, минус, `''`, `null`): `calcPrice(-100) -> null`.
  - **2.3. Проверка в коде:** сразу запиши их внизу через `console.log(calcPrice(1000)); /* 900 */`, чтобы прогнать после написания тела.
- **Шаг 3. Имя и порядок параметров:**
  - **3.1. Имя = Глагол + Суть** *(выбирай глагол под роль из `1.1`)*:
    - **Запрос:** `calc` *(посчитать)*, `get` *(получить)*, `count` *(подсчитать)*, `format` *(отформатировать)*; `is` *(является ли)*, `has` *(имеет ли)*, `can` *(может ли)*, `check` *(проверить)*; `create` *(создать)*, `make` *(сделать)*.
    - **Команда:** `show` *(показать)*, `hide` *(скрыть)*, `log` *(вывести в лог)*; `set` *(установить)*, `add` *(добавить)*, `update` *(обновить)*, `delete` *(удалить)*, `clear` *(очистить)*; `run` *(запустить)*, `process` *(обработать)*, `ask` *(спросить)*.
  - **3.2. Порядок в `(...)` (когда параметров `2+`):**
    1. Обязательные данные (`sum`, `text`).
    2. Обязательные колбэки (`onOk`).
    3. Необязательные параметры и колбэки с дефолтом `=` — **строго в конце** (`discount = 0.1`, `onErr = () => {}`).
    - *Правило `=`:* дефолт срабатывает только при пропуске аргумента или `undefined` (не при `null` и `''`).
  - **3.3. Готовая шапка:** `function calcPrice(sum, discount = 0.1) { ... }` или `function runTask(sum, onOk, onErr = () => {}) { ... }`.
- **Шаг 4. 3 этажа тела:**
  - **4.1. Этаж 1 (Защита):** отсеки плохие данные ранним `return` по типу входа (см. раздел 3).
  - **4.2. Этаж 2 (Логика):** выполни 1 главное дело (расчёт, цикл, проверка).
  - **4.3. Этаж 3 (Выход):** верни результат через `return` (для Запроса) или заверши действие (для Команды).

### 2. Как прочитать чужую функцию (за 15 секунд, зеркально разделу 1)
- **Шаг 1. Посмотри на Имя + `return` (Определи Роль из `1.1`):**
  - **1.1. Запрос:** имя `calc / get / count / format / is / has / create` и есть `return значение` *(только считает, проверяет или создаёт)*.
  - **1.2. Команда:** имя `show / hide / log / set / add / clear / run / ask` и делает действие без `return` (`undefined`).
  - **1.3. Красный флаг:** если имя `get...` / `calc...`, а внутри `console.log` без `return` (или меняет внешнюю переменную) — роли смешаны, в функции баг проектирования.
- **Шаг 2. Посмотри на скобки `(...)` (Собери Вход из `1.2` и `3.2`):**
  - **2.1. Обязательные (без `=`):** какие данные и колбэки нужно передать обязательно.
  - **2.2. Необязательные (с `=` в конце):** что можно пропустить при вызове.
- **Шаг 3. Пройди 3 этажа сверху вниз (Разбери тело из `4`):**
  - **3.1. Защита (верх):** что отсекает ранним `return` (`!Number.isFinite`, `typeof`, границы, `null`)?
  - **3.2. Логика (середина):** какое 1 главное дело делает (формула, цикл, ветвление, запуск колбэка)?
  - **3.3. Выход (низ):** что отдаёт через `return` (правая часть контракта `-> Выход`) или чем завершает действие?
- **Шаг 4. Собери паспорт в 1 строку (Контракт + смысл):**
  - Проговори про себя формулу: `/* Роль: имя(вход) -> выход */` — например: *«Запрос `calcPrice(number, number?) -> number | null`: берёт цену и необязательную скидку, отсекает нечисла, возвращает итог или `null`»*.

---

### 3. Защита входящих данных
> Проверяй на границе ввода (`prompt`, `<input>`, внешний вызов), а внутри доверяй контракту.

- **3.1. Пусто `fn()`:** защита не нужна.
- **3.2. Число:** `if (!Number.isFinite(n) || n <= 0) return null;` — ловит `NaN`, `Infinity` и строки.
- **3.3. Строка:** `if (typeof s !== 'string' || s.trim() === '') return '';` — `typeof` строго до `.trim()`, иначе `TypeError` на `null`.
- **3.4. Флаг (`boolean`):** `(isFlag = false)` и `isFlag === true` — иначе строка `'false'` станет `true`.
- **3.5. Колбэк:** `if (typeof cb !== 'function') return;` — снаружи передаём без `()`, внутри зовём с `()`.
- **3.6. Массив / объект** *(на вырост)*: `!Array.isArray(arr)` или `typeof obj !== 'object' || obj === null || Array.isArray(obj)` — передаются по ссылке, `typeof null === 'object'`.

### 4. Код-трафарет (вся методика в 7 строках)
```js
/* Запрос: calcResult(number) -> number | null */
function calcResult(value) {
  if (!Number.isFinite(value)) return null; /* 1. Защита */
  return value * 2;                         /* 2–3. Логика и Выход */
}
/* Команда: только вывод */
const showResult = (res) => console.log(res ?? 'Ошибка');
showResult(calcResult(50));
```

### 5. Главное правило: Запрос или Команда
- **Если Запрос** (`return значение`, ничего не меняет снаружи):
  - **Вычислитель** (число, строка, `null`): `calc` *(посчитать)*, `get` *(получить)*, `count` *(подсчитать)*, `format` *(отформатировать)*.
  - **Проверка** (строго `true` / `false`): `is` *(является ли)*, `has` *(имеет ли)*, `can` *(может ли)*, `check` *(проверить)*.
  - **Фабрика** (новая функция или объект): `create` *(создать)*, `make` *(сделать)*.
- **Если Команда** (делает действие, возвращает `undefined`):
  - **Вывод** (консоль, `alert`, экран): `show` *(показать)*, `hide` *(скрыть)*, `log` *(вывести в лог)*.
  - **Изменение** (меняет/чистит данные): `set` *(установить)*, `add` *(добавить)*, `update` *(обновить)*, `delete` *(удалить)*, `clear` *(очистить)*.
  - **Оркестратор** (запускает процесс и колбэки): `run` *(запустить)*, `process` *(обработать)*, `ask` *(спросить)*.
- **Контроль:** имя `get...`, а внутри `console.log` без `return` -> ошибка (не смешивай роли).

```js
/* ЗАПРОСЫ: всегда возвращают значение через return */

/* Вычислители */
const calcTotal = (price, qty) => price * qty;
const getDiscount = (isVip) => (isVip ? 0.2 : 0.05);
const countPositive = (a, b) => (a > 0 ? 1 : 0) + (b > 0 ? 1 : 0);
const formatPrice = (sum) => `${sum} руб.`;

/* Проверки (строго true / false) */
const isAdult = (age) => age >= 18;
const hasPromo = (code) => code === 'SALE20';
const canBuy = (balance, price) => balance >= price;
const checkPin = (pin) => pin === '1234';

/* Фабрики */
const createGreeter = (word) => (name) => `${word}, ${name}!`;
const makeUser = (name) => ({ name, role: 'user' });

/* КОМАНДЫ: делают действие, возвращают undefined */

/* Вывод */
const showMessage = (text) => { console.log(text); };
const hideBanner = () => { console.log('Баннер скрыт'); };
const logError = (err) => { console.log(`Ошибка: ${err}`); };

/* Изменение */
let score = 0;
const setScore = (val) => { score = val; };
const addScore = (pts) => { score += pts; };
const updateScore = (val) => { score = val * 2; };
const deleteUser = (id) => { console.log(`Удалён #${id}`); };
const clearScore = () => { score = 0; };

/* Оркестраторы */
const runTask = (taskFn) => { taskFn(); };
const processPay = (sum, onOk) => { if (sum > 0) onOk(sum); };
const askConfirm = (q, onYes) => { if (q) onYes(); };
```

Суть урока:

- **Пишем (4 шага):** Контракт -> Примеры -> Имя -> 3 этажа (`Защита -> Логика -> Выход`).
- **Читаем (Запрос или Команда):** если **Запрос** -> отдаёт `return`; если **Команда** -> делает действие (без `return`).
- **Защита по входу:** тип аргумента диктует первую строку (`Number.isFinite`, `typeof === 'string'`).

## 1. Как написать свою функцию (4 шага)

**На какой вопрос отвечает:** **КАК написать** функцию с нуля из условия задачи.

1. **Контракт и роль (CQS):** определи **Запрос** (*«Сколько/Какой?»* -> `return`) или **Команда** (*«Сделай/Покажи!»* -> `undefined`), и запиши `(Вход) -> Выход` *(где `?` — необязательный, `|` — «ИЛИ»)*.
2. **Примеры (до кода):** 2 рабочих и 1 плохой вызов (`calcPrice(1000) -> 900`, `calcPrice('abc') -> null`).
3. **Имя и параметры:** выбери глагол под роль (`calc`, `show`, `is`), обязательные ставь в начало, все дефолты `=` — в конец.
4. **3 этажа тела:** `Защита (ранний return)` -> `Логика (1 дело)` -> `Выход (return)`.

```js
/* Запрос: calcPrice(number, number?) -> number | null */
function calcPrice(price, discount = 0.1) {
  if (!Number.isFinite(price) || price <= 0) return null; /* 1. Защита */
  const total = price * (1 - discount);                   /* 2. Логика */
  return total;                                           /* 3. Выход */
}

/*
  Разбор по 4 шагам:
  1. Контракт: на вход ждём обязательное число price и необязательную скидку (?), на выход — число или null (|).
  2. Примеры: calcPrice(1000) -> 900, calcPrice(1000, 0.2) -> 800, calcPrice('abc') -> null.
  3. Имя и параметры: calcPrice — Запрос (считает без console.log), обязательное price в начале, дефолт discount = 0.1 в конце.
  4. 3 этажа: Защита отсекает не-числа и <= 0; Логика умножает цену на (1 - discount); Выход возвращает total.
*/
```

## 2. Как прочитать чужую функцию за 15 секунд

**На какой вопрос отвечает:** **ЧТО делает** чужая функция.

1. **Имя + `return` (Роль CQS):**
   - **Если это Запрос** (`calc`, `get`, `count`, `format`, `is`, `create`) -> функция только считает/проверяет и возвращает результат через `return значение` *(без `console.log` внутри)*.
   - **Если это Команда** (`show`, `log`, `clear`, `run`, `ask`) -> функция только делает действие (`console.log`, меняет страницу) и ничего не возвращает (`undefined`).
   - **Красный флаг:** имя `get...`, а внутри `console.log` без `return` -> роли смешаны, это ошибка.
2. **Скобки `(...)`:** какие типы на входе обязательны, а какие идут в конце с дефолтом `=`.
3. **3 этажа внутри:** где защита, какое главное действие и что уходит в `return`.

```js
/* Запрос: formatDiscount(number, number?) -> string */
function formatDiscount(price, percent = 10) {
  if (!Number.isFinite(price) || price <= 0) return 'Ошибка цены'; /* 1. Защита */
  const discount = price * (percent / 100);                        /* 2. Логика */
  return `Скидка: ${discount} руб.`;                               /* 3. Выход */
}

/*
  Разбор за 15 секунд:
  1. Имя + return: format... + в конце return со строкой -> честный Запрос (только считает).
  2. Скобки (...): ждёт обязательное число price и необязательное percent (по умолчанию 10).
  3. 3 этажа: Защита проверяет price (но забыли проверить percent!); Логика считает скидку; Выход возвращает строку.
*/
```

## 3. Защита входящих данных: справочник по типам

**На какой вопрос отвечает:** **ЧТО ПРОВЕРИТЬ** первой строкой внутри, чтобы функция не сломалась на плохих данных.

> **Главное правило границы ввода:** ставь проверки на границе (`prompt`, `<input>`, внешний вызов), а внутри вспомогательных функций доверяй контракту.

### 3.1. Ничего не ждёт — `fn()`
- **Роль:** **команда** (`showMenu()`, `clearCart()`) или **поставщик данных** (`getPi()`, `getAdminGreeting()`).
- **Первая строка (защита):** не нужна.
- **Что внутри:** либо сразу делает 1 действие (`undefined`), либо вычисляет и отдаёт значение через `return`.

```js
/* Команда: showMenu() -> undefined */
function showMenu() {
  console.log('1. Каталог  2. Корзина');
}
```

### 3.2. Ждёт число — `fn(num)`
- **Роль:** математика, цены, скидки, счётчики, циклы (`calcBonus(sum)`, `pow(x, n)`).
- **Первая строка (защита):** `if (!Number.isFinite(num)) return null;` *(плюс границы вроде `num <= 0`, если отрицательные нельзя)*.
- **Ловушка:** `typeof num !== 'number'` пропускает `NaN` и `Infinity` — поэтому надёжнее `Number.isFinite(num)`.

```js
/* Запрос: calcBonus(number) -> number | null */
function calcBonus(sum) {
  if (!Number.isFinite(sum) || sum <= 0) return null; /* 1. Защита */
  return sum * 0.1;                                   /* 2–3. Логика и Выход */
}
```

### 3.3. Ждёт строку — `fn(str)`
- **Роль:** форматирование текста, имён, поиск (`formatGreeting(userName)`).
- **Первая строка (защита):** `if (typeof str !== 'string' || str.trim() === '') return ...;` *(или дефолт `str = 'Гость'`, если параметр необязательный)*.
- **Ловушка:** проверка `typeof str !== 'string'` обязана идти **первой** — иначе `.trim()` на `null` или числе уронит код с `TypeError`.

```js
/* Запрос: formatGreeting(string) -> string */
function formatGreeting(userName) {
  if (typeof userName !== 'string' || userName.trim() === '') return 'Привет, Гость!'; /* 1. Защита */
  return `Привет, ${userName.trim()}!`;                                                 /* 2–3. Логика и Выход */
}
```

### 3.4. Ждёт `boolean` — `fn(isFlag)`
- **Роль:** развилка, переключатель режима или фабрика (`createGreeting(isAdmin)`).
- **Подсказка по имени:** параметр почти всегда начинается с `is...`, `has...`, `can...`.
- **Первая строка (защита):** обычно хватает дефолта `(isAdmin = false)` или строгой проверки `isAdmin === true`.
- **Ловушка:** непустая строка `'false'` внутри `if (isFlag)` станет `true`. А 2+ флага подряд (`fn(true, false)`) путают при чтении — на вырост их заменяют объектом настроек.

```js
/* Запрос: getAccessText(boolean?) -> string */
function getAccessText(isAdmin = false) {
  return isAdmin === true ? 'Панель админа' : 'Личный кабинет'; /* 2–3. Логика и Выход */
}
```

### 3.5. Ждёт функцию (колбэк) — `fn(callback)`
- **Роль:** универсальный оркестратор (`ask(q, yes, no)`, `processPayment(sum, ok, err)`).
- **Первая строка (защита):** для необязательного колбэка — пустышка `callback = () => {}`; для жёсткой защиты — `if (typeof callback !== 'function') return;`.
- **Главное правило:** снаружи передаём **без `()`**, а внутри запускаем **со скобками `()`** (пустыми или передавая результат `callback(result)`).

```js
/* Оркестратор: runAction(function?) -> undefined */
function runAction(onDone = () => {}) {
  if (typeof onDone !== 'function') return; /* 1. Защита */
  console.log('Готово');                    /* 2. Логика */
  onDone();                                 /* 3. Запуск колбэка */
}
```

### 3.6. Ждёт массив или объект — `fn(arr)` / `fn(obj)` *(На вырост: Блок 2–3)*
- **Роль:** работа с группой данных (корзина товаров, карточка пользователя).
- **Первая строка (защита):** для массива — `if (!Array.isArray(arr)) return ...;`; для обычного объекта — `if (typeof obj !== 'object' || obj === null || Array.isArray(obj)) return ...;` *(плюс `obj?.prop` при чтении)*.
- **Ловушка:** массивы и объекты передаются **по ссылке** — изменив их внутри функции, ты изменишь исходные данные снаружи. В JS `typeof null === 'object'` и `typeof [] === 'object'`, поэтому без `!== null` и `!Array.isArray(obj)` защита пропустит и `null`, и массив.

```js
/* Запрос: getUserName(object) -> string */
function getUserName(user) {
  if (typeof user !== 'object' || user === null || Array.isArray(user)) return 'Гость'; /* 1. Защита */
  return user?.name ?? 'Гость';                                                          /* 2–3. Логика и Выход */
}
```

## 4. Порядок параметров и роли по имени (Запрос или Команда)

**На какой вопрос отвечает:** **КАК НАЗВАТЬ** функцию и в каком порядке расставить параметры в `(...)`.

### Порядок параметров (когда их 2 и больше)
- **1-е место:** главные обязательные данные (`amount`, `text`).
- **2-е место:** обязательные колбэки (`onSuccess`), если функция без них не имеет смысла.
- **3-е место (в самом конце):** все необязательные настройки, флаги и колбэки с дефолтом (`rate = 0.1`, `isAdmin = false`, `onError = () => {}`).
- **Правило дефолтов:** параметры с `=` всегда идут **после** обязательных, иначе придётся передавать `undefined` для пропуска. *(Дефолт `=` срабатывает только при `undefined`, но не при `null` или `''`.)*

```js
/* Оркестратор: processOrder(number, function, number?, function?) -> undefined */
function processOrder(amount, onSuccess, discount = 0.1, onError = () => {}) {
  if (!Number.isFinite(amount) || amount <= 0) { /* 1. Защита */
    onError();
    return;
  }
  const total = amount * (1 - discount);         /* 2. Логика */
  onSuccess(total);                              /* 3. Запуск колбэка */
}

/*
  Разбор порядка параметров:
  1. amount — обязательные данные на 1-м месте.
  2. onSuccess — обязательный колбэк на 2-м месте (без него заказ не завершить).
  3. discount = 0.1 и onError = () => {} — всё необязательное с "=" в самом конце.
*/
```

### Имя заранее задаёт роль и выход (Запрос или Команда)

**Если ЗАПРОС** (отдаёт `return значение`, ничего не меняет снаружи):
- **Вычислитель** (число, строка, `null`): `calc...` *(посчитать)*, `get...` *(получить)*, `count...` *(подсчитать)*, `format...` *(отформатировать)*.
- **Проверка** (всегда `true` или `false`): `is...` *(является ли)*, `has...` *(имеет ли)*, `can...` *(может ли)*, `check...` *(проверить)*.
- **Фабрика** (новая функция или объект): `create...` *(создать)*, `make...` *(сделать)*.

**Если КОМАНДА** (делает действие, возвращает `undefined`):
- **Вывод** (консоль, `alert`, экран): `show...` *(показать)*, `hide...` *(скрыть)*, `log...` *(вывести в лог)*.
- **Изменение** (меняет или очищает данные): `set...` *(установить)*, `add...` *(добавить)*, `update...` *(обновить)*, `delete...` *(удалить)*, `clear...` *(очистить)*.
- **Оркестратор** (запускает процесс и колбэки): `run...` *(запустить)*, `process...` *(обработать)*, `ask...` *(спросить)*.

```js
/* ЗАПРОСЫ (возвращают значение через return) */
const calcSum = (a, b) => a + b;
const isAdult = (age) => age >= 18;
const createGreeter = (prefix) => (name) => `${prefix}, ${name}!`;

/* КОМАНДЫ (делают действие, возвращают undefined) */
const showLog = (msg) => { console.log(msg); };
const clearCart = () => { console.log('Корзина очищена'); };
const runTask = (taskFn) => { taskFn(); };
```

## Главная закономерность (1 правило на всё)

> **Контракт задаёт рамку, вход диктует защиту, а роль (Запрос или Команда) — выход.**

```js
'use strict';

/* Запрос: calcResult(number) -> number | null */
function calcResult(value) {
  if (!Number.isFinite(value)) return null;
  const result = value * 2;
  return result;
}

/* Команда: showResult(string, number | null) -> undefined */
function showResult(label, amount) {
  if (amount === null) {
    console.log(`${label}: некорректный ввод`);
    return;
  }
  console.log(`${label}: ${amount}`);
}

showResult('Успех', calcResult(50));
showResult('Ошибка', calcResult('50'));

/*
  3 правила на всё:
  1. Создаёшь: Контракт -> Примеры -> Защита -> Логика -> Выход.
  2. Читаешь: если Запрос -> return значение; если Команда -> действие без return; затем Вход и 3 этажа.
  3. Не смешивай: calc только считает, show только выводит.
*/
```
