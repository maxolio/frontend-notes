# Шпаргалка. Как проектировать и читать функции (HtDF + CQS)

Суть урока:

- **Пишем (4 шага):** Контракт -> Примеры -> Имя -> 3 этажа (`Защита -> Логика -> Выход`).
- **Читаем (Запрос или Команда):** если **Запрос** -> отдаёт `return`; если **Команда** -> делает действие (без `return`).
- **Защита по входу:** тип аргумента диктует первую строку (`Number.isFinite`, `typeof === 'string'`).

## Краткая шпаргалка

### 1. Главное правило: Запрос или Команда
- **Если Запрос** (`return значение`, ничего не меняет снаружи):
  - `calc / get / format` -> **Вычислитель** (число, строка, `null`).
  - `is / has / can / check` -> **Проверка** (строго `true` / `false`).
  - `create / make` -> **Фабрика** (новая функция или объект).
- **Если Команда** (делает действие, возвращает `undefined`):
  - `show / hide / log` -> **Вывод** (консоль, `alert`, экран).
  - `set / add / update / delete / clear` -> **Изменение** (меняет/чистит данные).
  - `run / process / ask` -> **Оркестратор** (запускает процесс и колбэки).
- **Контроль:** имя `get...`, а внутри `console.log` без `return` -> ошибка (не смешивай роли).

### 2. Как написать функцию (4 шага)
1. **Контракт:** `(Вход) -> Выход` (`(number, number?) -> number | null`).
2. **Примеры:** 2 рабочих + 1 плохой (`calc(1000) -> 900`, `calc('abc') -> null`).
3. **Имя и параметры:** порядок в `(...)` — **обязательные -> обязательные колбэки -> все `=` в конце** *(дефолт `=` срабатывает только при `undefined`, не при `null`/`''`)*.
4. **3 этажа тела:** `Защита (ранний return)` -> `Логика (1 дело)` -> `Выход (return)`.

### 3. Как прочитать чужую функцию (3 шага)
1. **Роль:** Запрос (`return значение`) или Команда (действие, `undefined`)?
2. **Вход `(...)`:** какие типы ждёт и какие параметры с `=`?
3. **3 этажа:** где защита, какое главное действие и что на выходе?

### 4. Первая строка защиты по типу входа
- **Пусто `fn()`:** защита не нужна.
- **Число:** `if (!Number.isFinite(n) || n <= 0) return null;` *(ловит `NaN` и `Infinity`)*.
- **Строка:** `if (typeof s !== 'string' || s.trim() === '') return '';` *(`typeof` строго до `.trim()`)*.
- **Флаг (`boolean`):** `(isFlag = false)` и `isFlag === true` *(чтобы `'false'` не стал `true`)*.
- **Колбэк:** `(cb = () => {})` или `if (typeof cb !== 'function') return;` *(передаём без `()`, вызываем с `()`)*.
- **Массив / объект *(на вырост)*:** `!Array.isArray(arr)` / `typeof obj !== 'object' || obj === null || Array.isArray(obj)` *(передаются по ссылке)*.

### 5. Код-трафарет (вся методика в 7 строках)
```js
/* Запрос: calcResult(number) -> number | null */
function calcResult(value) {
  if (!Number.isFinite(value)) return null; /* 1. Защита */
  return value * 2;                         /* 2–3. Логика и Выход */
}
/* Команда: только вывод */
const showResult = (res) => console.log(res ?? 'Ошибка');
showResult(calcResult(50));
```

## 1. Как написать свою функцию (4 шага)

**На какой вопрос отвечает:** **КАК написать** функцию с нуля.

1. **Контракт:** что на входе -> что на выходе (`number, number -> number | null`).
2. **Примеры:** 2 рабочих и 1 плохой (`calcPrice(1000) -> 900`, `calcPrice('abc') -> null`).
3. **Имя и параметры:** выбери глагол под роль (`calc`, `show`, `is`), дефолты `=` ставь в конец.
4. **3 этажа тела:** `Защита (ранний return)` -> `Логика (1 дело)` -> `Выход (return)`.

```js
function calcPrice(price, discount = 0.1) {
  if (!Number.isFinite(price) || price <= 0) return null;
  const total = price * (1 - discount);
  return total;
}

/*
  Разбор по 4 шагам:
  1. Контракт: на вход ждём два числа (price и необязательную скидку), на выход — число или null.
  2. Примеры: calcPrice(1000) -> 900, calcPrice(1000, 0.2) -> 800, calcPrice('abc') -> null.
  3. Имя и параметры: calcPrice — Запрос (считает без console.log), обязательное price в начале, дефолт discount = 0.1 в конце.
  4. 3 этажа: Защита отсекает не-числа и <= 0; Логика умножает цену на (1 - discount); Выход возвращает total.
*/
```

## 2. Как прочитать чужую функцию за 15 секунд

**На какой вопрос отвечает:** **ЧТО делает** чужая функция.

1. **Запрос или Команда (Имя + `return`):**
   - **Если это Запрос** (`calc`, `get`, `format`, `is`, `create`) -> функция только считает/проверяет и возвращает результат через `return значение` *(без `console.log` внутри)*.
   - **Если это Команда** (`show`, `log`, `clear`, `run`) -> функция только делает действие (`console.log`, меняет страницу) и ничего не возвращает (`undefined`).
   - **Если имя и тело не совпадают** (имя `get...`, а внутри `console.log` без `return`) -> это ошибка: либо переименуй функцию, либо верни значение через `return`.
2. **Скобки `(...)`:** какие типы на входе и что необязательно (`=`).
3. **3 этажа внутри:** где защита, какое главное действие и что уходит в `return`.

```js
function formatDiscount(price, percent = 10) {
  if (!Number.isFinite(price) || price <= 0) return 'Ошибка цены';
  const discount = price * (percent / 100);
  return `Скидка: ${discount} руб.`;
}

/*
  Разбор за 15 секунд:
  1. Запрос или Команда: имя format... + в конце return со строкой -> честный Запрос (только считает).
  2. Скобки (...): ждёт обязательное число price и необязательное percent (по умолчанию 10).
  3. 3 этажа: Защита проверяет price (но забыли проверить percent!); Логика считает скидку; Выход возвращает строку.
*/
```

## 3. Справочник по входу: какая защита нужна под каждый тип

**На какой вопрос отвечает:** **ЧТО ПРОВЕРИТЬ** первой строкой внутри, чтобы функция не сломалась на плохих данных.

### 3.1. Ничего не ждёт — `fn()`
- **Роль:** **команда** (`showMenu()`, `clearCart()`) или **поставщик данных** (`getPi()`, `getAdminGreeting()`).
- **Первая строка (защита):** не нужна.
- **Что внутри:** либо сразу делает 1 действие (`undefined`), либо вычисляет и отдаёт значение через `return`.

```js
/* Команда: showMenu() -> undefined */
function showMenu() {
  console.log('1. Каталог  2. Корзина');
}
```

### 3.2. Ждёт число — `fn(num)`
- **Роль:** математика, цены, скидки, счётчики, циклы (`calcBonus(sum)`, `pow(x, n)`).
- **Первая строка (защита):** `if (!Number.isFinite(num)) return null;` *(плюс границы вроде `num <= 0`, если отрицательные нельзя)*.
- **Ловушка:** `typeof num !== 'number'` пропускает `NaN` и `Infinity` — поэтому надёжнее `Number.isFinite(num)`. Ставь проверки на границах ввода (`prompt`, `<input>`), а не в каждой 1-строчной функции.

```js
/* Запрос: calcBonus(number) -> number | null */
function calcBonus(sum) {
  if (!Number.isFinite(sum) || sum <= 0) return null;
  return sum * 0.1;
}
```

### 3.3. Ждёт строку — `fn(str)`
- **Роль:** форматирование текста, имён, поиск (`formatGreeting(userName)`).
- **Первая строка (защита):** `if (typeof str !== 'string' || str.trim() === '') return ...;` *(или дефолт `str = 'Гость'`, если параметр необязательный)*.
- **Ловушка:** проверка `typeof str !== 'string'` обязана идти **первой** — иначе `.trim()` на `null` или числе уронит код с `TypeError`.

```js
/* Запрос: formatGreeting(string) -> string */
function formatGreeting(userName) {
  if (typeof userName !== 'string' || userName.trim() === '') return 'Привет, Гость!';
  return `Привет, ${userName.trim()}!`;
}
```

### 3.4. Ждёт `boolean` — `fn(isFlag)`
- **Роль:** развилка, переключатель режима или фабрика (`createGreeting(isAdmin)`).
- **Подсказка по имени:** параметр почти всегда начинается с `is...`, `has...`, `can...`.
- **Первая строка (защита):** обычно хватает дефолта `(isAdmin = false)` или строгой проверки `isAdmin === true`.
- **Ловушка:** непустая строка `'false'` внутри `if (isFlag)` станет `true`. А 2+ флага подряд (`fn(true, false)`) путают при чтении — на вырост их заменяют объектом настроек.

```js
/* Запрос: getAccessText(boolean?) -> string */
function getAccessText(isAdmin = false) {
  return isAdmin === true ? 'Панель админа' : 'Личный кабинет';
}
```

### 3.5. Ждёт функцию (колбэк) — `fn(callback)`
- **Роль:** универсальный оркестратор (`ask(q, yes, no)`, `processPayment(sum, ok, err)`).
- **Первая строка (защита):** для необязательного колбэка — пустышка `callback = () => {}`; для жёсткой защиты — `if (typeof callback !== 'function') return;`.
- **Главное правило:** снаружи передаём **без `()`**, а внутри запускаем **со скобками `()`** (пустыми или передавая результат `callback(result)`).

```js
/* Оркестратор: runAction(function?) -> undefined */
function runAction(onDone = () => {}) {
  if (typeof onDone !== 'function') return;
  console.log('Готово');
  onDone();
}
```

### 3.6. Ждёт массив или объект — `fn(arr)` / `fn(obj)` *(На вырост: Блок 2–3)*
- **Роль:** работа с группой данных (корзина товаров, карточка пользователя).
- **Первая строка (защита):** для массива — `if (!Array.isArray(arr)) return ...;`; для обычного объекта — `if (typeof obj !== 'object' || obj === null || Array.isArray(obj)) return ...;` *(плюс `obj?.prop` при чтении)*.
- **Ловушка:** массивы и объекты передаются **по ссылке** — изменив их внутри функции, ты изменишь исходные данные снаружи. В JS `typeof null === 'object'` и `typeof [] === 'object'`, поэтому без `!== null` и `!Array.isArray(obj)` защита пропустит и `null`, и массив.

```js
/* Запрос: getUserName(object) -> string */
function getUserName(user) {
  if (typeof user !== 'object' || user === null || Array.isArray(user)) return 'Гость';
  return user?.name ?? 'Гость';
}
```

## 4. Порядок параметров и 5 ролей по имени

**На какой вопрос отвечает:** **КАК НАЗВАТЬ** функцию и в каком порядке расставить параметры в `(...)`.

### Порядок параметров (когда их 2 и больше)
- **1-е место:** главные обязательные данные (`amount`, `text`).
- **2-е место:** обязательные колбэки (`onSuccess`), если функция без них не имеет смысла.
- **3-е место (в самом конце):** все необязательные настройки, флаги и колбэки с дефолтом (`rate = 0.1`, `isAdmin = false`, `onError = () => {}`).
- **Правило дефолтов:** параметры с `=` всегда идут **после** обязательных, иначе придётся передавать `undefined` для пропуска. *(Дефолт `=` срабатывает только при `undefined`, но не при `null` или `''`.)*

```js
function processOrder(amount, onSuccess, discount = 0.1, onError = () => {}) {
  if (!Number.isFinite(amount) || amount <= 0) {
    onError();
    return;
  }
  const total = amount * (1 - discount);
  onSuccess(total);
}

/*
  Разбор порядка параметров:
  1. amount — обязательные данные на 1-м месте.
  2. onSuccess — обязательный колбэк на 2-м месте (без него заказ не завершить).
  3. discount = 0.1 и onError = () => {} — всё необязательное с "=" в самом конце.
*/
```

### Имя заранее задаёт роль и выход (Запрос или Команда)

**Если ЗАПРОС** (отдаёт `return значение`, ничего не меняет снаружи):
- `calc...`, `get...`, `format...` -> **Вычислитель** (возвращает число, строку или `null`).
- `is...`, `has...`, `can...`, `check...` -> **Проверка** (всегда `true` или `false`).
- `create...`, `make...` -> **Фабрика** (возвращает новую функцию или объект).

**Если КОМАНДА** (делает действие, возвращает `undefined`):
- `show...`, `hide...`, `log...` -> **Вывод** (консоль, `alert`, показ/скрытие блока).
- `set...`, `add...`, `update...`, `delete...`, `clear...` -> **Изменение** (меняет или очищает данные).
- `run...`, `process...`, `ask...` -> **Оркестратор** (запускает процесс и вызывает колбэки).

```js
/* ЗАПРОСЫ (возвращают значение через return) */
const calcSum = (a, b) => a + b;
const isAdult = (age) => age >= 18;
const createGreeter = (prefix) => (name) => `${prefix}, ${name}!`;

/* КОМАНДЫ (делают действие, возвращают undefined) */
const showLog = (msg) => { console.log(msg); };
const clearCart = () => { console.log('Корзина очищена'); };
const runTask = (taskFn) => { taskFn(); };
```

## Главная закономерность (1 правило на всё)

> **Контракт задаёт рамку, вход диктует защиту, а роль (Запрос или Команда) — выход.**

```js
'use strict';

/* Запрос: calcResult(number) -> number | null */
function calcResult(value) {
  if (!Number.isFinite(value)) return null;
  const result = value * 2;
  return result;
}

/* Команда: showResult(string, number | null) -> undefined */
function showResult(label, amount) {
  if (amount === null) {
    console.log(`${label}: некорректный ввод`);
    return;
  }
  console.log(`${label}: ${amount}`);
}

showResult('Успех', calcResult(50));
showResult('Ошибка', calcResult('50'));

/*
  3 правила на всё:
  1. Создаёшь: Контракт -> Примеры -> Защита -> Логика -> Выход.
  2. Читаешь: если Запрос -> return значение; если Команда -> действие без return; затем Вход и 3 этажа.
  3. Не смешивай: calc только считает, show только выводит.
*/
```
