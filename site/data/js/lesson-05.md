# Урок 05. Условия if/else, тернарный оператор, логические операторы и ??

Суть урока: if/else выбирает ветку кода, тернарный ? : записывает выбор в const; операторы || и && не превращают результат в true/false, а возвращают сам операнд (у && приоритет выше ||), а ?? реагирует только на null и undefined (сохраняя 0 и "").

## 1. Конструкция if / else if / else и тернарный оператор (00:24–05:22)

[+] Условие внутри (...) автоматически приводится к boolean; срабатывает только первая истинная ветка. Если цель — просто выбрать значение для const, удобнее тернарник ? :.

```js
const year = 2024;
if (year === 2024) {
  console.log('Ура!');
} else if (year === 3000) {
  console.log('Нейросети победили');
} else {
  console.log('Неизвестный год');
}

/* Тернарный оператор для выбора значения сразу при объявлении const: */
const message = year === 2024 ? 'Начинаем учиться' : 'Неизвестный год';

/* Совет (Explaining Variable): длинные условия лучше вынести в понятные переменные! */
/* const isAdult = age >= 18; -> if (isAdult && hasTicket) читается намного легче */
```

## 2. Операторы || (ИЛИ), && (И) и приоритет (05:23–09:42, 10:57–12:17)

[!] Логические || и && приводят к boolean только внутри себя для проверки, но всегда возвращают саму исходную сущность! Приоритет: оператор && выполняется раньше ||.

```js
/* || (ИЛИ) ищет ПЕРВЫЙ истинный (truthy) операнд, иначе возвращает ПОСЛЕДНИЙ: */
console.log(null || '' || 100); /* 100 — остановился на первом истинном значении */
console.log(0 || '' || false);  /* false — все ложные, вернул последний операнд */

/* && (И) ищет ПЕРВЫЙ ложный (falsy) операнд, иначе возвращает ПОСЛЕДНИЙ: */
console.log('Hi' && null && 10); /* null — остановился на первом ложном */
console.log('Hi' && 5 && 10);    /* 10 — все истинные, вернул последний */

/* Ленивое вычисление: правая часть даже не запустится, если исход уже ясен! */
/* false && alert('Не покажется');  |  true || alert('Не покажется'); */
/* Приоритет: ! выше &&, а && выше || ->  a || b && c  ===  a || (b && c) */
```

## 3. Логическое НЕ (!) и оператор нулевого слияния ?? (09:43–10:56, 12:18–13:55)

[+] Оператор ! сначала приводит значение к boolean, затем инвертирует в true/false (двойное !! — то же, что Boolean(x), но Boolean читается яснее). Оператор ?? проверяет строго на null и undefined, не ломая 0, "" и false.

```js
console.log(!'Привет');  /* false */
console.log(!!'Привет'); /* true (аналог Boolean('Привет')) */

/* Разница || и ?? на примере нуля (a = 0): */
const a = 0;
const b = 100;
console.log(a || b); /* 100 — || считает 0 ложным значением (falsy) и отбрасывает его! */
console.log(a ?? b); /* 0 — ?? считает 0 нормальным значением (не null и не undefined) */

/* Смешивать ?? с || или && без скобок ЗАПРЕЩЕНО (SyntaxError)! */
/* 1 && 2 ?? 3 -> ОШИБКА;  нужно явно: (1 && 2) ?? 3 */
```

## 3 главные ловушки урока (чек-лист для повторения)

1. Думать, что || и && возвращают true/false — они всегда возвращают исходное значение одного из операндов (например, 0 || 100 вернёт 100, а "a" && null вернёт null).

2. Ставить || вместо ?? для значений по умолчанию, когда 0, "" или false допустимы (например, количество товара или скидка 0 исчезнет при ||).

3. Забывать, что && срабатывает раньше || (лучше ставить явные круглые скобки), и писать if (cond) ... без фигурных скобок или длинные вложенные тернарники.
