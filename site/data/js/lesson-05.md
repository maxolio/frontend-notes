# Урок 05. Условия if/else, тернарный оператор, логические операторы и ??

Суть урока: if/else выбирает ветку кода, тернарный ? : записывает выбор в const; операторы || и && не превращают результат в true/false, а возвращают сам операнд (у && приоритет выше ||), а ?? реагирует только на null и undefined (сохраняя 0 и "").

## 1. Конструкция if / else if / else и тернарный оператор (00:24–05:22)

[+] Условие внутри (...) автоматически приводится к boolean; срабатывает только первая истинная ветка. Если цель — просто выбрать значение для const, удобнее тернарник ? :.

```js
const year = 2024;
if (year === 2024) {
  console.log('Ура!');
} else if (year === 3000) {
  console.log('Нейросети победили');
} else {
  console.log('Неизвестный год');
}

/* Тернарный оператор для выбора значения сразу при объявлении const: */
const message = year === 2024 ? 'Начинаем учиться' : 'Неизвестный год';

/* Совет (Explaining Variable): длинные условия лучше вынести в понятные переменные! */
/* const isAdult = age >= 18; -> if (isAdult && hasTicket) читается намного легче */
```

## 2. Операторы || (ИЛИ), && (И) и приоритет (05:23–09:42, 10:57–12:17)

[!] Логические || и && приводят к boolean только внутри себя для проверки, но всегда возвращают саму исходную сущность! Приоритет: оператор && выполняется раньше ||.

```js
/* || (ИЛИ) ищет ПЕРВЫЙ истинный (truthy) операнд, иначе возвращает ПОСЛЕДНИЙ: */
console.log(null || '' || 100); /* 100 — остановился на первом истинном значении */
console.log(0 || '' || false);  /* false — все ложные, вернул последний операнд */

/* && (И) ищет ПЕРВЫЙ ложный (falsy) операнд, иначе возвращает ПОСЛЕДНИЙ: */
console.log('Hi' && null && 10); /* null — остановился на первом ложном */
console.log('Hi' && 5 && 10);    /* 10 — все истинные, вернул последний */

/* Ленивое вычисление: правая часть даже не запустится, если исход уже ясен! */
/* false && alert('Не покажется');  |  true || alert('Не покажется'); */
/* Приоритет: ! выше &&, а && выше || ->  a || b && c  ===  a || (b && c) */
```

## 3. Логическое НЕ (!) и оператор нулевого слияния ?? (09:43–10:56, 12:18–13:55)

[+] Оператор ! сначала приводит значение к boolean, затем инвертирует в true/false (двойное !! — то же, что Boolean(x), но Boolean читается яснее). Оператор ?? проверяет строго на null и undefined, не ломая 0, "" и false.

```js
console.log(!'Привет');  /* false */
console.log(!!'Привет'); /* true (аналог Boolean('Привет')) */

/* Разница || и ?? на примере нуля (a = 0): */
const a = 0;
const b = 100;
console.log(a || b); /* 100 — || считает 0 ложным значением (falsy) и отбрасывает его! */
console.log(a ?? b); /* 0 — ?? считает 0 нормальным значением (не null и не undefined) */

/* Смешивать ?? с || или && без скобок ЗАПРЕЩЕНО (SyntaxError)! */
/* 1 && 2 ?? 3 -> ОШИБКА;  нужно явно: (1 && 2) ?? 3 */
```

## 3 главные ловушки урока (чек-лист для повторения)

1. Думать, что || и && возвращают true/false — они всегда возвращают исходное значение одного из операндов (например, 0 || 100 вернёт 100, а "a" && null вернёт null).

2. Ставить || вместо ?? для значений по умолчанию, когда 0, "" или false допустимы (например, количество товара или скидка 0 исчезнет при ||).

3. Забывать, что && срабатывает раньше || (лучше ставить явные круглые скобки), и писать if (cond) ... без фигурных скобок или длинные вложенные тернарники.

## Вопросы для закрепления

**1. Что вернёт выражение `null || 2 && 3 || 4` и почему результат — не `true`?**

<details>
<summary>Показать ответ</summary>

Результат будет **`3`**.
1. У оператора `&&` приоритет выше, чем у `||`, поэтому сначала вычисляется `2 && 3` — оба значения истинные, и `&&` возвращает последний операнд (`3`).
2. Затем слева направо идёт `null || 3 || 4`: оператор `||` ищет первое истинное значение, находит `3` и останавливается. Логические операторы всегда возвращают само исходное значение, а не `true`/`false`.

</details>

**2. Почему `||` ломает значение `0` по умолчанию и зачем в строке `1 && 2 ?? 3` нужны скобки?**

<details>
<summary>Показать ответ</summary>

Оператор `||` считает `0`, `""` и `false` ложными (falsy), поэтому `0 || 100` потеряет настоящий ноль (например, нулевую скидку) и вернёт `100`. Оператор `??` проверяет строго `null` и `undefined`, поэтому `0 ?? 100` честно оставит `0`. А выражение `1 && 2 ?? 3` сразу вызовет `SyntaxError`: стандарт запрещает смешивать `??` с `&&` или `||` без явных скобок вроде `(1 && 2) ?? 3`.

</details>

**3. Какие строки выведутся в консоль и сработает ли ветка `'Отлично'`?**

```js
const score = 95;

false && console.log('Первый вызов');
true || console.log('Второй вызов');

if (score >= 50) {
  console.log('Зачёт');
} else if (score >= 90) {
  console.log('Отлично');
}
```

<details>
<summary>Показать ответ</summary>

Выведется только **`'Зачёт'`**.
1. Первые два `console.log` не запустятся из-за **ленивого вычисления**: слева от `&&` уже `false`, а слева от `||` уже `true`, поэтому правую часть движок даже не запускает.
2. В цепочке `if / else if` выполняется только **первая** истинная ветка (`95 >= 50`), а остальные пропускаются. Чтобы `'Отлично'` сработало, более строгое условие `score >= 90` нужно ставить выше.

</details>

## Задачи

**Задача 1. Правило входа и статус гостя через тернарный оператор**

Вынеси условия в понятные булевы переменные (`hasAgeAccess` — от 18 лет, `isVip` — роль равна `'vip'`). Через `if / else` выведи `'Доступ открыт'`, если гость совершеннолетний **и** у него есть билет, **или** если у него статус VIP (иначе — `'Доступ закрыт'`), а через тернарный оператор `? :` запиши в `badgeText` строку `'VIP-гость'` или `'Обычный гость'` и выведи её.

```js
'use strict';

const age = 16;
const hasTicket = true;
const role = 'vip';

/* Твоё решение: */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

const age = 16;
const hasTicket = true;
const role = 'vip';

/* Выносим проверки в понятные переменные (Explaining Variable) */
const hasAgeAccess = age >= 18;
const isVip = role === 'vip';

/*
  Явные скобки вокруг (hasAgeAccess && hasTicket) улучшают читаемость,
  хотя && и так выполняется раньше ||. Из-за isVip === true сработает if
*/
if ((hasAgeAccess && hasTicket) || isVip) {
  console.log('Доступ открыт');
} else {
  console.log('Доступ закрыт');
}

/* Тернарный оператор ? : удобно сразу записывает выбранную строку в const */
const badgeText = isVip ? 'VIP-гость' : 'Обычный гость';
console.log(badgeText); /* VIP-гость */
```

</details>

**Задача 2. Почини значения по умолчанию (`??` против `||`)**

Сейчас скрипт теряет нулевую скидку `0`, оставляет пустой промокод `''` вместо `'NO_PROMO'`, а третья строка вообще падает с `SyntaxError`. Замени операторы и расставь скобки так, чтобы на выходе получилось `0`, `'NO_PROMO'` и `50`.

```js
'use strict';

const userDiscount = 0;
const promoInput = '';
const serverLimit = null;

/* Твоё решение: */
const finalDiscount = userDiscount || 10;
const appliedPromo = promoInput ?? 'NO_PROMO';
const activeLimit = serverLimit && 100 ?? 50;

console.log(finalDiscount); /* должно быть: 0 */
console.log(appliedPromo);  /* должно быть: NO_PROMO */
console.log(activeLimit);   /* должно быть: 50 */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

const userDiscount = 0;
const promoInput = '';
const serverLimit = null;

/*
  Для скидки 0 используем ??: в отличие от || он реагирует только на
  null/undefined и не подменяет ноль значением по умолчанию
*/
const finalDiscount = userDiscount ?? 10;

/*
  Пустая строка '' — не null и не undefined, поэтому ?? оставил бы её пустой.
  Здесь нужен ||, чтобы для пустой строки подставился запасной текст
*/
const appliedPromo = promoInput || 'NO_PROMO';

/*
  Смешивать && и ?? без скобок запрещено (SyntaxError):
  сначала вычисляем (null && 100) -> null, затем null ?? 50 -> 50
*/
const activeLimit = (serverLimit && 100) ?? 50;

console.log(finalDiscount); /* 0 */
console.log(appliedPromo);  /* NO_PROMO */
console.log(activeLimit);   /* 50 */
```

</details>

**Задача 3. Отладка цепочки скидок `if / else if`**

Из-за неверного порядка условий заказ на `5500` получает скидку `5%` вместо `15%`, а нулевая или отрицательная сумма вообще не отлавливается. Перестрой цепочку так, чтобы при некорректной сумме (`!orderTotal || orderTotal < 0`) выводилось `'Ошибка суммы'`, от `5000` — `'Скидка 15%'`, от `1000` — `'Скидка 5%'`, иначе — `'Без скидки'`.

```js
'use strict';

const orderTotal = 5500;

/* Твоё решение: */
if (orderTotal >= 1000) {
  console.log('Скидка 5%');
} else if (orderTotal >= 5000) {
  console.log('Скидка 15%');
} else {
  console.log('Без скидки');
}
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

const orderTotal = 5500;

/*
  Сначала отсекаем некорректные суммы: !orderTotal поймает 0 и NaN,
  а orderTotal < 0 — отрицательные числа
*/
if (!orderTotal || orderTotal < 0) {
  console.log('Ошибка суммы');
} else if (orderTotal >= 5000) {
  /*
    Более строгий порог >= 5000 обязан идти раньше >= 1000,
    иначе любая сумма от 1000 перехватится первой веткой
  */
  console.log('Скидка 15%');
} else if (orderTotal >= 1000) {
  console.log('Скидка 5%');
} else {
  console.log('Без скидки');
}
```

</details>
