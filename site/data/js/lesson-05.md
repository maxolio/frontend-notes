# Урок 05. Условия `if`/`else`, тернарный оператор, логические операторы и `??`

Суть урока:

- **Ветвления:** `if`/`else` выбирает ветку кода, а тернарный `? :` позволяет записать выбор сразу в `const`.
- **Логические `||` и `&&`:** не превращают результат в `true`/`false`, а возвращают сам операнд (приоритет `&&` выше `||`).
- **Оператор `??`:** реагирует только на `null` и `undefined`, сохраняя `0`, `''` и `false`.

## 1. Конструкция `if` / `else if` / `else` и тернарный оператор (00:24–05:22)

[+] Условие внутри `(...)` автоматически приводится к `boolean`; срабатывает только первая истинная ветка. Всегда ставь фигурные скобки `{}`. Если цель — просто выбрать значение для `const`, удобнее тернарник `? :` (но не делай вложенные цепочки `? :` и не используй его вместо `if` для действий вроде `console.log`).

```js
const year = 2024;

if (year === 2024) {
  console.log('Ура!');
} else if (year === 3000) {
  console.log('Нейросети победили');
} else {
  console.log('Неизвестный год');
}

/* Тернарный оператор ? : выбирает значение сразу в const (нужны обе ветки) */
const message = year === 2024
  ? 'Начинаем учиться'
  : 'Неизвестный год';

/* Совет (Explaining Variable): длинные проверки выноси в переменные */
const age = 20;
const hasTicket = true;
const isAdult = age >= 18;

if (isAdult && hasTicket) {
  console.log('Вход разрешён');
}
```

## 2. Операторы `||` (ИЛИ), `&&` (И) и приоритет (05:23–09:42, 10:57–12:17)

[!] Логические `||` и `&&` приводят значения к `boolean` только внутри себя для проверки, но всегда возвращают **само исходное значение** одного из операндов. Приоритет: `!` выше `&&`, а `&&` выполняется раньше `||`.

```js
/* || (ИЛИ) ищет ПЕРВЫЙ истинный (truthy), иначе вернёт ПОСЛЕДНИЙ */
console.log(null || '' || 100); /* 100 — первый истинный */
console.log(0 || '' || false);  /* false — все ложные, взял последний */

/* && (И) ищет ПЕРВЫЙ ложный (falsy), иначе вернёт ПОСЛЕДНИЙ */
console.log('Hi' && null && 10); /* null — первый ложный */
console.log('Hi' && 5 && 10);    /* 10 — все истинные, взял последний */

/* Ленивое вычисление: правая часть не запустится, если исход уже ясен */
false && console.log('Не покажется');
true || console.log('Не покажется');

/* Приоритет: a || b && c читается движком как a || (b && c) */
```

## 3. Логическое НЕ (`!`) и оператор нулевого слияния `??` (09:43–10:56, 12:18–13:55)

[+] Оператор `!` приводит значение к `boolean` и инвертирует его в `true`/`false` (двойное `!!` — аналог `Boolean(x)`, но `Boolean()` читается яснее). Оператор `??` проверяет строго `null` и `undefined`, сохраняя `0`, `''`, `false` и `NaN`.

```js
console.log(!'Привет');  /* false */
console.log(!!'Привет'); /* true (аналог Boolean('Привет')) */

/* Разница || и ?? на допустимых falsy-значениях (0, '', false) */
const discount = 0;
const text = '';

/* || отбросит 0 и '', потому что считает их ложными (falsy) */
console.log(discount || 100); /* 100 */
console.log(text || 'Пусто'); /* 'Пусто' */

/* ?? пропустит дальше ТОЛЬКО null или undefined */
console.log(discount ?? 100); /* 0 */
console.log(text ?? 'Пусто'); /* '' */
console.log(null ?? 100);     /* 100 */

/* Смешивать ?? с || или && без скобок ЗАПРЕЩЕНО (SyntaxError) */
/* 1 && 2 ?? 3 -> SyntaxError; правильно: (1 && 2) ?? 3 */
```

| Оператор | Приоритет | Что возвращает | Реагирует на `0`, `''`, `false`? |
| :--- | :---: | :--- | :---: |
| `!` | Высший | Всегда `true` или `false` | Да (инвертирует в `true`) |
| `&&` | Средний | Первый falsy или последний операнд | Да (останавливается на них) |
| `||` | Низкий | Первый truthy или последний операнд | Да (пропускает их) |
| `??` | Низкий | Первый не-`null`/не-`undefined` или последний | Нет (считает их валидными) |

## 3 главные ловушки урока (чек-лист для повторения)

1. Думать, что `||` и `&&` возвращают `true`/`false` — они всегда возвращают исходное значение операнда (например, `0 || 100` вернёт `100`, а `'a' && null` вернёт `null`).

2. Ставить `||` вместо `??` для значений по умолчанию, когда `0`, `''` или `false` допустимы (например, нулевая скидка или количество `0` потеряется при `||`).

3. Забывать, что `&&` срабатывает раньше `||` (лучше ставить явные круглые скобки), смешивать `??` с `&&`/`||` без скобок (`SyntaxError`), а также писать `if` без `{}` или вложенные тернарники.

## Вопросы для закрепления

**1. Что вернёт выражение `null || 2 && 3 || 4` и почему результат — не `true`?**

<details>
<summary>Показать ответ</summary>

Результат будет **`3`**.

1. У оператора `&&` приоритет выше, чем у `||`, поэтому сначала вычисляется `2 && 3` — оба значения истинные, и `&&` возвращает последний операнд (`3`).
2. Затем слева направо идёт `null || 3 || 4`: оператор `||` ищет первое истинное значение, находит `3` и останавливается. Логические операторы всегда возвращают само исходное значение, а не `true`/`false`.

</details>

**2. Почему `||` ломает значение `0` по умолчанию и зачем в строке `1 && 2 ?? 3` нужны скобки?**

<details>
<summary>Показать ответ</summary>

Оператор `||` считает `0`, `''` и `false` ложными (`falsy`), поэтому `0 || 100` потеряет настоящий ноль (например, нулевую скидку) и вернёт `100`. Оператор `??` проверяет строго `null` и `undefined`, поэтому `0 ?? 100` честно оставит `0`. А выражение `1 && 2 ?? 3` сразу вызовет `SyntaxError`: стандарт запрещает смешивать `??` с `&&` или `||` без явных скобок вроде `(1 && 2) ?? 3`.

</details>

**3. Какие строки выведутся в консоль и сработает ли ветка `'Отлично'`?**

```js
const score = 95;

false && console.log('Первый вызов');
true || console.log('Второй вызов');

if (score >= 50) {
  console.log('Зачёт');
} else if (score >= 90) {
  console.log('Отлично');
}
```

<details>
<summary>Показать ответ</summary>

Выведется только **`'Зачёт'`**.

1. Первые два `console.log` не запустятся из-за **ленивого вычисления**: слева от `&&` уже `false`, а слева от `||` уже `true`, поэтому правую часть движок даже не запускает.
2. В цепочке `if` / `else if` выполняется только **первая** истинная ветка (`95 >= 50`), а остальные пропускаются. Чтобы `'Отлично'` сработало, более строгое условие `score >= 90` нужно ставить выше.

</details>

**Задача 1. Правило входа и статус гостя через тернарный оператор**

Проверь право входа на мероприятие и подпись для бейджа гостя:

1. Вынеси проверки в понятные булевы переменные: `hasAgeAccess` (от 18 лет) и `isVip` (роль строго `'vip'`).
2. Через `if` / `else` выведи `'Доступ открыт'`, если гость совершеннолетний **и** у него есть билет, **или** если у него статус VIP (иначе — `'Доступ закрыт'`).
3. Через тернарный оператор `? :` запиши в `badgeText` строку `'VIP-гость'` или `'Обычный гость'` и выведи её.

Проверка: в консоли должны появиться `'Доступ открыт'` и `'VIP-гость'`.

```js
'use strict';

const age = 16;
const hasTicket = true;
const role = 'vip';

/* Твоё решение: */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

const age = 16;
const hasTicket = true;
const role = 'vip';

/* Выносим проверки в понятные переменные (Explaining Variable) */
const hasAgeAccess = age >= 18;
const isVip = role === 'vip';

/*
  Явные скобки вокруг (hasAgeAccess && hasTicket) улучшают читаемость,
  хотя && и так выполняется раньше ||. Из-за isVip === true сработает if
*/
if ((hasAgeAccess && hasTicket) || isVip) {
  console.log('Доступ открыт');
} else {
  console.log('Доступ закрыт');
}

/* Тернарный оператор ? : удобно сразу записывает выбранную строку в const */
const badgeText = isVip ? 'VIP-гость' : 'Обычный гость';
console.log(badgeText); /* VIP-гость */
```

</details>

**Задача 2. Почини значения по умолчанию (`??` против `||`)**

Сейчас скрипт теряет нулевую скидку `0`, оставляет пустой промокод `''` вместо `'NO_PROMO'`, а третья строка падает с `SyntaxError`. Исправь три выражения:

1. В `finalDiscount` используй оператор `??`, чтобы нулевая скидка `0` не заменялась на `10`.
2. В `appliedPromo` используй оператор `||`, чтобы пустая строка `''` заменилась на `'NO_PROMO'`.
3. В `activeLimit` расставь скобки вокруг `&&`, чтобы разрешить сочетание с `??` без `SyntaxError`.

Проверка: в консоль должны вывестись `0`, `'NO_PROMO'` и `50`.

```js
'use strict';

const userDiscount = 0;
const promoInput = '';
const serverLimit = null;

/* Твоё решение: */
const finalDiscount = userDiscount || 10;
const appliedPromo = promoInput ?? 'NO_PROMO';
const activeLimit = serverLimit && 100 ?? 50;

console.log(finalDiscount); /* должно быть: 0 */
console.log(appliedPromo);  /* должно быть: NO_PROMO */
console.log(activeLimit);   /* должно быть: 50 */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

const userDiscount = 0;
const promoInput = '';
const serverLimit = null;

/*
  Для скидки 0 используем ??: в отличие от || он реагирует только на
  null/undefined и не подменяет ноль значением по умолчанию
*/
const finalDiscount = userDiscount ?? 10;

/*
  Пустая строка '' — не null и не undefined, поэтому ?? оставил бы её пустой.
  Здесь нужен ||, чтобы для пустой строки подставился запасной текст
*/
const appliedPromo = promoInput || 'NO_PROMO';

/*
  Смешивать && и ?? без скобок запрещено (SyntaxError):
  сначала вычисляем (null && 100) -> null, затем null ?? 50 -> 50
*/
const activeLimit = (serverLimit && 100) ?? 50;

console.log(finalDiscount); /* 0 */
console.log(appliedPromo);  /* NO_PROMO */
console.log(activeLimit);   /* 50 */
```

</details>

**Задача 3. Отладка цепочки скидок `if` / `else if`**

Сейчас из-за неверного порядка условий заказ на `5500` получает скидку `5%` вместо `15%`, а нулевая или отрицательная сумма вообще не отлавливается. Перестрой цепочку условий по шагам:

1. Если сумма некорректна (`!orderTotal || orderTotal < 0`) — выведи `'Ошибка суммы'`.
2. Если сумма от `5000` и выше — выведи `'Скидка 15%'`.
3. Если сумма от `1000` и выше — выведи `'Скидка 5%'`.
4. Во всех остальных случаях — выведи `'Без скидки'`.

Проверка: для `5500` должно вывестись `'Скидка 15%'` (после решения попробуй подставить `0`, `-100`, `500` и `1500`, чтобы проверить все ветки).

```js
'use strict';

const orderTotal = 5500;

/* Твоё решение: */
if (orderTotal >= 1000) {
  console.log('Скидка 5%');
} else if (orderTotal >= 5000) {
  console.log('Скидка 15%');
} else {
  console.log('Без скидки');
}
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

const orderTotal = 5500;

/*
  Сначала отсекаем некорректные суммы: !orderTotal поймает 0 и NaN,
  а orderTotal < 0 — отрицательные числа.
  На вырост: в реальных проектах числа проверяют через
  !Number.isFinite(orderTotal) || orderTotal <= 0, чтобы отсечь
  Infinity и строки вроде 'abc'
*/
if (!orderTotal || orderTotal < 0) {
  console.log('Ошибка суммы');
} else if (orderTotal >= 5000) {
  /*
    Более строгий порог >= 5000 обязан идти раньше >= 1000,
    иначе любая сумма от 1000 перехватится первой веткой
  */
  console.log('Скидка 15%');
} else if (orderTotal >= 1000) {
  console.log('Скидка 5%');
} else {
  console.log('Без скидки');
}
```

</details>
