# Урок 15. Массивы в JavaScript

Суть урока: массив ([...]) — упорядоченный список, который под капотом является объектом, хранится по ссылке и изменяем (мутабелен).

## 1. Массив — это объект (00:19 – 01:27)

```js
const arr = ['Яблоко', 100, true]; // Внутри могут лежать любые типы данных
typeof arr; // 'object' (массив под капотом является объектом)
/* Всегда создавай через []. new Array(3) с одним числом создаст НЕ [3],
   а пустой массив длиной 3 с 3 пустыми слотами (<3 empty items>). */
```

## 2. Доступ к элементам, разные типы, изменение, пустые ячейки и length (02:14 – 08:01)

```js
const mixed = [
  'Привет',                       // [0] строка
  100,                            // [1] число
  true,                           // [2] boolean
  { name: 'Александр' },          // [3] объект
  () => console.log('Хаха'),      // [4] функция
  [true, true, true],             // [5] вложенный массив
];
/* Как обращаться к разным типам внутри массива: */
mixed[0];      // 'Привет' (индексы всегда начинаются с 0)
mixed[3].name; // 'Александр' (достали объект по индексу [3], дальше через точку)
mixed[4]();    // Вызовет функцию -> 'Хаха' (достали функцию [4] и вызвали через ())
mixed[5][0];   // true (взяли 0-й элемент из вложенного массива на индексе [5])
/* Когда приходит undefined: если обратиться к несуществующему индексу или пустой ячейке: */
mixed[99];     // undefined (ошибки НЕ будет, как и при чтении лишнего ключа в объекте)

/* Изменение и добавление по большому индексу: */
/* const запрещает менять саму переменную (mixed = []), но элементы менять МОЖНО: */
mixed[1] = 200;     // Изменили существующий элемент на индексе 1
mixed[100] = 'Bay'; // Записали далеко за пределы длины -> length станет 101!
/* Ячейки с [6] по [99] останутся пустыми (<94 empty items>); при чтении дадут undefined.
   Так добавлять в конец НЕ надо — используй .push(). */

/* Длина и последний элемент: */
mixed[mixed.length - 1]; // Старый способ взять последний элемент
mixed.at(-1);            // Современный короткий способ (считает с конца!)
mixed.length = 0;        // [] — самый быстрый способ полностью очистить массив
```

## 3. Добавление и удаление: push, pop, unshift, shift — МУТИРУЮТ массив (09:36 – 11:27)

```js
const list = ['b', 'c'];
/* Конец массива (БЫСТРО) — меняют только хвост, остальные индексы не трогают: */
list.push('d');    // + в конец  -> ['b', 'c', 'd'] (возвращает новую длину: 3)
list.pop();        // - с конца  -> ['b', 'c']      (возвращает удалённый: 'd')
/* Начало массива (МЕДЛЕННО) — движку приходится сдвигать и перенумеровывать ВСЕ элементы: */
list.unshift('a'); // + в начало -> ['a', 'b', 'c']
list.shift();      // - с начала -> ['b', 'c']
```

## 4. Массив <-> Строка: toString, join, split — НЕ мутируют (12:51 – 14:19)

```js
const words = ['Привет', 'JS'];
words.toString();             // 'Привет,JS' (всегда склеивает только через запятую)
words.join(' ');              // 'Привет JS' (можно задать любой разделитель — лучше его)
'а,б,в'.split(',');           // ['а', 'б', 'в'] (строковый метод режет строку в массив)
'а,б,в'.split(',').join('-'); // 'а-б-в' (частая связка: разобрали -> склеили по-новому)
/* Приведение к строке вложенных сущностей (toString / join): */
const complex = [{ name: 'Саша' }, () => 1, [10, 20]];
complex.join(' | '); // '[object Object] | () => 1 | 10,20'
/* Объект теряет свойства и становится '[object Object]', функция — текстом своего кода,
   а вложенный массив просто расплющивается через запятую! */
```

## 5. Копирование, slice и объединение — НЕ мутируют (15:32 – 18:42)

```js
const a = [10, 20, 30, 40]; const b = [50, 60];
/* const copy = a копирует только ССЫЛКУ. Для реальной (поверхностной) копии: */
const copy1 = [...a];         // [10, 20, 30, 40] — через Spread (главный способ)
const copy2 = a.slice();      // [10, 20, 30, 40] — slice() без аргументов копирует весь
const part  = a.slice(1, 3);  // [20, 30] — от start до end (НЕ включая end), a цел
/* Объединение: современный Spread или метод concat (тоже не меняют исходные массивы): */
const merged1 = [...a, ...b]; // [10, 20, 30, 40, 50, 60]
const merged2 = a.concat(b);  // [10, 20, 30, 40, 50, 60]
/* Spread и slice копируют только 1-й уровень. Для вложенных -> structuredClone(a). */
```

## 6. Сравнение массивов, перебор и проверка Array.isArray (19:29 – 22:34)

```js
/* 1. Сравнение: массивы сравниваются по ССЫЛКЕ в Куче, а не по содержимому: */
[1, 2] === [1, 2]; // false (разные адреса памяти; по значениям сравнивают поэлементно)
/* 2. Проверка на массив: typeof врёт, потому что массив — объект: */
typeof [1, 2];         // 'object'
Array.isArray([1, 2]); // true (единственно надёжная проверка) | Array.isArray({}) -> false
/* 3. Перебирай массив через for..of (по значениям), а НЕ for..in (он для объектов!): */
for (const item of a) { console.log(item); }
```

## 3 главные ловушки урока (чек-лист для повторения)

1. unshift / shift тормозят — на больших списках сдвигают все индексы (быстрее работать с хвостом: push / pop).

2. Запись по огромному индексу и [...arr] — arr[100] создаёт пустые дыры (undefined), а [...arr] копирует только 1-й уровень (для вложенных нужен structuredClone).

3. typeof [] === "object" и toString для объектов — проверяй массив через Array.isArray(arr), перебирай через for..of, а объекты внутри .join() дадут "[object Object]".
