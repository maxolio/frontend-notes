# Урок 01. Введение: подключение JS, console.log, синтаксис и ошибки

Суть урока: Скрипт подключают через `<script src="script.js">``</script>` перед `</body>` (или в `<head>` с defer), вывод смотрят в DevTools -> Console, ; ставят перед [ и ( из-за ASI, а любая ошибка останавливает выполнение дальнейшего кода файла.

## 1. Подключение JS к странице и атрибуты defer / async (01:46–02:44)

[+] Браузер читает HTML сверху вниз: обычный `<script>` в `<head>` блокирует отрисовку страницы и не видит разметку ниже. Поэтому ставят в конце `<body>` или с defer в `<head>`.

```html
<!-- Способ 1 — в конце разметки (HTML уже построен, код внутри тега с src игнорируется!): -->
<script src="script.js"></script>
</body>

<!-- Способ 2 — в <head>: defer ждёт DOM и соблюдает порядок; async (аналитика) нет -->
<script src="script.js" defer></script>
```

## 2. Вывод данных в DevTools -> Console (02:45–03:43)

[+] console.log(...) выводит неограниченное число значений через запятую в консоль браузера (клавиша F12). Для наглядности таблиц и ошибок есть table, warn и error.

```js
console.log('Привет', 555, true); /* можно переносить аргументы на разные строки */
console.table([10, 20, 30]);      /* удобная таблица для массивов и объектов */
console.error('Ошибка!');         /* красное сообщение с трассировкой стека */
```

## 3. Инструкции, ловушка ; (ASI) и комментарии (03:44–06:09)

[!] Каждую инструкцию пишут с новой строки. Движок сам подставляет ; (механизм ASI), но перед строкой с [ или ( точку с запятой ставить ОБЯЗАТЕЛЬНО, иначе строки склеятся!

```js
console.log('Привет 1');
[1, 2].forEach(console.log); /* без ";" выше JS попытался бы склеить "Привет 1"[1, 2]! */

// Однострочный комментарий (горячая клавиша в IDE: Ctrl + /)
/* Многострочный комментарий — но вкладывать /* /* */ */ друг в друга НЕЛЬЗЯ! */
```

## 4. Обнаружение и чтение ошибок в консоли (06:10–07:25)

[+] При ошибке (например, console.lg) выполнение файла сразу прерывается. Справа от красной плашки ошибки указана кликабельная ссылка вида script.js:2:9 — клик по ней открывает точную строку во вкладке Sources.

## 3 главные ловушки урока (чек-лист для повторения)

1. Подключить `<script src="...">` в `<head>` без defer (не найдёт HTML-элементы) или написать JS внутрь тега, у которого уже есть атрибут src (внутренний код проигнорируется).

2. Отказаться от ; и начать следующую строку с [ или ( — механизм ASI не поставит точку с запятой, и код упадёт.

3. Вложить многострочный комментарий /* /* */ */ внутрь другого (SyntaxError) или ждать, что код после ошибки в консоли продолжит выполняться.
