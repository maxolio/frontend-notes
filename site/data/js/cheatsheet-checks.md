# Шпаргалка. Проверки типов, значений и структур в JS

Суть урока:

- **Единый справочник:** все основные проверки для базовых типов, чисел, строк, массивов, объектов, классов и логических связок в одном месте.
- **Безопасность:** для чисел надёжнее `Number.isFinite(x)`, для массивов — `Array.isArray(x)`, а для объектов с защитой от `null` — `typeof x === 'object' && x !== null`.

## 1. Базовые типы (`typeof`)

- `typeof x === 'number'` — **тип `x` — число** *(но пропускает `NaN` и `Infinity`)*
- `typeof x === 'string'` — **тип `x` — строка**
- `typeof x === 'boolean'` — **тип `x` — логический (`true` / `false`)**
- `typeof x === 'undefined'` — **`x` не определён / не объявлен** *(не падает, даже если переменной нет)*
- `typeof x === 'function'` — **`x` является функцией**
- `typeof x === 'bigint'` — **`x` — большое целое число (`10n`)**
- `typeof x === 'symbol'` — **`x` — уникальный символ (`Symbol()`)**
- `typeof x === 'object' && x !== null` — **`x` — объект (и не `null`)** *(в JS `typeof null === 'object'` — старый баг языка)*

## 2. Числа (`Number` и математика)

- `Number.isNaN(x)` — **`x` является `NaN`** *(не число после кривой математики)*
- `!Number.isNaN(x)` — **`x` НЕ является `NaN`**
- `Number.isFinite(x)` — **`x` — обычное конечное число** *(лучшая проверка: отсекает строки, `NaN`, `Infinity`, `null`)*
- `Number.isInteger(x)` — **`x` — целое число** *(дробные `1.5` и строки вернут `false`)*
- `Number.isSafeInteger(x)` — **`x` — безопасное целое число** *(без потери точности)*
- `x % 1 === 0` — **`x` — целое число** *(делится на `1` без остатка)*
- `x % 2 === 0` — **`x` — чётное число**
- `x % 2 !== 0` — **`x` — нечётное число**
- `x > 0` / `x < 0` — **`x` положительное / отрицательное**
- `x >= min && x <= max` — **`x` входит в диапазон от `min` до `max`**

## 3. Строки (`String`)

- `x.length === 0` — **строка пустая** *(длина `0` символов)*
- `x.trim() === ''` — **строка пустая или из одних пробелов**
- `x.includes('abc')` — **строка содержит `'abc'`**
- `x.startsWith('abc')` — **строка начинается с `'abc'`**
- `x.endsWith('abc')` — **строка заканчивается на `'abc'`**

## 4. Пустота и истинность (`null`, `undefined`, Falsy)

- `x === null` — **`x` равен `null`** *(явно пусто / нажали Cancel)*
- `x === undefined` — **`x` равен `undefined`** *(не передан / не задан)*
- `x == null` — **`x` равен `null` ИЛИ `undefined`** *(единственный случай, когда `==` полезен)*
- `!x` — **`x` ложный / пустой** *(`''`, `0`, `-0`, `0n`, `null`, `undefined`, `NaN`, `false`)*
- `!!x` (или `Boolean(x)`) — **`x` истинный / непустой** *(всё остальное)*

## 5. Массивы (`Array`)

- `Array.isArray(x)` — **`x` является массивом** *(обычный `typeof` для массива даёт `'object'`)*
- `arr.length === 0` — **массив пустой**
- `arr.length > 0` — **в массиве есть хотя бы один элемент**
- `arr.includes(val)` — **массив содержит значение `val`**
- `arr.some(fn)` — **хотя бы один элемент массива подходит под условие**
- `arr.every(fn)` — **все элементы массива подходят под условие**

## 6. Объекты (`Object`)

- `'key' in obj` — **ключ `'key'` есть в объекте `obj`** *(или в его прототипе)*
- `Object.hasOwn(obj, 'key')` — **ключ `'key'` принадлежит самому объекту `obj`** *(современная замена `hasOwnProperty`)*
- `Object.keys(obj).length === 0` — **объект пустой** *(у него нет своих ключей)*

## 7. Классы и встроенные типы (`instanceof`)

- `x instanceof Date` — **`x` является датой (`Date`)**
- `x instanceof Error` — **`x` является объектом ошибки (`Error`)**
- `x instanceof HTMLElement` — **`x` является DOM-элементом со страницы**
- `x instanceof MyClass` — **`x` создан через класс `MyClass`**

## 8. Логические связки и операторы

- `if (A || B)` — **если верно хотя бы одно** *(A ИЛИ B)*
- `if (A && B)` — **если верны оба условия** *(A И B)*
- `a ?? b` — **взять `a`, а если там `null` или `undefined` — взять `b`** *(нулевое слияние)*
- `obj?.prop` — **безопасно прочитать `prop`, если `obj` не `null`/`undefined`** *(иначе вернёт `undefined` без ошибки)*
