# Урок 07. Циклы `while`, `do..while` и `for`, `break`, `continue` и область видимости

Суть урока:

- **Виды циклов:** `while` проверяет условие ДО тела (`0+` раз), `do..while` — ПОСЛЕ тела (минимум `1` раз), а `for` собирает старт, условие и шаг в скобках.
- **Область и управление:** переменные цикла видны только внутри него; `break` завершает весь цикл, а `continue` пропускает только текущий шаг.

## 1. Циклы `while`, `do..while` и риск бесконечного цикла (00:15–04:30)

[!] В реальных проектах `while` применяют осторожно: если забыть обновить счётчик (`count++`), условие всегда будет `true` — вкладка браузера уйдёт в бесконечный цикл и зависнет.

```js
let count = 0;

while (count < 10) {
  console.log(count); /* выведет 0..9 */
  count++;            /* без этой строки цикл станет БЕСКОНЕЧНЫМ! */
}

/* do..while выполнит тело минимум 1 раз, даже если условие сразу false */
let n = 100;

do {
  console.log(n); /* выполнится 1 раз и выведет 100 */
  n++;
} while (n < 10);
```

## 2. Цикл `for`, порядок шагов и область видимости (04:31–08:49)

[+] `for (начало; условие; шаг)`: «начало» запускается `1` раз, «условие» проверяется перед каждым шагом, а «шаг» — после тела. Любую часть можно пропустить, оставив обе `;`. Код после цикла ждёт его полного завершения.

```js
/* const i = 0 даст TypeError на i++ — счётчик всегда через let! */
for (let i = 0; i < 4; i++) {
  const message = `Шаг ${i}`; /* видна ТОЛЬКО внутри {} цикла */
  console.log(message);
}
/* console.log(i); -> ReferenceError (i живёт только внутри цикла) */

/* Пропуск частей внутри for (две точки с запятой обязательны!) */
let k = 0;
for (; k < 3; ) {
  console.log(k); /* работает точно так же, как while (k < 3) */
  k++;
}

/*
  На вырост (let vs var в for): при let на КАЖДЫЙ шаг создаётся своя i
  (таймеры и колбэки запомнят 0, 1, 2), а var делит одну i на всех (3, 3, 3)
*/
```

| Цикл | Проверка условия | Минимум шагов | Когда лучше выбирать |
| :--- | :--- | :---: | :--- |
| `for` | Перед телом | `0` | Известно число повторений или нужен счётчик `i` |
| `while` | Перед телом | `0` | Повторяем, пока выполняется внешнее условие |
| `do..while` | После тела | `1` | Тело обязано сработать минимум 1 раз (например, `prompt`) |

## 3. Досрочный выход `break`, пропуск `continue` и метки `label:` (08:50–10:37)

[+] `break` мгновенно прекращает весь цикл, а `continue` обрывает только текущий шаг и переходит к следующей итерации (удобно для фильтрации внутри цикла).

```js
for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) continue; /* чётные пропускаем -> сразу к i++ */
  if (i > 7) break;          /* выходим из цикла полностью после 7 */
  console.log(i);            /* выведет только: 1, 3, 5, 7 */
}

/* Осторожно: в while команда continue ДО count++ зациклит код! */

/* Метка (label:) позволяет break/continue выйти из внешнего цикла */
outer:
for (let y = 0; y < 3; y++) {
  for (let x = 0; x < 3; x++) {
    if (y === 1 && x === 1) break outer;
  }
}

/* break/continue нельзя писать в тернарнике ? : (SyntaxError) */
```

## 3 главные ловушки урока (чек-лист для повторения)

1. Забыть шаг счётчика в `while`, поставить `continue` в `while` раньше `count++` или задать условие, которое всегда `true` — получите бесконечный цикл и зависание вкладки.
2. Поставить `const` вместо `let` для счётчика в `for` (`TypeError`) или попытаться прочитать `i` / переменную из тела цикла после `}` (`ReferenceError`).
3. Перепутать `break` (обрывает весь цикл) и `continue` (пропускает лишь 1 шаг), а также забыть, что при `false` цикл `while` не сработает ни разу, а `do..while` выполнится 1 раз.

## Вопросы для закрепления

**1. Какие числа выведут эти два цикла `while` и почему наборы отличаются?**

```js
let a = 0;
while (++a < 4) console.log(a);

let b = 0;
while (b++ < 4) console.log(b);
```

<details>
<summary>Показать ответ</summary>

Первый цикл выведет **`1, 2, 3`**, а второй — **`1, 2, 3, 4`**.

1. В `++a < 4` префикс сначала увеличивает `a`, и в сравнение уходит уже новое число: на `a = 4` условие `4 < 4` ложно, поэтому цикл останавливается.
2. В `b++ < 4` постфикс отдаёт в сравнение **старое** значение `b` (`3 < 4` даёт `true`), но к моменту запуска `console.log(b)` переменная уже выросла до `4` и выводится на экран.

</details>

**2. Изменится ли вывод в `for (let i = 0; i < 3; i++)`, если заменить `i++` на `++i`, и что произойдёт при вызове `console.log(i)` сразу после цикла?**

<details>
<summary>Показать ответ</summary>

Вывод цикла **не изменится** (`0, 1, 2`), потому что «шаг» в `for` выполняется отдельно после тела цикла, а возвращённое им значение никуда не записывается. А вызов `console.log(i)` после закрывающей скобки `}` выбросит **`ReferenceError: i is not defined`** — переменная `let i` существует только внутри области видимости цикла.

</details>

**3. Сколько раз сработает `do..while` при изначально ложном условии и чем `break` отличается от `continue`?**

<details>
<summary>Показать ответ</summary>

Цикл `do..while` всегда выполняется **минимум 1 раз**, так как проверка условия стоит в самом конце (а обычный `while` при ложном условии не сработает ни разу). Оператор `continue` обрывает только текущую итерацию и сразу переходит к следующей, тогда как `break` полностью завершает весь цикл (а для выхода из внешнего вложенного цикла используют метку `label:`).

</details>

**Задача 1. Чётные числа и их сумма через `for` и `continue`**

Потренируй фильтрацию шагов цикла с помощью `continue`:

1. Напиши цикл `for` от `1` до `10` включительно.
2. Пропускай все нечётные числа через `if (i % 2 !== 0) continue;`.
3. Выводи в консоль каждое чётное число и прибавляй его к `evenSum`.

Проверка: в консоль должны вывестись `2, 4, 6, 8, 10`, а затем `'Сумма чётных: 30'`.

```js
'use strict';

let evenSum = 0;

/* Твоё решение: */

console.log(`Сумма чётных: ${evenSum}`);
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

let evenSum = 0;

/*
  Перебираем числа от 1 до 10; переменная i объявлена через let
  и видна только внутри тела цикла
*/
for (let i = 1; i <= 10; i++) {
  /*
    Если остаток от деления на 2 не равен 0 — число нечётное:
    continue сразу прерывает шаг и переходит к i++
  */
  if (i % 2 !== 0) continue;

  console.log(i); /* выведет: 2, 4, 6, 8, 10 */
  evenSum += i;   /* прибавляем чётное число к общей сумме */
}

console.log(`Сумма чётных: ${evenSum}`); /* Сумма чётных: 30 */
```

</details>

**Задача 2. Повторяй ввод числа больше `100` (`do..while`)**

Реализуй цикл проверки ввода пользователя, который срабатывает минимум один раз:

1. Внутри `do..while` запрашивай значение через `prompt('Введите число больше 100:', '')`.
2. Повторяй запрос, пока пользователь не введёт число строго больше `100` (отлавливай и нечисловой ввод вроде `'abc'`) или не отменит ввод (`null` / пустая строка `''`).
3. После цикла выведи `'Ввод отменён'` при отмене или `'Принято число: ...'` при успехе.

Проверка: на `'50'`, `'100'` и `'abc'` окно `prompt` появляется снова; на `'150'` выводится `'Принято число: 150'`; на `Cancel` или пустой `OK` — `'Ввод отменён'`.

```js
'use strict';

let rawInput;

/* Твоё решение: */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

let rawInput;

/*
  do..while подходит идеально: нам нужно спросить пользователя минимум 1 раз,
  а уже потом решать, повторять ли запрос
*/
do {
  rawInput = prompt('Введите число больше 100:', '');
} while (
  /*
    Повторяем, пока не нажали Cancel (null) и не ввели '',
    а условие +rawInput > 100 ложно (ловит и <= 100, и NaN)
  */
  rawInput !== null && rawInput !== '' && !(+rawInput > 100)
);

if (rawInput === null || rawInput === '') {
  console.log('Ввод отменён');
} else {
  console.log(`Принято число: ${+rawInput}`);
}
```

</details>

**Задача 3. Простые числа через вложенный цикл и метку `label`**

Выведи все простые числа от `2` до `limit` включительно (делятся без остатка только на `1` и сами на себя):

1. Поставь метку `nextPrime:` перед внешним циклом `for` от `2` до `limit`.
2. Во внутреннем цикле `for` проверь делители `j` от `2` до `i - 1`: если `i % j === 0`, сразу переходи к следующему `i` через `continue nextPrime`.
3. Если делителей не нашлось — выведи `i` в консоль.

Проверка: для `limit = 20` должны вывестись `2, 3, 5, 7, 11, 13, 17, 19`.

```js
'use strict';

const limit = 20;

/* Твоё решение: */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

const limit = 20;

/*
  Метка nextPrime позволяет внутреннему циклу перескочить сразу
  на следующую итерацию внешнего цикла, если нашёлся делитель
*/
nextPrime:
for (let i = 2; i <= limit; i++) {
  /*
    Проверяем возможные делители от 2 до i - 1.
    Как только i делится нацело (остаток 0) — оно не простое, бросаем проверку
  */
  for (let j = 2; j < i; j++) {
    if (i % j === 0) continue nextPrime;
  }

  /* Если ни один делитель не сработал — выводим простое число */
  console.log(i);
}
```

</details>
