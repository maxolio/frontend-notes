# Урок 07. Циклы while, do..while и for, break, continue и область видимости

Суть урока: while проверяет условие ДО тела (0+ раз), do..while — ПОСЛЕ тела (минимум 1 раз), а for собирает старт, условие и шаг в скобках; переменные внутри цикла видны только внутри него, break завершает весь цикл, а continue пропускает только текущий шаг.

## 1. Циклы while, do..while и риск бесконечного цикла (00:15–04:30)

[!] В реальных проектах while применяют осторожно: если забыть обновить счётчик (count++), условие всегда будет true — вкладка браузера уйдёт в бесконечный цикл и съест всю оперативную память.

```js
let count = 0;
while (count < 10) {
  console.log(count); /* выведет 0..9 */
  count++;            /* без этой строки цикл станет БЕСКОНЕЧНЫМ! */
}

/* do..while выполнит тело минимум 1 раз, даже если условие с самого начала false: */
let n = 100;
do {
  console.log(n); /* выполнится 1 раз и выведет 100 */
  n++;
} while (n < 10);
```

## 2. Цикл for, порядок шагов и область видимости (04:31–08:49)

[+] for (начало; условие; шаг): «начало» запускается 1 раз, «условие» проверяется перед каждым шагом, а «шаг» — после тела. Любую часть можно пропустить, оставив обе ;. Код после цикла ждёт его полного завершения.

```js
for (let i = 0; i < 4; i++) {
  const message = `Шаг ${i}`; /* видна ТОЛЬКО внутри фигурных скобок цикла */
  console.log(message);
}
/* console.log(i); -> ОШИБКА: ReferenceError: i is not defined (вне области видимости) */

/* Пропуск частей внутри for (две точки с запятой обязательны!): */
let k = 0;
for (; k < 3; ) { console.log(k); k++; } /* по сути то же, что while (k < 3) */

/* Нюанс (let vs var в for): при let на КАЖДЫЙ шаг создаётся своя переменная i (для */
/* таймеров/колбэков сохранит 0, 1, 2), а var делит одну переменную на все шаги (3, 3, 3) */
```

## 3. Досрочный выход break и пропуск итерации continue (08:50–10:37)

[+] break мгновенно прекращает весь цикл, а continue обрывает только текущий шаг и переходит к следующей итерации (удобно для фильтрации прямо внутри цикла).

```js
for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) continue; /* чётные пропускаем — сразу идём к следующему i */
  if (i > 7) break;          /* выходим из цикла полностью после числа 7 */
  console.log(i);            /* выведет только: 1, 3, 5, 7 */
}

/* Метка (label:) нужна, чтобы break/continue выходил сразу из внешнего вложенного цикла: */
outer: for (let y = 0; y < 3; y++) {
  for (let x = 0; x < 3; x++) { if (y === 1 && x === 1) break outer; }
}
/* НЕЛЬЗЯ писать break/continue справа от ? : (например, cond ? log() : continue -> Error) */
```

## 3 главные ловушки урока (чек-лист для повторения)

1. Забыть шаг изменения счётчика в while (или написать условие всегда true) — получите бесконечный цикл и зависание браузера.

2. Пытаться прочитать счётчик let i или переменную из тела цикла после } — будет ReferenceError (они живут только внутри блока цикла).

3. Перепутать break (обрывает весь цикл) и continue (пропускает лишь 1 шаг) или не учесть, что while без единого выполнения пропустит тело при false, а do..while — нет.
