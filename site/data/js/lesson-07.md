# Урок 07. Циклы while, do..while и for, break, continue и область видимости

Суть урока:

- **Виды циклов:** `while` проверяет условие ДО тела (`0+` раз), `do..while` — ПОСЛЕ тела (минимум `1` раз), а `for` собирает старт, условие и шаг в скобках.
- **Область и управление:** переменные цикла видны только внутри него; `break` завершает весь цикл, а `continue` пропускает только текущий шаг.

## 1. Циклы while, do..while и риск бесконечного цикла (00:15–04:30)

[!] В реальных проектах while применяют осторожно: если забыть обновить счётчик (count++), условие всегда будет true — вкладка браузера уйдёт в бесконечный цикл и съест всю оперативную память.

```js
let count = 0;
while (count < 10) {
  console.log(count); /* выведет 0..9 */
  count++;            /* без этой строки цикл станет БЕСКОНЕЧНЫМ! */
}

/* do..while выполнит тело минимум 1 раз, даже если условие с самого начала false: */
let n = 100;
do {
  console.log(n); /* выполнится 1 раз и выведет 100 */
  n++;
} while (n < 10);
```

## 2. Цикл for, порядок шагов и область видимости (04:31–08:49)

[+] for (начало; условие; шаг): «начало» запускается 1 раз, «условие» проверяется перед каждым шагом, а «шаг» — после тела. Любую часть можно пропустить, оставив обе ;. Код после цикла ждёт его полного завершения.

```js
for (let i = 0; i < 4; i++) {
  const message = `Шаг ${i}`; /* видна ТОЛЬКО внутри фигурных скобок цикла */
  console.log(message);
}
/* console.log(i); -> ОШИБКА: ReferenceError: i is not defined (вне области видимости) */

/* Пропуск частей внутри for (две точки с запятой обязательны!): */
let k = 0;
for (; k < 3; ) { console.log(k); k++; } /* по сути то же, что while (k < 3) */

/* Нюанс (let vs var в for): при let на КАЖДЫЙ шаг создаётся своя переменная i (для */
/* таймеров/колбэков сохранит 0, 1, 2), а var делит одну переменную на все шаги (3, 3, 3) */
```

## 3. Досрочный выход break и пропуск итерации continue (08:50–10:37)

[+] break мгновенно прекращает весь цикл, а continue обрывает только текущий шаг и переходит к следующей итерации (удобно для фильтрации прямо внутри цикла).

```js
for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) continue; /* чётные пропускаем — сразу идём к следующему i */
  if (i > 7) break;          /* выходим из цикла полностью после числа 7 */
  console.log(i);            /* выведет только: 1, 3, 5, 7 */
}

/* Метка (label:) нужна, чтобы break/continue выходил сразу из внешнего вложенного цикла: */
outer: for (let y = 0; y < 3; y++) {
  for (let x = 0; x < 3; x++) { if (y === 1 && x === 1) break outer; }
}
/* НЕЛЬЗЯ писать break/continue справа от ? : (например, cond ? log() : continue -> Error) */
```

## 3 главные ловушки урока (чек-лист для повторения)

1. Забыть шаг изменения счётчика в while (или написать условие всегда true) — получите бесконечный цикл и зависание браузера.

2. Пытаться прочитать счётчик let i или переменную из тела цикла после } — будет ReferenceError (они живут только внутри блока цикла).

3. Перепутать break (обрывает весь цикл) и continue (пропускает лишь 1 шаг) или не учесть, что while без единого выполнения пропустит тело при false, а do..while — нет.

## Вопросы для закрепления

**1. Какие числа выведут эти два цикла `while` и почему наборы отличаются?**

```js
let a = 0;
while (++a < 4) console.log(a);

let b = 0;
while (b++ < 4) console.log(b);
```

<details>
<summary>Показать ответ</summary>

Первый цикл выведет **`1, 2, 3`**, а второй — **`1, 2, 3, 4`**.
1. В `++a < 4` префикс сначала увеличивает `a`, и в сравнение уходит уже новое число: на `a = 4` условие `4 < 4` ложно, поэтому цикл останавливается.
2. В `b++ < 4` постфикс отдаёт в сравнение **старое** значение `b` (`3 < 4` даёт `true`), но к моменту запуска `console.log(b)` переменная уже выросла до `4` и выводится на экран.

</details>

**2. Изменится ли вывод в `for (let i = 0; i < 3; i++)`, если заменить `i++` на `++i`, и что произойдёт при вызове `console.log(i)` сразу после цикла?**

<details>
<summary>Показать ответ</summary>

Вывод цикла **не изменится** (`0, 1, 2`), потому что «шаг» в `for` выполняется отдельно после тела цикла, а возвращённое им значение никуда не записывается. А вызов `console.log(i)` после закрывающей скобки `}` выбросит **`ReferenceError: i is not defined`** — переменная `let i` существует только внутри области видимости цикла.

</details>

**3. Сколько раз сработает `do..while` при изначально ложном условии и чем `break` отличается от `continue`?**

<details>
<summary>Показать ответ</summary>

Цикл `do..while` всегда выполняется **минимум 1 раз**, так как проверка условия стоит в самом конце (а обычный `while` при ложном условии не сработает ни разу). Оператор `continue` обрывает только текущую итерацию и сразу переходит к следующей, тогда как `break` полностью завершает весь цикл (а для выхода из внешнего вложенного цикла используют метку `label:`).

</details>

**Задача 1. Чётные числа и их сумма через `for` и `continue`**

Напиши цикл `for` от `1` до `10` включительно. С помощью `continue` пропускай все нечётные числа, выводи в консоль только чётные (`2, 4, 6, 8, 10`), накапливай их сумму в `evenSum` и в конце выведи итоговую сумму (`30`).

```js
'use strict';

let evenSum = 0;

/* Твоё решение: */

console.log(`Сумма чётных: ${evenSum}`);
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

let evenSum = 0;

/*
  Перебираем числа от 1 до 10; переменная i объявлена через let
  и видна только внутри тела цикла
*/
for (let i = 1; i <= 10; i++) {
  /*
    Если остаток от деления на 2 не равен 0 — число нечётное:
    continue сразу прерывает шаг и переходит к i++
  */
  if (i % 2 !== 0) continue;

  console.log(i); /* выведет: 2, 4, 6, 8, 10 */
  evenSum += i;   /* прибавляем чётное число к общей сумме */
}

console.log(`Сумма чётных: ${evenSum}`); /* Сумма чётных: 30 */
```

</details>

**Задача 2. Повторяй ввод числа больше `100` (`do..while`)**

Напиши цикл `do..while`, который запрашивает у пользователя число через `prompt('Введите число больше 100:', '')` до тех пор, пока он не введёт число строго больше `100` (не забудь также отловить нечисловой ввод вроде `'abc'`) или не отменит ввод (Cancel / пустая строка). После цикла выведи принятое число или `'Ввод отменён'`.

```js
'use strict';

let rawInput;

/* Твоё решение: */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

let rawInput;

/*
  do..while подходит идеально: нам нужно спросить пользователя минимум 1 раз,
  а уже потом решать, повторять ли запрос
*/
do {
  rawInput = prompt('Введите число больше 100:', '');
} while (
  /*
    Продолжаем цикл, только если пользователь НЕ нажал Cancel (null) и НЕ оставил
    пустую строку (''), а выражение +rawInput > 100 ложно (ловит и <= 100, и NaN)
  */
  rawInput !== null && rawInput !== '' && !(+rawInput > 100)
);

if (rawInput === null || rawInput === '') {
  console.log('Ввод отменён');
} else {
  console.log(`Принято число: ${+rawInput}`);
}
```

</details>

**Задача 3. Простые числа через вложенный цикл и метку `label`**

Выведи в консоль все простые числа от `2` до `limit` включительно (`2, 3, 5, 7, 11, 13, 17, 19`) — это числа, которые делятся без остатка только на `1` и сами на себя. Используй внешний цикл `for` с меткой `nextPrime:`, внутренний цикл `for` по делителям `j` и команду `continue nextPrime`.

```js
'use strict';

const limit = 20;

/* Твоё решение: */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

const limit = 20;

/*
  Метка nextPrime позволяет внутреннему циклу перескочить сразу
  на следующую итерацию внешнего цикла, если нашёлся делитель
*/
nextPrime:
for (let i = 2; i <= limit; i++) {
  /*
    Проверяем возможные делители от 2 до i - 1.
    Как только i делится нацело (остаток 0) — оно не простое, бросаем проверку
  */
  for (let j = 2; j < i; j++) {
    if (i % j === 0) continue nextPrime;
  }

  /* Если ни один делитель не сработал — выводим простое число */
  console.log(i);
}
```

</details>
