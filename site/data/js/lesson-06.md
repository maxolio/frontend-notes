# Урок 06. Функции alert, prompt, confirm и конструкция switch / case

Суть урока: Модалки alert(), prompt() и confirm() ставят код на паузу (prompt отдаёт строку или null при отмене, confirm — true/false); в switch/case без break после совпадения выполняются все следующие ветки подряд.

## 1. Модальные окна браузера: alert, prompt и confirm (00:25–05:40)

[+] Все три функции останавливают выполнение JS до закрытия окна. В продакшене их не используют (окно нельзя стилизовать), но они удобны в обучении и быстрых тестах.

```js
alert('Привет'); /* выводит только 1-й аргумент, приводя его к строке */

/* prompt(вопрос, значениеПоУмолчанию) -> возвращает строку или null при Cancel/Esc: */
const rawAge = prompt('Сколько тебе лет?', 18);
/* Совет: задавайте 2-й аргумент ("") — в старом IE без него в поле писалось "undefined"; */
/* отмену проверяйте явно: if (rawAge === null) ... (пустой OK даст "", а +"" === 0!) */
const userAge = +rawAge; /* если нужно число, приводим! Но +null === 0! */

/* confirm(вопрос) -> две кнопки (OK и Cancel), всегда возвращает boolean: */
const isUserReady = confirm('Готов начать?'); /* OK -> true, Cancel/Esc -> false */
```

## 2. Конструкция switch / case и зачем нужен break (05:41–08:29)

[!] switch сравнивает значение в (...) с каждым case. Если в конце case забыть break, JS «провалится» и выполнит все следующие ветки подряд, даже не проверяя их условия!

```js
const age = +prompt('Ваш возраст?', '');
/* ВНИМАНИЕ: в switch сравнение СТРОГОЕ (===)! Строка "0" НЕ совпадёт с case 0! */

/* Вариант 1 — точное совпадение (и группировка нескольких case без break): */
switch (age) {
  case 0:
    console.log('Такого возраста не бывает');
    break; /* обязателен, иначе провалится в следующий case! */
  case 1:
  case 2:
    console.log('Один или два года');
    break;
  case 18:
    console.log('Не верю, покажи паспорт');
    break;
  default:
    /* Если поставить default в середине без break, он провалится в следующий case! */
    console.log(`Твой возраст: ${age}`); /* сработает, если ничего не подошло */
}

/* Вариант 2 — проверка диапазонов/условий через switch (true): */
switch (true) {
  case age < 1: console.log('Малыш'); break;
  case age > 125: console.log('Вампир?'); break;
}
```

## 3 главные ловушки урока (чек-лист для повторения)

1. Забыть, что prompt() возвращает строку (введённый "0" не равен числу 0 без + или Number), а нажатие Cancel / Esc возвращает null (и +null превратится в 0!).

2. Пропустить break внутри case в switch — после первого совпадения выполнятся все нижестоящие case и даже блок default.

3. Передать в alert(a, b) несколько аргументов как в console.log — alert покажет только первый и заморозит весь JS-код до нажатия ОК.

## Вопросы для закрепления

**1. Что окажется в `age`, если при вызове `const age = +prompt('Возраст?', '');` пользователь нажмёт Cancel или просто OK с пустым полем?**

<details>
<summary>Показать ответ</summary>

В обоих случаях в `age` запишется число **`0`**. При отмене (Cancel/Esc) `prompt` возвращает `null`, а при пустом OK — строку `""`. Унарный `+` превращает и `null`, и `""` в `0`, поэтому отмену нужно проверять **до** приведения к числу (`rawAge === null`).

</details>

**2. Что выведется в консоль, если пользователь введёт в `prompt` цифру `1`?**

```js
const step = prompt('Шаг (1 или 2)?', '');

switch (step) {
  case 1:
    console.log('Первый');
  case 2:
    console.log('Второй');
  default:
    console.log('Другой');
}
```

<details>
<summary>Показать ответ</summary>

Выведется только **`'Другой'`**. Оператор `switch` сравнивает значения **строго (`===`)**: `prompt` вернул строку `'1'`, а `'1' === 1` даёт `false`, поэтому сработала ветка `default`. А если бы `step` стал числом `1` (через `+prompt`), то из-за забытых `break` выполнились бы все три `console.log` подряд.

</details>

**3. Что покажет окно `alert('Сумма:', 100 + 200)` и почему встроенные модалки не используют в реальных сайтах?**

<details>
<summary>Показать ответ</summary>

Окно покажет только **`'Сумма:'`**: в отличие от `console.log`, `alert` принимает лишь первый аргумент и игнорирует остальные (для вывода нескольких значений собирают одну строку через бэктики `` `Сумма: ${100 + 200}` ``). В продакшене их не берут, потому что эти окна нельзя стилизовать через CSS, а сам JS-код полностью встаёт на паузу, пока пользователь не нажмёт кнопку.

</details>

## Задачи

**Задача 1. Безопасная работа с `prompt`, `confirm` и `alert`**

Запроси у пользователя количество билетов через `prompt` (по умолчанию `''`). Сначала обработай отмену (`null`) и пустой ввод (`''`), чтобы они не превратились в `0` после `+`. Если введено корректное число больше `0`, уточни через `confirm` наличие скидки (цена билета `400` со скидкой или `500` без неё) и покажи итоговую сумму в `alert` одной строкой, а при некорректном числе — ошибку.

```js
'use strict';

const rawTickets = prompt('Сколько билетов нужно?', '');

/* Твоё решение: */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

const rawTickets = prompt('Сколько билетов нужно?', '');

/*
  Отсекаем Cancel (null) и пустой OK ('') ДО приведения к числу,
  чтобы +null и +'' не превратились незаметно в 0
*/
if (rawTickets === null || rawTickets === '') {
  alert('Заказ отменён');
} else {
  const tickets = +rawTickets;

  /* !tickets поймает 0 и NaN (если ввели буквы вроде 'abc') */
  if (!tickets || tickets <= 0) {
    alert('Введите число больше 0');
  } else {
    /* confirm возвращает boolean: OK -> true, Cancel -> false */
    const hasDiscount = confirm('У вас есть карта скидок?');
    const ticketPrice = hasDiscount ? 400 : 500;

    /* Передаём в alert готовую шаблонную строку одним аргументом */
    alert(`К оплате: ${tickets * ticketPrice} руб.`);
  }
}
```

</details>

**Задача 2. Перепиши цепочку `if` на `switch` с группировкой**

Перепиши три отдельных `if` на одну конструкцию `switch`. Приведи ввод из `prompt` к числу, объедини варианты `2` и `3` через группировку `case` без дублирования кода, расставь `break` и добавь `default` для всех остальных значений.

```js
'use strict';

/* Твоё решение: */
const grade = prompt('Оцените сервис от 1 до 3', '');

if (grade === '1') {
  console.log('Плохо');
}
if (grade === '2' || grade === '3') {
  console.log('Нормально или хорошо');
}
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

/* Приводим строку к числу, так как switch сравнивает строго (===) */
const grade = +prompt('Оцените сервис от 1 до 3', '');

switch (grade) {
  case 1:
    console.log('Плохо');
    break; /* прерываем switch, чтобы выполнение не ушло в case 2 */

  /* Группировка: у case 2 нет break, поэтому 2 и 3 ведут к одному блоку */
  case 2:
  case 3:
    console.log('Нормально или хорошо');
    break;

  default:
    /* Сработает для любого другого ввода, включая 0 (Cancel) и NaN */
    console.log('Оценка не распознана');
}
```

</details>

**Задача 3. Почини «проваливающийся» `switch` и добавь `switch (true)`**

Первый `switch` сравнивает строку `'1'` с числом `1` и забывает `break` — исправь его так, чтобы в консоль вывелось только `'Администратор'`. Ниже напиши второй `switch (true)` для переменной `age`: до `18` выводи `'Доступ с 18'`, от `18` до `65` включительно — `'Полный доступ'`, иначе — `'Пенсионный тариф'`.

```js
'use strict';

const roleCode = '1';
const age = 25;

/* Твоё решение: */
switch (roleCode) {
  case 1:
    console.log('Администратор');
  case 2:
    console.log('Редактор');
  default:
    console.log('Гость');
}

/* Ниже добавь switch (true) для проверки диапазонов age: */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

const roleCode = '1';
const age = 25;

/*
  Приводим roleCode к числу через унарный +, чтобы '1' совпала с case 1,
  и ставим break в конце веток против проваливания кода вниз
*/
switch (+roleCode) {
  case 1:
    console.log('Администратор');
    break;
  case 2:
    console.log('Редактор');
    break;
  default:
    console.log('Гость');
}

/*
  switch (true) ищет первый case, чьё логическое выражение вернёт true —
  удобный способ проверять числовые диапазоны
*/
switch (true) {
  case age < 18:
    console.log('Доступ с 18');
    break;
  case age >= 18 && age <= 65:
    console.log('Полный доступ');
    break;
  default:
    console.log('Пенсионный тариф');
}
```

</details>
