# Урок 06. Функции `alert`, `prompt`, `confirm` и конструкция `switch` / `case`

Суть урока:

- **Модалки браузера:** `alert()`, `prompt()` и `confirm()` ставят скрипт на паузу (`prompt` вернёт строку или `null`, `confirm` — `true`/`false`).
- **Конструкция `switch` / `case`:** сравнивает значения строго (`===`), а без `break` после первого совпадения выполняет все следующие ветки подряд.

## 1. Модальные окна браузера: `alert`, `prompt` и `confirm` (00:25–05:40)

[+] Все три функции замораживают выполнение JS до закрытия окна. В реальных сайтах их не используют (окно нельзя стилизовать через CSS), но они удобны в обучении и быстрых тестах.

| Функция | Назначение | Вернёт при `OK` | Вернёт при `Cancel` / `Esc` |
| :--- | :--- | :--- | :--- |
| `alert(msg)` | Показать сообщение | `undefined` | `undefined` |
| `prompt(msg, def)` | Запросить текст | Введённая строка (`''`, если пусто) | `null` |
| `confirm(msg)` | Запросить да/нет | `true` | `false` |

```js
/* alert показывает только 1-й аргумент, приводя его к строке */
alert('Привет');

/* prompt(вопрос, текстПоУмолчанию) возвращает строку или null */
const rawAge = prompt('Сколько тебе лет?', '');

/*
  Отмену (null) и пустой ввод ('') проверяем ДО приведения к числу,
  иначе +null и +'' молча превратятся в 0
*/
if (rawAge === null || rawAge === '') {
  console.log('Ввод отменён');
} else {
  const userAge = +rawAge;
  console.log(`Возраст: ${userAge}`);
}

/* confirm(вопрос) всегда возвращает boolean: OK -> true, Cancel -> false */
const isUserReady = confirm('Готов начать?');
```

## 2. Конструкция `switch` / `case` и зачем нужен `break` (05:41–08:29)

[!] Оператор `switch` сравнивает значение в `(...)` с каждым `case` строго через `===`. Если в конце `case` забыть `break`, JS «провалится» и выполнит все следующие ветки подряд, не проверяя их условия.

```js
/* ВНИМАНИЕ: сравнение в switch СТРОГОЕ (===)! '0' НЕ совпадёт с case 0 */
const age = +prompt('Ваш возраст?', '');

/* Вариант 1: точное совпадение и группировка case без break */
switch (age) {
  case 0:
    console.log('Такого возраста не бывает');
    break; /* обязателен, иначе код провалится в case 1 */
  case 1:
  case 2:
    console.log('Один или два года');
    break;
  case 18:
    console.log('Не верю, покажи паспорт');
    break;
  default:
    /* Если default стоит не последним, ему тоже нужен break */
    console.log(`Твой возраст: ${age}`);
}

/* Вариант 2: проверка диапазонов через switch (true) */
switch (true) {
  case age < 1:
    console.log('Малыш');
    break;
  case age > 125:
    console.log('Вампир?');
    break;
}
```

[+] Когда что выбирать: для сравнения **одной переменной** с конкретными значениями (`1`, `2`, `'admin'`) бери `switch`, а для диапазонов (`age >= 18`) и составных условий (`&&`, `||`) на практике чаще используют `if` / `else if`.

[+] На вырост (`return` в `switch` и циклах): команда `return` работает **только внутри функции** (вне функции JS выдаст `SyntaxError`). Когда дойдём до функций в Уроке 08, внутри `switch` или цикла в функции можно будет писать `return` вместо `break` — он сразу вернёт результат и завершит функцию.

## 3 главные ловушки урока (чек-лист для повторения)

1. Забыть, что `prompt()` всегда возвращает строку (`'0'` не совпадёт с `case 0` без `+` или `Number()`), а при нажатии `Cancel` / `Esc` возвращает `null` (и `+null` превратится в `0`).
2. Пропустить `break` внутри `case` в `switch` — после первого совпадения выполнятся все нижестоящие `case` и даже блок `default`.
3. Передать в `alert(a, b)` несколько аргументов как в `console.log()` — `alert` покажет только первый и поставит весь JS на паузу до нажатия `OK`.

## Вопросы для закрепления

**1. Что окажется в `age`, если при вызове `const age = +prompt('Возраст?', '');` пользователь нажмёт Cancel или просто OK с пустым полем?**

<details>
<summary>Показать ответ</summary>

В обоих случаях в `age` запишется число **`0`** (`+null` и `+''` дают `0`).

**Как делать НЕ надо (ловушка):**

```js
const age = +prompt('Сколько тебе лет?', '');
/*
  Нажал Отмена -> +null -> 0
  Нажал OK на пустом поле -> +'' -> 0
  Итог: программа думает, что пользователю 0 лет
*/
```

**Как правильно (проверяем ДО плюса):**

```js
const rawAge = prompt('Сколько тебе лет?', ''); /* пока строка или null */

if (rawAge === null) {
  console.log('Ввод отменён'); /* нажали Cancel или Esc */
} else if (rawAge === '') {
  console.log('Ты ничего не ввёл'); /* нажали OK на пустом поле */
} else {
  const age = +rawAge; /* превращаем в число ТОЛЬКО здесь */
  console.log(`Твой возраст: ${age}`);
}
```

</details>

**2. Что выведется в консоль, если пользователь введёт в `prompt` цифру `1`?**

```js
const step = prompt('Шаг (1 или 2)?', '');

switch (step) {
  case 1:
    console.log('Первый');
  case 2:
    console.log('Второй');
  default:
    console.log('Другой');
}
```

<details>
<summary>Показать ответ</summary>

Выведется только **`'Другой'`**. Оператор `switch` сравнивает значения **строго (`===`)**: `prompt` вернул строку `'1'`, а `'1' === 1` даёт `false`, поэтому сработала ветка `default`. А если бы `step` стал числом `1` (через `+prompt`), то из-за забытых `break` выполнились бы все три `console.log` подряд.

</details>

**3. Что покажет окно `alert('Сумма:', 100 + 200)` и почему встроенные модалки не используют в реальных сайтах?**

<details>
<summary>Показать ответ</summary>

Окно покажет только **`'Сумма:'`**: в отличие от `console.log`, `alert` принимает лишь первый аргумент и игнорирует остальные (для вывода нескольких значений собирают одну шаблонную строку вида `Сумма: ${100 + 200}`). В продакшене их не берут, потому что эти окна нельзя стилизовать через CSS, а сам JS-код полностью встаёт на паузу, пока пользователь не нажмёт кнопку.

</details>

**Задача 1. Безопасная работа с `prompt`, `confirm` и `alert`**

Нужно безопасно рассчитать стоимость билетов по вводу пользователя:

1. До приведения к числу проверь отмену (`rawTickets === null`) и пустой ввод (`rawTickets === ''`) — в этом случае покажи `alert('Заказ отменён')`.
2. Приведи `rawTickets` к числу: если получилось некорректное значение (`!tickets || tickets <= 0`), покажи `alert('Введите число больше 0')`.
3. Иначе спроси через `confirm` наличие скидки (`400` руб. со скидкой или `500` руб. без неё) и выведи итоговую сумму в `alert` одной строкой.

Проверка: при вводе `'3'` и `OK` в `confirm` появится `alert('К оплате: 1200 руб.')`; при нажатии `Cancel` в `prompt` — `alert('Заказ отменён')`.

```js
'use strict';

const rawTickets = prompt('Сколько билетов нужно?', '');

/* Твоё решение: */
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

const rawTickets = prompt('Сколько билетов нужно?', '');

/*
  Отсекаем Cancel (null) и пустой OK ('') ДО приведения к числу,
  чтобы +null и +'' не превратились незаметно в 0
*/
if (rawTickets === null || rawTickets === '') {
  alert('Заказ отменён');
} else {
  const tickets = +rawTickets;

  /* !tickets поймает 0 и NaN (если ввели буквы вроде 'abc') */
  if (!tickets || tickets <= 0) {
    alert('Введите число больше 0');
  } else {
    /* confirm возвращает boolean: OK -> true, Cancel -> false */
    const hasDiscount = confirm('У вас есть карта скидок?');
    const ticketPrice = hasDiscount ? 400 : 500;

    /* Передаём в alert готовую шаблонную строку одним аргументом */
    alert(`К оплате: ${tickets * ticketPrice} руб.`);
  }
}
```

</details>

**Задача 2. Перепиши цепочку `if` на `switch` с группировкой**

Замени отдельные `if` на одну конструкцию `switch`:

1. Приведи ввод из `prompt` к числу через унарный `+`.
2. Для `1` выведи `'Плохо'`, а варианты `2` и `3` сгруппируй в один блок `'Нормально или хорошо'` без дублирования кода.
3. Расставь `break` и добавь ветку `default` с текстом `'Оценка не распознана'`.

Проверка: при вводе `'1'` выведется `'Плохо'`, при `'2'` или `'3'` — `'Нормально или хорошо'`, при `'5'` или `Cancel` — `'Оценка не распознана'`.

```js
'use strict';

/* Твоё решение: */
const grade = prompt('Оцените сервис от 1 до 3', '');

if (grade === '1') {
  console.log('Плохо');
}
if (grade === '2' || grade === '3') {
  console.log('Нормально или хорошо');
}
```

<details>
<summary>Подсказка и решение</summary>

```js
'use strict';

/* Приводим строку к числу, так как switch сравнивает строго (===) */
const grade = +prompt('Оцените сервис от 1 до 3', '');

switch (grade) {
  case 1:
    console.log('Плохо');
    break; /* прерываем switch, чтобы выполнение не ушло в case 2 */

  /* Группировка: у case 2 нет break, поэтому 2 и 3 ведут к одному блоку */
  case 2:
  case 3:
    console.log('Нормально или хорошо');
    break;

  default:
    /* Сработает для любого другого ввода, включая 0 (Cancel) и NaN */
    console.log('Оценка не распознана');
}
```

</details>
