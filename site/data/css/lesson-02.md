# Урок 02. Все виды селекторов, комбинаторы и расчёт специфичности

Суть урока: базовый рабочий инструмент в CSS — селектор по классу (`.card`) со средней специфичностью `0-1-0`; для точечных выборок есть селекторы атрибутов и комбинаторы (пробел, `>`, `+`, `~`), а итоговый вес сравнивается по трём разрядам слева направо.

## 1. Базовые селекторы: тег, класс и ID (00:15–01:57)

[+] Селектор по тегу выбирает все такие теги на странице; класс (`.red`) переиспользуется и задаётся списком через пробел в HTML; ID (`#header`) уникален на странице и сильно завышает вес, поэтому в стилях его избегают (оставляя для якорей и JS).

| Селектор | Пример | Вес `(A-B-C)` | Когда использовать |
| --- | --- | --- | --- |
| По тегу | `p` | `0-0-1` | Базовые стили и сбросы |
| По классу | `.card` | `0-1-0` | Основной рабочий инструмент |
| По ID | `#hero` | `1-0-0` | Избегать в CSS (слишком тяжёлый) |

[!] Порядок имён внутри HTML-атрибута `class="red blue"` **не влияет** на приоритет. При равном весе победит то правило, которое написано **ниже в CSS-файле**.

<!-- demo-html:
<p>Обычный &lt;p&gt; (тег)</p>
<p class="red blue">&lt;p class="red blue"&gt; (победит .red, т.к. ниже)</p>
<p id="hero" class="red">&lt;p id="hero" class="red"&gt; (победит #hero)</p>
-->
```css
/* По тегу: применится ко всем <p> на странице (вес 0-0-1) */
p {
  color: red;
}

/* По классу: переиспользуется, пишется через точку (0-1-0) */
.blue {
  color: blue;
}

/* У <p class="red blue"> победит .red — оно ниже в CSS */
.red {
  color: red;
}

/* По ID: высокий вес (1-0-0), в стилях обычно избегают */
#hero {
  color: navy;
}
```

## 2. Селекторы по атрибуту и модификаторы (01:58–06:53)

[+] Позволяют находить элементы по любому HTML-атрибуту в квадратных скобках `[attr]` (вес как у класса — `0-1-0`). Спецсимволы перед `=` работают как фильтры подстроки, а флаг `i` отключает регистр (только для латиницы).

| Селектор | Что проверяет | Пример |
| --- | --- | --- |
| `[attr]` | Атрибут просто есть | `[placeholder]` |
| `[attr="val"]` | Точное совпадение значения | `[type="email"]` |
| `[attr*="val"]` | Подстрока в любом месте | `[href*="habr"]` |
| `[attr^="val"]` | Значение начинается с `val` | `[href^="https://"]` |
| `[attr$="val"]` | Значение оканчивается на `val` | `[href$=".ru"]` |
| `[attr~="val"]` | Отдельное слово через пробел | `[alt~="cat"]` |
| `[attr\|="val"]` | Точно `val` или `val-...` | `[class\|="warning"]` |
| `[attr*="val" i]` | Игнор регистра (латиница) | `[alt*="cat" i]` |

<!-- demo-html:
<div style="display:flex;flex-direction:column;gap:6px;font-size:14px;align-items:flex-start;">
  <input placeholder="Есть [placeholder]" />
  <input type="email" value="test@mail.com" />
  <a href="http://habr.com/posts">http://habr.com/posts (подстрока habr)</a>
  <a href="https://example.org">https://example.org (начинается с https://)</a>
  <a href="http://site.ru">http://site.ru (оканчивается на .ru)</a>
  <div style="display:flex;gap:8px;align-items:center;">
    <img src="data:image/svg+xml;utf8,<svg xmlns='http://www.w3.org/2000/svg' width='68' height='26'><rect width='68' height='26' fill='%23fef3c7'/><text x='6' y='17' font-size='11'>my cat</text></svg>" alt="my cat" />
    <img src="data:image/svg+xml;utf8,<svg xmlns='http://www.w3.org/2000/svg' width='68' height='26'><rect width='68' height='26' fill='%23e0e7ff'/><text x='10' y='17' font-size='11'>BIG CAT</text></svg>" alt="BIG CAT" />
  </div>
  <span class="warning-text">class="warning-text" ([class|="warning"])</span>
</div>
-->
```css
/* Есть атрибут placeholder с любым значением */
[placeholder] {
  border-color: skyblue;
}

/* Точное совпадение (кавычки обязательны при пробелах/символах) */
[type="email"] {
  box-shadow: 0 0 3px navy;
}

/* * — подстрока в любом месте значения */
[href*="habr"] {
  color: green;
}

/* ^ — значение начинается с указанной строки */
[href^="https://"] {
  color: darkgreen;
}

/* $ — значение оканчивается на указанную строку */
[href$=".ru"] {
  color: navy;
}

/* ~ — отдельное слово, отделённое пробелами */
[alt~="cat"] {
  border: 2px solid tan;
}

/* | — точно "warning" или "warning-..." с дефисом */
[class|="warning"] {
  color: orange;
}

/* i — игнор регистра (работает только для латиницы) */
[alt*="cat" i] {
  opacity: 0.75;
}
```

## 3. Универсальный селектор `*` (06:54–07:42)

[+] Выбирает все HTML-элементы (часто используют в сбросах и `box-sizing`), имеет нулевой вес `0-0-0` и не затрагивает псевдоэлементы `::before` и `::after` (Урок 13).

[!] Не задавайте в `*` наследуемые свойства вроде `color` или `font-family` — лучше ставить их на `<body>`. Даже при весе `0-0-0` правило `* { color: black; }` бьёт по каждому `<p>` **напрямую** и перебивает наследование от `<header>` или `<section>`.

```css
/* Вес 0-0-0 (слабее тега p); ::before и ::after не затрагивает */
* {
  margin: 0;
}
```

## 4. Комбинаторы, группировка и объединение классов (07:43–11:44)

[+] Комбинаторы связывают селекторы по положению в DOM-дереве и сами по себе **не добавляют веса**. Не путайте `.btn.is-active` (оба класса на одном теге) и `.btn .is-active` (вложенность).

| Запись | Роль | Что выбирает |
| --- | --- | --- |
| `.a.b` | Объединение | Один элемент сразу с двумя классами |
| `A B` | Потомок | Любой `B` внутри `A` на любой глубине |
| `A > B` | Прямой ребёнок | `B` только на 1-м уровне внутри `A` |
| `A + B` | Ближайший сосед | Первый `B` сразу после `A` на том же уровне |
| `A ~ B` | Все братья | Все следующие `B` после `A` на том же уровне |

[!] В группировке через запятую (`h1, h2, h3`) специфичность считается **отдельно** для каждого селектора. Если хотя бы один селектор в списке синтаксически сломан, браузер отбросит **всё правило целиком**. На вырост: «прощающие» списки `:is()` и `:where()` разберём в уроках 05 и 14.

<!-- demo-html:
<style>.error-message{visibility:hidden;color:crimson;font-size:13px;}</style>
<section style="border:1px solid #cbd5e1;padding:8px;border-radius:6px;">
  <h2>Прямой &lt;h2&gt; (синий)</h2>
  <div><h2>Вложенный &lt;h2&gt; (не синий)</h2></div>
  <p>Параграф после &lt;h2&gt; (серый)</p>
  <button class="button is-active" type="button">.button.is-active</button>
  <input class="input is-invalid" value="Неверный ввод" />
  <span class="error-message">Ошибка ввода!</span>
</section>
-->
```css
/* Группировка через запятую: вес каждого считается отдельно */
h1,
h2,
h3 {
  color: #222;
}

/* Объединение без пробела: оба класса на одном элементе */
.button.is-active {
  background: coral;
}

/* Потомок (пробел): любой <p> внутри <section> */
section p {
  color: #333;
}

/* Прямой ребёнок (>): только <h2> на 1-м уровне ниже */
section > h2 {
  color: blue;
}

/* Ближайший сосед (+): сразу после .input.is-invalid */
.input.is-invalid + .error-message {
  visibility: visible;
}

/* Все следующие братья (~) на том же уровне после <h2> */
h2 ~ p {
  color: gray;
}
```

## 5. Специфичность селекторов: 3 разряда веса (11:45–15:15)

[+] Вес селектора состоит из трёх счётчиков `(A-B-C)`: `A` — число `#id`, `B` — число `.class`, `[attr]` и `:псевдоклассов`, `C` — число тегов и `::псевдоэлементов`. Разряды сравниваются слева направо (как версии `1.0.0 > 0.20.0`), а не как десятичное число.

| Селектор | Вес `(A-B-C)` | Из чего сложился |
| --- | --- | --- |
| `*` | `0-0-0` | Универсальный и комбинаторы дают `0` |
| `p` | `0-0-1` | `1` тег |
| `section > p` | `0-0-2` | `2` тега (`>` веса не добавляет) |
| `.text` | `0-1-0` | `1` класс (основа для проектов) |
| `p.text[title]` | `0-2-1` | `1` класс + `1` атрибут + `1` тег |
| `#lead` | `1-0-0` | `1` ID (сильнее `20` классов `0-20-0`) |
| `p#lead.text` | `1-1-1` | `1` ID + `1` класс + `1` тег |

[+] Быстрая проверка в браузере: открой DevTools → `Elements` → `Styles` и наведи курсор на любой селектор — браузер покажет всплывающую подсказку с точным весом `(A, B, C)`. На вырост: инлайн `style="..."` и `!important` стоят выше этой шкалы, а `:where()` всегда даёт `0-0-0` (Урок 05).

## 3 главные ловушки урока (чек-лист для повторения)

1. Считать специфичность десятичным числом: даже `15` классов (`0-15-0`) не перебьют один `#id` (`1-0-0`), так как разряды сравниваются слева направо.

2. Поставить лишний пробел между классами: `.btn.active` ищет один элемент с двумя классами, а `.btn .active` — вложенный `.active` внутри `.btn`.

3. Ждать от `[alt*="кот" i]` игнорирования регистра в кириллице или путать `[attr~="word"]` (целое слово через пробел) с `[attr*="word"]` (любая подстрока).

## Вопросы для закрепления

**1. Какого цвета станет `<p>` и почему? (Разбери вес обоих селекторов в формате `A-B-C`.)**

```html
<div id="box">
  <p class="text lead">Привет</p>
</div>
```

```css
#box p {
  color: navy;
}

p.text.lead {
  color: crimson;
}
```

<details>
<summary>Показать ответ</summary>

Текст станет **тёмно-синим (`navy`)**. Вес `#box p` равен `1-0-1` (`1` ID + `1` тег), а вес `p.text.lead` равен `0-2-1` (`2` класса + `1` тег). Разряды сравниваются строго слева направо (как версии `1.0.1 > 0.2.1`) и не складываются в десятичное число — даже `12` классов (`0-12-0`) проиграют одному `#id` (`1-0-0`).

</details>

**2. Чем отличаются `.btn.is-active`, `.btn .is-active` и `.btn > .is-active`? Влияет ли на результат порядок классов в `class="is-active btn"`?**

<details>
<summary>Показать ответ</summary>

- `.btn.is-active` (без пробела) выбирает **один** элемент, на котором указаны сразу оба класса; порядок слов в `class="is-active btn"` в HTML вообще **не важен**.
- `.btn .is-active` ищет `.is-active` внутри `.btn` на любой глубине вложенности.
- `.btn > .is-active` ищет `.is-active` только среди **прямых детей** `.btn`.
- Специфичность у всех трёх селекторов одинаковая — `0-2-0`, так как комбинаторы (` ` и `>`) веса не добавляют.

</details>

**3. В чём разница между `[alt~="cat"]`, `[alt*="cat"]` и `[alt|="cat"]` на строке `alt="cat-2 blackcat"`?**

<details>
<summary>Показать ответ</summary>

- `[alt*="cat"]` — **сработает** (ищет подстроку `cat` в любом месте).
- `[alt~="cat"]` — **не сработает** (ищет отдельное слово `cat`, отделённое пробелами, а тут `cat-2` и `blackcat`).
- `[alt|="cat"]` — **сработает**, потому что вся строка атрибута начинается с `cat-` (значение либо равно `cat`, либо начинается с `cat-`).

</details>

**Задача 1. Селекторы по атрибуту для умной стилизации ссылок и картинок**

Нужно визуально разделить ссылки по протоколу/формату и выделить нужные аватары, не добавляя новых классов в HTML.

1. Ссылкам `<a>`, у которых `href` начинается с `https://`, задай цвет `green`.
2. Ссылкам `<a>`, у которых `href` начинается с `http://`, задай цвет `red`.
3. Ссылкам `<a>`, у которых `href` оканчивается на `.pdf` в любом регистре (`pdf` / `PDF`), задай фон `background-color: gold`.
4. Картинкам `<img>`, у которых в `alt` есть отдельное слово `avatar` (но не `avatars`), задай рамку `border: 2px solid navy`.

Проверка: первая ссылка зелёная, вторая красная, третья с золотым фоном, а синяя рамка появилась только вокруг первой картинки (`user avatar`).

```html
<a href="https://example.com">Безопасная ссылка</a>
<a href="http://example.com">Небезопасная ссылка</a>
<a href="/docs/guide.PDF">Инструкция PDF</a>

<img src="u2.png" alt="avatars list" />
```

```css
img[alt~="avatar"] {

}
```

**Задача 2. Комбинаторы прямого ребёнка (`>`) и соседей (`+`, `~`)**

Есть карточка `<section class="card">` с вложенным заголовком, полем с ошибкой и примечаниями. Стилизуй нужные элементы точечно через комбинаторы.

1. Покрась в `blue` только прямой `<h2>` внутри `.card`, не задев `<h2>` внутри вложенного `<div>`.
2. Скрой все `.error-message` через `visibility: hidden`, а для `.input` с классом `.is-invalid` покажи (`visibility: visible`) только ближайший следующий `.error-message`.
3. Сделай серыми (`color: gray`) все параграфы `<p>`, идущие на том же уровне после `<h3>`.

Проверка: «Заголовок карточки» стал синим, «Вложенный подзаголовок» остался чёрным, из двух ошибок видна только «Ошибка ввода», а оба комментария после `<h3>` стали серыми.

```html
<section class="card">
  <h2>Заголовок карточки</h2>
  <div>
    <h2>Вложенный подзаголовок</h2>
  </div>

  <input class="input is-invalid" type="text" />
  <span class="error-message">Ошибка ввода</span>
  <span class="error-message">Запасная подсказка</span>

  <h3>Примечания</h3>
  <p>Первый комментарий</p>
  <p>Второй комментарий</p>
</section>
```

<details>
<summary>Подсказка и решение</summary>

```css
/* Комбинатор > выбирает только прямой <h2> внутри .card */
.card > h2 {
  color: blue;
}

/* По умолчанию прячем все сообщения об ошибках */
.error-message {
  visibility: hidden;
}

/* Оба класса на <input> + ближайший следующий .error-message */
.input.is-invalid + .error-message {
  visibility: visible;
}

/* Комбинатор ~ выбирает все последующие <p> на том же уровне */
h3 ~ p {
  color: gray;
}
```

</details>

**Задача 3. Cascade Fix: расчёт веса и починка конфликта без `!important`**

На абзац `<p>` нацелены 4 конфликтующих правила, и из-за `#lead` текст стал тёмно-синим вместо бирюзового (`teal`). Почини конфликт только в CSS, не меняя HTML (`id="lead"` остаётся для якорей/JS).

1. В комментарии над каждым правилом подпиши его исходный вес `(A-B-C)` и объясни, почему сейчас побеждает `navy`.
2. Убери стилизацию по `#id`: замени `#lead` на селектор уже имеющегося класса `.lead`.
3. Добейся победы цвета `teal` у правила `.text.note` без `!important` и без удаления остальных правил.

Проверка: текст «Важный абзац» стал бирюзовым (`teal`); в DevTools → `Styles` наведи курсор на селекторы и убедись, что вес `.text.note` равен `(0, 2, 0)` и перебивает `div p.text` `(0, 1, 2)` и `.lead` `(0, 1, 0)`.

```html
<div id="app">
  <p class="text note lead" id="lead">Важный абзац</p>
</div>
```

```css
#lead {
  color: navy;
}

div p.text {
  color: crimson;
}

.text.note {
  color: teal;
}

p {
  color: black;
}
```

<details>
<summary>Подсказка и решение</summary>

```css
/* Было: #lead (1-0-0) — побеждало navy, т.к. 1 ID сильнее классов */
/* Заменяем #lead на класс .lead (0-1-0), не трогая id в HTML */
.lead {
  color: navy;
}

/* Вес 0-1-2: 1 класс и 2 тега (слабее двух классов 0-2-0) */
div p.text {
  color: crimson;
}

/* Вес 0-2-0: 2 класса во втором разряде — теперь побеждает teal */
.text.note {
  color: teal;
}

/* Вес 0-0-1: 1 тег (самое слабое правило) */
p {
  color: black;
}
```

</details>
