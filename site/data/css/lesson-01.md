# Урок 01. Единицы rem, clamp() и кастомные свойства

Суть урока: Относительная единица `rem` привязана к размеру шрифта корневого `<html>`, а функция `clamp(min, fluid, max)` позволяет масштабировать текст и отступы без лишних медиазапросов.

## 1. Базовая настройка rem и clamp()

[+] Стартовый шаблон для будущего раздела CSS: сюда легко добавлять новые уроки в папку `site/data/css/`.

```css
:root {
  --fs-body: clamp(1rem, 0.95rem + 0.3vw, 1.125rem);
  --space-card: 1.25rem;
}

body {
  font-size: var(--fs-body);
  min-height: 100dvh;
}
```

[!] При работе с `clamp()` всегда добавляй к `vw` базовый сдвиг в `rem` (`0.95rem + 0.3vw`), иначе масштаб текста пользователем в настройках браузера перестанет работать.

## 3 главные ловушки урока (чек-лист для повторения)

1. Путать `em` и `rem`: `em` множится от родителя и может «раздувать» вложенные списки, а `rem` всегда опирается на `<html>`.

2. Задавать фиксированную высоту `100vh` на мобилке: адресная строка браузера обрезает экран — используй `100dvh`.

3. Ставить `:hover` без `@media (any-hover: hover)`: на телефоне состояние hover «залипает» после нажатия.
