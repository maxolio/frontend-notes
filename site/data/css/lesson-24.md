# Урок 24. Единицы вьюпорта: `vmin`, `vmax`, `svh`, `lvh` и `dvh`

Суть урока: кроме `vw` и `vh` в CSS есть `vmin`/`vmax` (процент от меньшей/большей стороны окна), а мобильный баг с адресной строкой, перекрывающей `100vh`, сегодня решают без JS с помощью новых единиц `svh` (с панелью), `lvh` (без панели) и `dvh` (динамическая высота), добавляя `100vh` как запасной вариант строкой выше.

## 1. `vw`, `vh`, `vmin`, `vmax` и проблема `100vh` на телефонах (00:10–04:55)

[+] **`100vh`** задаёт секции высоту во весь экран без необходимости прописывать `height: 100%` для `<html>` и `<body>`. А ещё в CSS есть **`vmin`** (1% от **меньшей** из двух сторон окна — ширины или высоты) и **`vmax`** (1% от **большей** стороны).

[!] На мобильных устройствах (iOS Safari, Chrome) есть выезжающая/скрывающаяся адресная строка. Стандартный `100vh` всегда считается по максимальному размеру (как будто панель скрыта), поэтому при открытой панели нижняя часть секции `100vh` **прячется под адресной строкой**.

<!-- demo-html:
<style>
  .vp-row { display: flex; gap: 10px; align-items: center; }
  .vp-box { background: #dbeafe; border: 2px solid #2563eb; padding: 8px; font-size: 12px; font-weight: 700; display: grid; place-items: center; text-align: center; }
</style>
<div class="vp-row">
  <div class="vp-box vp-vmin">22vmin x 22vmin (всегда квадрат от меньшей стороны)</div>
</div>
-->
```css
/* Всегда впишется по меньшей стороне экрана (удобно и на портретном, и на альбомном) */
.vp-vmin {
  width: 22vmin;
  height: 22vmin;
}
```

## 2. Новые единицы: `svh`, `lvh` и `dvh` (04:56–07:20)

[+] Чтобы не писать громоздкие JS-скрипты с `window.innerHeight` и `debounce`, в CSS появились три единицы (и их широтные аналоги `svw`, `lvw`, `dvw`):
- **`svh`** (*Small Viewport Height*) — высота, когда панель браузера **показана** (гарантированно видимая область без перекрытия).
- **`lvh`** (*Large Viewport Height*) — высота, когда панель браузера **скрыта** (максимальная высота, аналог старого `vh`).
- **`dvh`** (*Dynamic Viewport Height*) — **динамическая** высота, которая сама подстраивается между `svh` и `lvh` при скролле.

[!] Три практических правила:
1) Всегда ставьте **`100vh` строкой выше** как запасной вариант (fallback) для старых браузеров.
2) Для первого экрана (Hero-секции) часто удобнее **`100svh`**, чтобы секция не дёргалась при появлении/исчезновении адресной строки; а **`100dvh`** идеален для полноэкранного меню или модального окна.
3) **Не используйте `dvh` в `font-size`** — при каждом скролле на телефоне текст начнёт скакать по размеру и нагружать браузер.

<!-- demo-html:
<style>
  .hero-sec { background: #fef3c7; border: 2px solid #b45309; padding: 12px; font-weight: 700; font-size: 13px; display: grid; place-items: center; text-align: center; }
</style>
<section class="hero-sec">Секция с fallback 100vh + min-height: 30svh</section>
-->
```css
/* Сначала fallback на 30vh, затем 30svh (на реальной странице — 100svh) */
.hero-sec {
  min-height: 30vh;
  min-height: 30svh;
}
```

## 3 главные ловушки урока (чек-лист для повторения)

1. Использовать `dvh` в `font-size` (`font-size: calc(14px + 1dvh);`) — при скролле на мобильном браузере размер шрифта начнёт постоянно пересчитываться и дёргаться.

2. Забывать `100vh` строкой перед `100dvh` / `100svh` — в старых браузерах без поддержки новых единиц правило полностью отбросится.

3. Ставить `height: 100dvh;` вместо `min-height` на секцию с контентом — при росте текста на маленьком экране контент вылезет за пределы блока.

## Вопросы для закрепления

**1. В чём разница между `100svh`, `100lvh` и `100dvh` на смартфоне?**

<details>
<summary>Показать ответ</summary>

`100svh` — это высота экрана с **открытой** панелью/адресной строкой браузера (наименьшая видимая область). `100lvh` — высота со **скрытой** панелью (наибольшая область). `100dvh` динамически переключается между ними в зависимости от того, видна ли панель в данный момент.

</details>

**2. Почему для Hero-секции на главной странице часто предпочитают `min-height: 100svh;`, а не `100dvh`?**

<details>
<summary>Показать ответ</summary>

При использовании `100dvh` высота секции немного скачет вверх-вниз каждый раз, когда при прокрутке на телефоне прячется или появляется адресная строка. `100svh` остаётся стабильным и гарантирует, что кнопка и заголовок первого экрана точно поместятся целиком при загрузке.

</details>

**3. Какую сторону окна браузера берёт `10vmin` на экране `1200x600` и на экране `375x812`?**

<details>
<summary>Показать ответ</summary>

`vmin` всегда берёт **меньшую** из двух сторон: на `1200x600` это высота `600px` (`10vmin = 60px`), а на вертикальном телефоне `375x812` — ширина `375px` (`10vmin = 37.5px`).

</details>

## Задачи

**Задача 1. Полноэкранная секция без перекрытия панелью браузера и с fallback**

Задай секции `.hero` минимальную высоту на весь видимый экран при открытой адресной строке телефона (`100svh`), не забыв про запасной вариант `100vh` строкой выше для старых браузеров.

```html
<section class="hero">Главный экран</section>
```

<details>
<summary>Подсказка и решение</summary>

```css
/* Сначала fallback на классический vh, затем стабильный svh */
.hero {
  min-height: 100vh;
  min-height: 100svh;
}
```

</details>

**Задача 2. Мобильное выезжающее меню во всю динамическую высоту экрана**

Оформи панель меню `.mobile-drawer`:
1) Зафиксируй её к правому краю окна (`position: fixed; top: 0; right: 0;`).
2) Задай ширину `80vw` (но не шире `320px` через `max-width`) и высоту во весь динамический экран (`100dvh` с fallback `100vh` выше).

```html
<aside class="mobile-drawer">Мобильное меню</aside>
```

<details>
<summary>Подсказка и решение</summary>

```css
/* Для фиксированного меню 100dvh идеально подстраивается под выезжающую панель браузера */
.mobile-drawer {
  position: fixed;
  top: 0;
  right: 0;
  width: 80vw;
  max-width: 320px;
  height: 100vh;
  height: 100dvh;
}
```

</details>

**Задача 3. Квадратный значок, который не вылезает ни на широком, ни на узком экране (`vmin`)**

Создай круглую кнопку `.fab` с размерами `14vmin` на `14vmin` (но минимум `44px` и максимум `64px` через `clamp()`!) и скруглением `50%`.

```html
<button class="fab" type="button">+</button>
```

<details>
<summary>Подсказка и решение</summary>

<!-- demo-html:
<style>
  .fab { border: 0; background: #2563eb; color: #fff; font-size: 22px; font-weight: 700; cursor: pointer; }
</style>
<button class="fab" type="button">+</button>
-->
```css
/* vmin от меньшей стороны окна + жёсткий диапазон от 44px до 64px через clamp */
.fab {
  width: clamp(44px, 14vmin, 64px);
  height: clamp(44px, 14vmin, 64px);
  border-radius: 50%;
}
```

</details>
