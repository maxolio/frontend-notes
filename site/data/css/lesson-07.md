# Урок 07. Цвета в CSS: ключевые слова, `rgb()`, `HEX`, `hsl()`, `transparent` и `currentColor`

Суть урока: в CSS цвета задают ключевыми словами (`red`), каналами `rgb(r g b / a)` или шестнадцатеричным кодом `#rrggbb`, но удобнее всего управлять оттенками и светлотой в `hsl(h s l / a)`, а `currentColor` связывает рамки и SVG-иконки с текущим `color` текста.

## 1. Ключевые слова и наследование `color` (00:10–01:51)

[+] Цвет в CSS задают тексту (`color`), фону (`background-color`), рамкам (`border-color`) и теням. Свойство `color` наследуется от родителя к потомкам (кроме ссылок `<a>` со встроенным синим стилем браузера). Для быстрых тестов можно писать стандартные имена цветов (`red`, `magenta`, `navy`).

<!-- demo-html:
<p class="red-text">Текст с ключевым словом red</p>
<p class="pink-text">Текст с ключевым словом magenta</p>
-->
```css
/* Ключевое слово на латинице: удобно для быстрых тестов */
.red-text {
  color: red;
}

/* В списке W3C более 140 стандартных имён цветов */
.pink-text {
  color: magenta;
}
```

## 2. Модель `rgb()` и прозрачность через `/` (01:52–03:28)

[+] Функция `rgb()` смешивает три канала от `0` до `255`: красный (Red), зелёный (Green) и синий (Blue). В современном синтаксисе числа разделяют **пробелами**, а альфа-канал (прозрачность от `0` до `1`) дописывают в конце через **`/`**.

[!] Не смешивайте старый синтаксис с запятыми и современный слеш: запись `rgb(255, 0, 0 / 0.5)` невалидна и будет отброшена браузером. Альфа-канал меняет прозрачность только этого свойства, а `opacity: 0.5` делает полупрозрачным весь блок целиком вместе с текстом.

<!-- demo-html:
<p class="alpha-75">Прозрачность 75% (0.75)</p>
<p class="alpha-50">Прозрачность 50% (0.5)</p>
<p class="alpha-25">Прозрачность 25% (0.25)</p>
-->
```css
/* Современный синтаксис: пробелы между каналами и / перед альфой */
.alpha-75 {
  color: rgb(220 38 38 / 0.75);
}

/* 0.5 — половина видимости только для цвета текста */
.alpha-50 {
  color: rgb(220 38 38 / 0.5);
}

/* Старый формат rgba(220, 38, 38, 0.25) тоже работает, но пробелы короче */
.alpha-25 {
  color: rgb(220 38 38 / 0.25);
}
```

## 3. HEX-запись `#RRGGBB`, `#RGB` и прозрачность (03:29–04:53)

[+] HEX (`#rrggbb`) — та же модель RGB, но в шестнадцатеричной системе (`0–9` и `a–f`), по 2 символа на канал (`00` — минимум, `ff` — максимум `255`). Если в каждой паре символы одинаковые (`#ff0000`), запись сокращают до 3 знаков (`#f00`). Четвёртая пара символов в конце (`#ff000080`) задаёт альфа-канал.

<!-- demo-html:
<p class="hex-red">Чистый красный (#f00 из #ff0000)</p>
<p class="hex-green">Зелёный с альфой 50% (#16a34a80)</p>
<p class="hex-blue">Синий полный формат (#1d4ed8)</p>
-->
```css
/* Сокращённая запись: #ff0000 -> #f00 (регистр букв не важен) */
.hex-red {
  color: #f00;
}

/* 8 символов HEX: последние два (80) задают ~50% прозрачности */
.hex-green {
  color: #16a34a80;
}

/* Полная 6-значная запись из макета */
.hex-blue {
  color: #1d4ed8;
}
```

## 4. Цветовой круг `hsl()` (04:54–07:12)

[+] Формат `hsl(оттенок насыщенность светлота / альфа)` читается человеком легче, чем наборы цифр HEX/RGB, и идеально подходит для палитр и тёмных тем:
- **Hue (оттенок):** градусы цветового круга от `0` до `360` (`0` — красный, `120` — зелёный, `240` — синий).
- **Saturation (насыщенность):** от `0%` (серый) до `100%` (максимально сочный цвет).
- **Lightness (светлота):** `0%` — чёрный, `50%` — чистый цвет, `100%` — белый.

<!-- demo-html:
<p class="hsl-pure">Чистый синий (240 100% 50%)</p>
<p class="hsl-dark">Тот же оттенок темнее (240 100% 30%)</p>
<p class="hsl-muted">Приглушённый серый оттенок (240 30% 50% / 0.8)</p>
-->
```css
/* 240° — синий, 100% насыщенности, 50% светлоты = чистый оттенок */
.hsl-pure {
  color: hsl(240 100% 50%);
}

/* Уменьшаем только светлоту (L) — получаем более тёмный вариант */
.hsl-dark {
  color: hsl(240 100% 30%);
}

/* Снижаем насыщенность (S) до 30% и добавляем прозрачность 0.8 */
.hsl-muted {
  color: hsl(240 30% 50% / 0.8);
}
```

## 5. Ключевые слова `transparent` и `currentColor` (07:13–09:00)

[+] `transparent` делает цвет полностью прозрачным (под капотом это `rgb(0 0 0 / 0)` — прозрачный чёрный). `currentColor` (пишется в camelCase!) подставляет текущее вычисленное значение свойства `color` этого элемента в рамки, фоны и SVG-иконки (`fill: currentColor`).

<!-- demo-html:
<style>
  .demo-btn { padding: 6px 12px; background: #fff7ed; cursor: pointer; display: inline-flex; align-items: center; gap: 6px; }
</style>
<p class="ghost-box">Невидимый текст (transparent), но рамка видна</p>
<button class="demo-btn icon-btn" type="button">
  <svg width="16" height="16" viewBox="0 0 16 16"><circle cx="8" cy="8" r="6"/></svg>
  Кнопка с currentColor
</button>
-->
```css
/* Текст скрыт через transparent, хотя место в раскладке сохраняется */
.ghost-box {
  color: transparent;
  border: 1px dashed #94a3b8;
}

/* Задаём color один раз — и рамка, и SVG ниже заберут его автоматически */
.icon-btn {
  color: tomato;
  border: 2px solid currentColor;
}

/* Все элементы внутри SVG перекрасятся в томатный цвет из color кнопки */
.icon-btn svg * {
  fill: currentColor;
}
```

## 3 главные ловушки урока (чек-лист для повторения)

1. Смешивать запятые и слеш в функциях цвета: `rgb(255, 0, 0 / 0.5)` не работает — либо пробелы со слешем (`rgb(255 0 0 / 0.5)`), либо старая запись `rgba(255, 0, 0, 0.5)`.

2. Путать альфа-канал цвета и `opacity`: альфа в `rgb()` / `hsl()` меняет прозрачность только одного свойства (фона или рамки), а `opacity` делает полупрозрачным весь блок с текстом внутри.

3. Использовать `transparent` для плавного исчезновения яркого цвета (например, в градиентах): поскольку `transparent` под капотом чёрный (`rgb(0 0 0 / 0)`), посередине перехода появляется серый оттенок.

## Вопросы для закрепления

**1. В чём главное практическое преимущество `hsl()` перед `HEX` и `rgb()`, когда нужно сделать кнопку чуть темнее или светлее?**

<details>
<summary>Показать ответ</summary>

В `hsl(h s l)` оттенок, насыщенность и светлота разделены: достаточно изменить только третий параметр (`lightness`), не подбирая заново все три канала красного, зелёного и синего.

</details>

**2. Можно ли сократить `#aabbcc` и `#123456` до 3 символов? Почему?**

<details>
<summary>Показать ответ</summary>

`#aabbcc` можно сократить до `#abc`, так как в каждой паре символов (`aa`, `bb`, `cc`) оба знака одинаковые. `#123456` сократить нельзя, потому что цифры внутри пар разные.

</details>

**3. Как `currentColor` помогает перекрашивать встроенный `<svg>` внутри кнопки при одном изменении `color`?**

<details>
<summary>Показать ответ</summary>

Свойство `color` наследуется от кнопки к дочернему `<svg>` и его внутренним тегам (`<path>`, `<circle>`). Если задать им `fill: currentColor;`, заливка автоматически примет унаследованный цвет текста кнопки.

</details>

Для уведомления `.notice` и метки `.badge`:
1) Задай `.notice` фон светло-синего оттенка с прозрачностью `15%` через современный пробельный `rgb(37 99 235 / 0.15)` и рамку `2px solid` в сокращённом HEX `#36c` (расшифровывается как `#3366cc`).
2) Задай `.badge` цвет текста `#ffffff` в сокращённом HEX и тёмно-зелёный фон в `hsl(142 70% 35%)`.

```html
<div class="notice">
  <span class="badge">NEW</span>
  Новое сообщение в системе
</div>
```

<details>
<summary>Подсказка и решение</summary>

<!-- demo-html:
<style>
  .notice { padding: 12px; border-radius: 6px; }
  .badge { padding: 2px 8px; border-radius: 4px; font-size: 13px; margin-right: 6px; }

<div class="notice">
  <span class="badge">NEW</span>
  Новое сообщение в системе
</div>
-->
```css
/* Современный пробельный rgb() со слешем для альфы и 3-значный HEX для рамки */

}

/* 3-значный белый #fff и читаемый зелёный оттенок через hsl() */

  color: #fff;
  background-color: hsl(142 70% 35%);
}
```

</details>

**Задача 2. Палитра в `hsl()` (основной и тёмный вариант кнопки)**

У тебя есть две кнопки: `.btn` и её тёмный вариант `.btn-dark`:
1) Задай `.btn` базовый зелёный фон `hsl(150 65% 42%)`, белый текст `#fff` и рамку `2px solid hsl(150 65% 32%)`.
2) Для `.btn-dark` оставь те же оттенок и насыщенность (`150 65%`), но снизь светлоту фона до `28%`.

```html
<button class="btn" type="button">Обычная кнопка</button>
<button class="btn btn-dark" type="button">Тёмный вариант</button>
```

<details>
<summary>Подсказка и решение</summary>

<!-- demo-html:
<style>
  .btn { padding: 8px 14px; border-radius: 6px; font: inherit; cursor: pointer; }
</style>
<button class="btn" type="button">Обычная кнопка</button>
<button class="btn btn-dark" type="button">Тёмный вариант</button>
-->
```css
/* Базовый цвет и более тёмная рамка за счёт снижения светлоты с 42% до 32% */
.btn {
  background-color: hsl(150 65% 42%);
  color: #fff;
  border: 2px solid hsl(150 65% 32%);
}

/* Меняем только третий параметр (L = 28%), оттенок остаётся тем же */
.btn-dark {
  background-color: hsl(150 65% 28%);
}
```

</details>
