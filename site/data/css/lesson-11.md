# Урок 11. Единицы измерения в CSS: `px`, `%`, `em`, `rem`, `vw` и `vh`

Суть урока: абсолютные единицы (`px`) удобны для рамок, теней и мелких деталей, проценты (`%`) считаются от размеров родителя (но для `height: %` родителю нужна явная высота), `em` зависит от шрифта родителя/элемента, `rem` — от корневого `<html>`, а `vw`/`vh` (и `dvh` на мобильных) привязаны к окну браузера.

## 1. Абсолютные и относительные единицы, CSS-пиксель (00:17–03:46)

[+] Все единицы расстояний делятся на **абсолютные** (`px`, `cm`, `mm` — последние нужны в основном для печати) и **относительные** (`%`, `em`, `rem`, `vw`, `vh`), которые подстраиваются под шрифт, родителя или экран.

[+] Исторически `1px` = `1/96` дюйма, но на современных экранах с высокой плотностью (Retina) браузер сам масштабирует CSS-пиксели так, чтобы интерфейс оставался читаемым.

[!] Не задавайте элементам с динамическим текстом (кнопкам, карточкам) жёсткую ширину в `px` — при росте текста он вылезет за границы. Ширину таких элементов задают через `padding` или `max-width`.

## 2. Проценты `%` и ловушка высоты (03:47–05:50)

[+] Процентная ширина (`width: 50%`) почти всегда считается от ширины родителя. А вот **процентная высота (`height: 50%`) не сработает**, если у самого родителя высота по умолчанию `auto` (нет явного `height` или `position: absolute`).

<!-- demo-html:
<style>
  .pct-wrap-auto { border: 2px dashed #dc2626; padding: 6px; margin-bottom: 8px; font-size: 13px; }
  .pct-wrap-fixed { height: 100px; border: 2px solid #16a34a; padding: 6px; font-size: 13px; }
  .pct-child { background: #dbeafe; padding: 4px 8px; }
</style>
<div class="pct-wrap-auto">
  <div class="pct-child">Родитель без height: height 50% не сработает (осталась по тексту)</div>
</div>
<div class="pct-wrap-fixed">
  <div class="pct-child">Родитель height 100px: ребёнок height 50% = 50px</div>
</div>
-->
```css
/* Для .pct-wrap-auto: высота родителя auto, поэтому 50% превращается в auto */
.pct-child {
  width: 80%;
  height: 50%;
}
```

## 3. Шрифтовые единицы `em` и `rem` (05:51–08:40)

[+] **`em`** умножает `font-size` родителя (а в других свойствах вроде `padding` или `width` — собственный `font-size` элемента). Это удобно для подзаголовка `<span>` внутри `<h1>` или для `padding: 0.5em 1em;` у кнопки: увеличили шрифт кнопки — и отступы выросли пропорционально.

[!] При вложенности (`ul { font-size: 0.85em; }`) `em` даёт **эффект снежного кома** (`0.85 -> 0.72 -> 0.61`), сжимая глубокие списки.

[+] **`rem`** (*root em*) всегда считается от `font-size` корневого тега `<html>` (по умолчанию `16px`). Чтобы не ломать пользовательский масштаб шрифта из настроек браузера, вместо жёсткого `html { font-size: 10px; }` безопаснее писать `html { font-size: 62.5%; }` (те же `10px`, но с уважением к настройкам) либо оставлять `16px`.

<!-- demo-html:
<style>
  .em-heading { font-size: 28px; margin: 0 0 8px; }
  .em-sub { color: #2563eb; }
  .em-btn { background: #fef3c7; border: 2px solid #b45309; cursor: pointer; }
</style>
<h2 class="em-heading">Заголовок 28px <span class="em-sub">(подпись 0.5em = 14px)</span></h2>
<button class="em-btn" type="button">Кнопка с padding в em</button>
-->
```css
/* 0.5 от родительского заголовка (28px * 0.5 = 14px) */
.em-sub {
  font-size: 0.5em;
}

/* Отступы кнопки масштабируются от её собственного шрифта (18px) */
.em-btn {
  font-size: 18px;
  padding: 0.5em 1.2em;
}
```

## 4. Единицы окна `vw`, `vh` и `dvh` (08:41–10:02)

[+] `1vw` (*viewport width*) = `1%` ширины окна браузера, `1vh` (*viewport height*) = `1%` высоты окна. Они удобны для полноэкранных секций (`min-height: 100vh`) и боковых панелей.

[!] На мобильных телефонах адресная строка браузера то появляется, то прячется, из-за чего `100vh` обрезает низ страницы — для мобильных лучше использовать `100dvh` (*dynamic viewport height*). А `width: 100vw` на длинной странице с вертикальным скроллбаром вызывает горизонтальный скролл (для ширины безопаснее `100%`).

<!-- demo-html:
<style>
  .vw-bar { background: #dcfce7; border: 2px solid #16a34a; padding: 8px; font-size: 13px; font-weight: 700; }
</style>
<div class="vw-bar">Ширина 50vw + min-height 15vh (тянется при изменении окна)</div>
-->
```css
/* 50% ширины окна браузера и минимум 15% его высоты */
.vw-bar {
  width: 50vw;
  min-height: 15vh;
}
```

## 3 главные ловушки урока (чек-лист для повторения)

1. Ставить элементу `height: 50%`, когда у его родителя высота `auto` — браузер не знает, от чего брать 50%, и сбрасывает высоту обратно в `auto`.

2. Забывать про каскадное умножение `em` во вложенных списках и карточках (`0.8em * 0.8em`) или ломать пользовательский шрифт жёстким `html { font-size: 10px; }` вместо `%`.

3. Писать `width: 100vw;` на странице с вертикальным скроллбаром — `100vw` включает ширину полосы прокрутки и создаёт лишний горизонтальный скролл (лучше `width: 100%`).

## Вопросы для закрепления

**1. Почему `height: 50%` на `<div class="box">` внутри обычного `<body>` не делает блок высотой в пол-экрана?**

<details>
<summary>Показать ответ</summary>

Потому что по умолчанию высота `<body>` равна `auto` (зависит от высоты его контента). Браузер не может вычислить 50% от ещё неизвестной величины и сбрасывает высоту `.box` в `auto`. Чтобы проценты работали, родителю нужна явная высота (или на ребёнке должен быть `position: absolute` внутри опорного родителя с высотой).

</details>

**2. В чём главное отличие `em` от `rem` и когда лучше выбрать `em`, а когда `rem`?**

<details>
<summary>Показать ответ</summary>

`em` считается от `font-size` родителя (а в `padding`/`width` — от собственного `font-size`), из-за чего при вложенности может накапливаться. `rem` всегда считается от корневого `<html>`. `em` идеален для локального масштабирования (отступы кнопки `padding: 0.5em 1em` или подпись внутри заголовка), а `rem` — для единой независимой шкалы по всему сайту.

</details>

**3. Почему на мобильном телефоне блок `height: 100vh;` может обрезаться снизу, и какая единица это исправляет?**

<details>
<summary>Показать ответ</summary>

В мобильных браузерах `100vh` считается как максимальная высота экрана (без учёта выезжающей адресной строки и нижней панели). Современная единица `100dvh` динамически подстраивается под реально видимую высоту окна.

</details>

**Задача 1. Кнопка с пропорциональными отступами в `em`**

У кнопки `.cta-btn` задан `font-size: 20px;`. Сделай так, чтобы её внутренние отступы всегда были пропорциональны её размеру шрифта: сверху/снизу в `0.6` раза больше шрифта (`12px`), а слева/справа в `1.5` раза больше (`30px`), используя единицу `em` и логические свойства (или `padding`).

```html
<button class="cta-btn" type="button">Начать обучение</button>
```

<details>
<summary>Подсказка и решение</summary>

<!-- demo-html:
<style>
  .cta-btn { background: #2563eb; color: #fff; border: 0; border-radius: 6px; font-weight: 700; cursor: pointer; }
</style>
<button class="cta-btn" type="button">Начать обучение</button>
-->
```css
/* В padding значение em берётся от собственного font-size кнопки (20px) */
.cta-btn {
  font-size: 20px;
  padding: 0.6em 1.5em;
}
```

</details>

**Задача 2. Починка процентной высоты карточки внутри обёртки**

Разработчик хотел сделать блок `.panel` ровно в `50%` высоты от обёртки `.container` (`200px`), но `.panel` сейчас схлопнулся до одной строки текста. Почини CSS (подсказка: высота не задана на `.container`).

```html
<div class="container">
  <div class="panel">Панель 50% высоты</div>
</div>
```

```css
/* Проблемный CSS: */
.container {
  background-color: #e2e8f0;
  padding: 10px;
}

.panel {
  height: 50%;
  background-color: #fde68a;
}
```

<details>
<summary>Подсказка и решение</summary>

```css
/* Задаём явную высоту родителю — теперь 50% у .panel посчитаются от 200px */
.container {
  height: 200px;
  background-color: #e2e8f0;
  padding: 10px;
}

.panel {
  height: 50%;
  background-color: #fde68a;
}
```

</details>

2) Растяни `.full-bar` на всю доступную ширину контейнера **без риска горизонтального скролла** (выбери между `100vw` и `100%`).

```

<details>
<summary>Подсказка и решение</summary>

<!-- demo-html:
<style>
  .card-box { font-size: 12px; border: 2px solid #94a3b8; padding: 10px; }
  .full-bar { background: #bfdbfe; padding: 6px; font-weight: 700; }
</style>

  <p class="lead-rem">Текст в 1.25rem (игнорирует 12px родителя)</p>

```

</details>
