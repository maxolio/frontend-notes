# Этап 2. Урок 2. Подробный разбор `renderMenu()`: `createElement`, замыкание и `append`

Суть урока: Функция `renderMenu()` работает как конвейер: очищает старое меню, в цикле по `state.lessons` создаёт в памяти теги `<button>`, настраивает текст, класс `active` и отложенный клик `() => openLesson(lesson)`, и переносит кнопки на страницу через `append()`.

## 1. Построчный разбор функции `renderMenu()`

[+] Разберём каждую строчку и то, что происходит под капотом браузера:

```js
function renderMenu() {
  menuEl.innerHTML = '';
  /* 1. Стираем всё содержимое внутри <nav id="menu">.
        Это нужно, чтобы при повторном вызове (при переключении урока)
        новые кнопки не приклеились ниже старых и не создали дубли. */

  for (const lesson of state.lessons) {
  /* 2. Цикл for..of по очереди берёт каждый объект урока из массива state.lessons:
        на 1-м шаге lesson = { id: 'lesson-01', title: '...', file: '...' },
        на 2-м шаге — lesson-02 и т.д. */

    const btn = document.createElement('button');
    /* 3. Создаёт в памяти браузера (пока ещё НЕ на странице!) пустой тег <button>.
          В переменной btn лежит ссылка на этот новый DOM-элемент. */

    btn.type = 'button';
    /* 4. Защита: у <button> по умолчанию тип "submit" (для отправки форм).
          Явно ставим "button", чтобы кнопка никогда случайно не перезагрузила страницу. */

    btn.textContent = lesson.title;
    /* 5. Кладём текст названия урока внутрь кнопки.
          Используем .textContent (а не .innerHTML), потому что это просто текст —
          так быстрее и безопаснее от случайных HTML-тегов в названии. */

    if (lesson.id === state.activeId) {
      btn.classList.add('active');
    }
    /* 6. Проверяем состояние: если id этого урока совпадает с текущим открытым
          в state.activeId, добавляем кнопке CSS-класс "active" (синяя рамка). */

    btn.addEventListener('click', () => {
      openLesson(lesson);
    });
    /* 7. Вешаем обработчик клика. Стрелочная функция () => openLesson(lesson)
          запоминает (через замыкание) именно СВОЙ объект lesson с этого шага цикла! */

    menuEl.append(btn);
    /* 8. Финал шага: переносим готовую, настроенную кнопку из памяти
          внутрь реального <nav id="menu"> — и она появляется на экране. */
  }
}
```

## 2. Почему в `addEventListener` нужна обёртка `() => openLesson(lesson)`

[!] Важно не путать **передачу функции** и **вызов функции со скобками** (и это никак не связано с потерей `this`, которого в `openLesson` вообще нет):

```js
/* ПЛОХО: скобки () вызовут функцию МГНОВЕННО прямо при создании кнопки в цикле! */
btn.addEventListener('click', openLesson(lesson));
/* 1. openLesson запустится сразу внутри for..of и вызовет renderMenu() снова -> бесконечный цикл!
   2. В addEventListener передастся НЕ функция, а результат (Promise), и клик не будет работать. */

/* ХОРОШО: стрелочная функция-обёртка — это «отложенная инструкция» */
btn.addEventListener('click', () => {
  openLesson(lesson);
});
/* Браузер запоминает эту стрелку и вызовет её только В МОМЕНТ КЛИКА. */
```

## 3. Итог работы `renderMenu()`: кнопки в режиме ожидания

[+] По завершении `renderMenu()` цикл заканчивается, и на странице внутри `<nav id="menu">` остаётся готовый ряд живых кнопок. Сама функция уже отработала и завершилась, но каждая кнопка **хранит в памяти свою привязку** (обработчик `click` + свой объект `lesson` через замыкание) и спокойно ждёт нажатия:

```text
<nav id="menu">
  ├── <button class="active">Урок 01</button>  ── ждёт клика ──► openLesson(lesson1)
  ├── <button>Урок 02</button>                 ── ждёт клика ──► openLesson(lesson2)
  └── <button>Урок 03</button>                 ── ждёт клика ──► openLesson(lesson3)
</nav>
```

Как только пользователь нажимает на любую кнопку, браузер достаёт привязанный к ней колбэк и запускает следующую ключевую функцию — `openLesson(lesson)`.

## 3 главные ловушки урока (чек-лист для повторения)

1. Написать `btn.addEventListener('click', openLesson(lesson))` без стрелки: функция вызовется прямо в цикле (бесконечная рекурсия через `renderMenu()`), а сам клик перестанет работать.

2. Не поставить `btn.type = 'button'`: если в будущем меню окажется внутри `<form>`, клик по кнопке будет перезагружать страницу.

3. Забыть очистить `menuEl.innerHTML = ''` перед циклом `for..of`: при каждом переключении урока кнопки будут бесконечно дублироваться.

## Вопросы для закрепления

**1. Что произойдёт, если написать `btn.addEventListener('click', openLesson(lesson));` без стрелочной функции-обёртки?**

<details>
<summary>Показать ответ</summary>

Дело не в контексте (`this`), а в моменте вызова: из-за круглых скобок `openLesson(lesson)` запустится **сразу прямо внутри цикла `for..of`** (а поскольку внутри она вызывает `renderMenu()`, начнётся бесконечный цикл). При этом в `addEventListener` попадёт результат `Promise` вместо функции, и клики работать не будут.

</details>

**2. Почему внутри цикла `for..of` каждая кнопка при клике открывает именно свой урок, а не последний урок из массива?**

<details>
<summary>Показать ответ</summary>

Благодаря `const lesson` в цикле `for..of`: на каждой итерации создаётся своя блочная переменная `lesson`, и стрелочная функция `() => openLesson(lesson)` запоминает её через замыкание.

</details>
