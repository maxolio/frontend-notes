1. Совместно со вторым ассистентом оптимизируем уроки CSS на сайте (`site/data/css/`) и пересобираем бандл (`python site/tools/convert_docx.py --subject css --bundle-only`).

## Правила взаимодействия в этом треке
- При заливке задачи/вопроса в `css-site/` давать только короткие якоря вёрстки по пунктам (контейнер, классы/теги/атрибуты, конфликт в CSS).
- Для каждого нового селектора/примера писать, как он читается полностью профессиональным языком.
- Все вопросы и непонятные моменты, которые ученик спрашивает во время практики, заносить в раздел `## Вопросы для закрепления` соответствующего `practice-XX.md` (и пересобирать `all-lessons.md`).
- Формат: короткие шаги, один шаг за раз, без лишней воды.
