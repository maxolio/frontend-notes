## 2. Шпаргалка по CSS: «Современные боевые селекторы» (в раздел CSS)
- **Куда добавить:** отдельной шпаргалкой в `site/data/css/` (или в [lesson-14.md](file:///c:/Frontend/js-ucheba/site/data/css/lesson-14.md) «Псевдоклассы»).
- **Важно про `&`:** запись с `&` работает только внутри вложенности (CSS Nesting: `.card { &:has(img) { ... } }` или SCSS); в плоском CSS пишется без `&` (`.card:has(img)`).
- **Для отступов и списков:**
  - `& > * + *` — селектор «сова»: выбирает все прямые элементы, кроме первого (удобно для `margin-top` между блоками).
  - `&:not(:last-child)` — все элементы, кроме последнего (разделители `border-bottom` в списках/меню).
  - `&:empty` — элемент без текста и тегов (`display: none;` для пустых контейнеров ошибок). *Ловушка: не сработает, если внутри остался пробел или перенос строки (`<div> </div>`).*
- **Магия `:has()` (меняем родителя по детям):**
  - `&:has(img)` — если внутри есть картинка (например, карточка новости перестраивается в 2 колонки).
  - `&:has(input:checked)` — если чекбокс или радиокнопка внутри выбраны (подсветка карточки тарифа без JS).
  - `&:has(> :nth-child(4))` — если внутри 4 и больше прямых элементов (адаптация сетки под количество карточек).
- **Для форм и интерактива:**
  - `&:focus-within` — фокус на любом элементе внутри (подсветка всей строки поиска вместе с иконкой).
  - `&:focus-visible` — обводка только при фокусе с клавиатуры (`Tab`), без рамки после клика мышкой.
  - `&:not(:placeholder-shown)` — в поле уже есть текст (плавающие `label`, кнопка «Очистить»). *Ловушка: в HTML обязателен `placeholder=" "` (хотя бы пробел).*
- **Группировка и управление весом (дополнено):**
  - `&:is(...)` — сокращает длинные списки селекторов (берёт вес самого тяжёлого из списка).
  - `&:where(...)` — то же самое, но с **нулевой специфичностью** (`0-0-0`), чтобы стили легко переопределялись.
