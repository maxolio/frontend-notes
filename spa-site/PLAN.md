# План сборки пет-проекта «Конспекты на чистом JS» (`my-site/`)

> **Архитектурная суть:** SPA (Single Page Application) + **State-Driven UI** (`UI = render(state)`).
> Одна HTML-страница, данные отдельно (`.md` / `.json`), интерфейс перерисовывается от текущего состояния.

---

## Этапы разработки (от простого к сложному)

- [x] **Этап 1. Скелет + 1 урок (`fetch` + `marked`)**
  - Сделать `index.html` и `app.js` (~15 строк): загрузить один `.md`-файл через `fetch()` и вывести в `<article>` через `marked.parse()`.
  - *Практика:* асинхронный `fetch`, `async/await`, `innerHTML`.

- [x] **Этап 2. Оглавление и переключение уроков (массивы + `#hash`)**
  - [x] Загрузить `lessons.json` (3 урока), отрисовать меню через `createElement` и переключать уроки по клику (`state`, `renderMenu`, `openLesson`, `init`).
  - [x] Добавить сохранение активного урока в `window.location.hash` (`#lesson-02`) и реакцию на `hashchange` (кнопки Назад/Вперёд и `F5`).
  - *Практика:* циклы/массивы, события клика, замыкание, `hashchange`.

- [ ] **Этап 3. Карточки и подсветка кода (`DOM` + `highlight.js`)**
  - Найти в DOM абзацы с `Суть урока:` и `[!]`, превратить в карточки, раскрасить код через `hljs.highlightElement()` и добавить кнопку «Копировать».
  - *Практика:* обход DOM (`querySelectorAll`, `classList`), `navigator.clipboard`.

- [ ] **Этап 4. Память браузера (`localStorage` + темы + режим `⚡`)**
  - Добавить смену тем через `data-theme`, статусы `Изучено / Повторить` и кнопку `⚡` (класс `.cheat-mode`).
  - *Практика:* `localStorage`, `JSON.stringify` / `JSON.parse`, связь JS и CSS-переменных.

- [ ] **Этап 5. Умный поиск (`Map` + `debounce`)**
  - Живой фильтр по массиву уроков, предзагрузка `.md` в `Map`-кэш, задержка ввода (`setTimeout`) и безопасная подсветка совпадений (`<mark>`).
  - *Практика:* `Promise.all`, `Map`, `RegExp`, защита от XSS.

- [ ] **Этап 6. Модульная архитектура (`ES-модули` + разделы `HTML / CSS / JS`)**
  - Разбить `app.js` на `state.js`, `render.js`, `search.js`, `app.js` и подключить переключение курсов через `subjects.json`.
  - *Практика:* `import / export`, разделение ответственности (Separation of Concerns).
