# Этап 1. Урок 1. Общая структура: `index.html`, точка входа и `defer`

Суть урока: Минимальный SPA-сайт строится вокруг одной HTML-страницы (`index.html`), в которой есть пустой контейнер-точка входа (`<article id="content">`) и два скрипта с `defer` в строгом порядке.

## 1. Структура файлов этапа

[+] Для простейшего рабочего варианта нужны всего 3 файла рядом в папке `my-site/`:

```text
my-site/
├── index.html    <── пустой каркас страницы и подключение скриптов
├── app.js        <── логика: скачать .md и вставить в страницу
└── lesson-01.md  <── сырой текст конспекта (отделён от вёрстки)
```

## 2. Каркас `index.html` и порядок `<script>` с `defer`

[+] Библиотека `marked.min.js` подключается в `<head>` строго **до** `app.js`, и оба тега получают атрибут `defer`:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Мой сайт конспектов — Шаг 1</title>

  <!-- 1. Внешняя библиотека по CDN -->
  <script src="https://cdn.jsdelivr.net/npm/marked/marked.min.js" defer></script>

  <!-- 2. Наш скрипт строго ПОСЛЕ библиотеки -->
  <script src="app.js" defer></script>
</head>
<body>
  <main>
    <!-- Точка входа: сюда JS позже подставит готовый HTML урока -->
    <article id="content">Загрузка...</article>
  </main>
</body>
</html>
```

[!] `defer` решает сразу две задачи:
- оба скрипта не тормозят чтение HTML и запускаются **после** построения `<article id="content">`;
- скрипты выполняются **строго в том порядке**, в котором записаны в HTML (сначала `marked`, потом `app.js`).

## 3. Схема работы всей связки

```text
[index.html] ─► строит <article id="content">Загрузка...</article>
     │ (HTML готов — запускаются defer-скрипты по очереди)
     ▼
[marked.min.js] ─► добавляет window.marked в память браузера
     │
     ▼
[app.js] ─► берёт lesson-01.md ─► переводит через marked ─► вставляет в #content
```

## 3 главные ловушки урока (чек-лист для повторения)

1. Убрать `defer` у `app.js`: скрипт запустится до чтения `<body>`, `document.getElementById('content')` вернёт `null`, и страница упадёт с `TypeError`.

2. Поставить `app.js` в `<head>` **выше** `marked.min.js`: к моменту запуска `app.js` переменная `marked` ещё не создана (`ReferenceError`).

3. Написать JS-код прямо внутри тега `<script src="app.js">...</script>`: браузер полностью проигнорирует код внутри тега, у которого указан атрибут `src`.
